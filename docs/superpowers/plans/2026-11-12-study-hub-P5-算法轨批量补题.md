# 学习中枢 App（study-hub）—— P5 算法轨批量补题实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把算法轨的题库缺口一次填平——**687 道空骨架**（`learning/bank/`，题面与用例都空）补成「题面 + 测试用例 + 参考解法 + 负例」四件套，**51 道 Codeforces 原题**（工程仓 `bank/`，题面用例齐、参考解法空）补上参考解法与负例，全部落进 `learning/units/algorithm/`，**每一份都经过真实 `g++` 编译执行**：参考解法跑通全部用例（AC），负例必须被拒。产出 738 个单元，`plan` 的内容缺口从 687 降到 0。

**Architecture:** 在 P4 的供给流水线上加一条**算法轨专线**，三个新模块各管一段：`core/supply/algorithm-fill.js`（生成侧：扫题库、判缺口、拼四件套、落盘三件文件）、`core/supply/algorithm-verify.js`（校验侧：复用消费侧同一套 `judge/runner.js` 执行器，参考解法必须全 AC、负例必须被拒）、`core/supply/algorithm-batch.js`（批处理侧：一次 LLM 调用产四件套、配额/限速/重试/断点续跑/记账）。`core/llm/prompts.js` 的 `generate` 场景扩一个 `skeleton` 分支，产出四件套；`tools/supply.js` 加 `--track algorithm` 与 `--batch / --resume / --retry-rejected / --limit / --dry-run / --session`。**存量题库一个字节都不动**——新内容的唯一落点是 `learning/units/algorithm/`。

**Tech Stack:** Node.js ≥ 24（内置 `node:fs` / `node:path` / `node:sqlite` / `node:child_process` / `node:test` / 全局 `fetch`）、原生 JS、**零 npm 依赖**、**零构建**。C++17（`g++ -std=c++17 -O2`）。

**Spec:** `docs/superpowers/specs/2026-11-12-study-hub-design.md`（本计划覆盖其中 §1.2 三轨缺口表「算法」行、§1.5 内容供给三阶段、§1.6 载体与落位、§2.3 三类内容源与 loader、§6.1 供给流水线三阶段表、§6.2 反向校验表、§6.3 工具链、§6.5 降级、§7.1 场景表第 6 行、§10 分期表的 P5 行、§12 风险第 3 条成本）

### P5 新增（P5-1 – P5-12）

| # | 约束 | 精确值 |
|---|---|---|
| P5-1 | **存量题库零改动** | `learning/bank/**` 与工程仓 `bank/**` **一个字节都不许改**。新内容的**唯一落点**是 `learning/units/algorithm/`。护的是 learning 仓的 git 历史（G13） |
| P5-2 | **单元三件套同目录成对** | `learning/units/algorithm/<stem>.md` + `<stem>.reference.cpp` + `<stem>.negative.cpp`，三个文件**同目录、同 stem** |
| P5-3 | **一次 LLM 调用产四件套** | 题面 / 用例 / 参考解法 / 负例**在同一次回复里**产出（省一半的钱，且负例与参考解法针对同一份用例，不会跑偏）。每题**最多 3 次尝试**（1 次 + `supply.batch.max_retries` = 2） |
| P5-4 | **负例是独立代码产物，不是第五种断言** | `Assert` 仍然只有四种（契约 §2）。负例是**单独的 `.cpp` 文件**，用**同一批 `output` 断言**去跑它。「被拒」= `verdict ∈ {wrong_answer, runtime_error, timeout}`。**`compile_error` 不算被拒**——那说明负例本身没写对 |
| P5-5 | **负例内容绝不进单元 md** | 学习者看到的 `## 参考解法` 里只有**正确解法**。负例的内容只存在于 `<stem>.negative.cpp`，md 里只留它的相对路径。学习者**永远看不到错解** |
| P5-6 | **参考解法双份且必须一致** | `<stem>.reference.cpp`（`entry.reference` 指向它，判题器编译它）与 md 里 `## 参考解法` 的代码块是**同一份内容**。校验时逐字节比对，不一致 → `rejected` |
| P5-7 | **校验是真实编译执行** | 用消费侧同一套 `judge/runner.js` 的 `judge()` + `judge/sandbox.js` 的沙箱，`g++ -std=c++17 -O2`。**不许**用字符串比对冒充执行 |
| P5-8 | **参考解法全 AC 才算过** | 参考解法跑**全部**用例必须 `verdict === "pass"`。任一用例不过 → `rejected`，理由写明 `wrong_answer` / `timeout` / `runtime_error` / `compile_error` |
| P5-9 | **负例必须被拒，且「全过」也算失败** | 负例全过 → `rejected`，理由「负例竟然全部通过，说明测试用例太弱，挡不住错解」——这是**假判题器**的信号 |
| P5-10 | **状态写回只改一行** | 单元 md 的 `status` 用读-改-写改写（G15）：只替换 frontmatter 里 `status:` 那一行，其余逐字节不变。落盘顺序固定：`draft` → 校验 → 改成 `verified` / `rejected` |
| P5-11 | **批处理幂等 + 可续跑** | 每题的状态落在 `settings` 表的 `supply.batch.item.algo.<stem>`。`--resume` 跳过已 `verified` / 已 `rejected` 的题（`--retry-rejected` 才重新试 `rejected`），只重跑 `failed` 的题。**同一个批次重跑不重复花钱** |
| P5-12 | **超预算就停，不硬撑** | 批次调用数达到 `supply.batch.session_limit`（默认 800）或当日计数达到 `supply.batch.daily_limit`（默认 800）→ **立刻停止**，打印中文提示「还欠 N 个，用 `--resume` 接着跑」。**绝不**为了跑完而烧穿预算 |

### 8. 负例到底是什么（口径钉死，P5-4/P5-5）

**负例 = 一份故意写错的 C++ 参考解法。** 具体长这样：题是「输出 a + b」，参考解法输出 `a+b`，负例输出 `a*b`——**读起来像模像样，编译得过，但在至少一个用例上给出错误答案**。

- **它怎么生成**：LLM 在同一次调用里一并产出，提示词明确要求「负例必须能编译、必须有一个与参考解法不同的逻辑错误、必须在至少一个给定用例上给出错误输出」。P5 只在**结构层面**检查（必须有 `main()`、不能与参考解法逐字相同），**逻辑对错由执行器判**。
- **它怎么被判定「必须被拒」**：用**同一批 `output` 断言**去跑负例。判定：
  - `verdict === "pass"` → **不算被拒** → `rejected`，理由「负例竟然全部通过，说明测试用例太弱，挡不住错解」；
  - `verdict === "compile_error"` → **不算被拒** → `rejected`，理由「负例编译失败，负例本身无效」；
  - `verdict ∈ {wrong_answer, runtime_error, timeout}` → **算被拒** → 这一项通过。
- **被拒算成功吗**：**算成功**。负例被拒 = 质检通过 = 单元可以进 `verified`。负例**没**被拒 = 质检失败 = 单元进 `rejected` 队列等人看。
- **负例不会泄题**：负例的**内容**只存在于 `<stem>.negative.cpp`，单元 md 里**只留相对路径**。学习者打开单元页看不到错解（G24 的精神）。

### 9. 为什么不用契约 §3.5 的 Python 断言脚本模板

契约 §3.5 冻结的模板是给 **DB / AI 两轨的 `kind: card`** 用的：脚本用 `subprocess` 跑 demo、demo 路径取环境变量 `STUDY_HUB_DEMO`、全部断言通过 `exit 0`。算法轨**不是**这个形状：

| | DB / AI 卡（§3.5） | 算法题（P5） |
|---|---|---|
| 判题入口 | 单元自带的断言脚本（Python） | **用户提交的代码 / 参考解法（C++）** |
| 检验的东西 | demo 的**结论字符串**出现在 stdout 里 | 程序的**输出**与期望逐字相等 |
| 产物 | `<stem>.assert.py` | `<stem>.reference.cpp` + `<stem>.negative.cpp` |
| 「通过」的含义 | 脚本 `exit 0` | 参考解法全用例 AC **且** 负例被拒 |

§3.5 的**原则**（断言全过才 exit 0、执行在沙箱里、脚本与单元同目录成对）P5 **全部照搬**；只是**载体从 Python 换成 C++**，因为算法题的「被测对象」是 C++ 程序本身，不是 demo 的结论字符串。**不许**为了套模板而把算法轨改成 Python 脚本——那样就变成了「校验 Python 脚本」，与 spec §6.2「跑参考解法 × 全部用例，全 AC」直接冲突。

```javascript
// ============ core/unit/loader-c.js 追加 ============

/** 算法轨单元的 id 合法性（契约 §3.3） */
const UNIT_ID_RE = /^(algo|db|ai):[a-z0-9][a-z0-9._-]*$/

/** track 与 id 前缀的对应（契约 §3.3） */
const TRACK_PREFIX = { algorithm: "algo", database: "db", ai: "ai" }

/**
 * 算法轨的单元文件（契约 §3.3.1）。
 *
 * 与 DB/AI 卡的差别只在正文小节：
 *   ## 题面      → unit.statement
 *   ## 测试用例  → unit.asserts（每行一条 output 型断言，cmp 固定 exact）
 *   ## 参考解法  → **不进 Unit**（那是给人看的镜像，校验交给 algorithm-verify.js）
 *   ## 关联      → unit.related
 *
 * frontmatter 在 §3.3 的清单上额外允许 negative: / source_id: / url: 三个选填字段。
 * 算法轨的 graded 恒为 user、entry.script 恒为空串、entry.language 恒为 cpp。
 *
 * @param {string} text
 * @param {{path?: string}} opts
 * @returns {{unit: object|null, warnings: string[]}}
 */
function parseAlgorithmUnit(text, opts) {
  const o = opts || {}
  const warnings = []
  const src = String(text || "").replace(/\r\n/g, "\n")
  const fmMatch = /^---\n([\s\S]*?)\n---\n?/.exec(src)
  const fm = fmMatch ? parseFrontmatter(fmMatch[1]) : {}
  const body = fmMatch ? src.slice(fmMatch[0].length) : src
  const sections = splitSections(body)

  const id = String(fm.id || "")
  const track = String(fm.track || "")
  const kind = String(fm.kind || "")
  const status = String(fm.status || "")
  const graded = String(fm.graded || "")
  const filePath = String(o.path || "")

  // —— 校验（契约 §3.3 的清单，逐条对应）——
  if (!UNIT_ID_RE.test(id)) {
    warnings.push("单元 id 非法：" + (id || "（空）"))
    return { unit: null, warnings: warnings }
  }
  if (TRACK_PREFIX[track] !== id.split(":")[0]) {
    warnings.push("单元 id 前缀与 track 不一致：" + id + " / " + (track || "（空）"))
    return { unit: null, warnings: warnings }
  }
  if (kind !== "problem") {
    warnings.push("单元 " + id + " 的 kind 非法：" + (kind || "（空）"))
    return { unit: null, warnings: warnings }
  }
  if (graded !== "user" && graded !== "script") {
    warnings.push("单元 " + id + " 的 graded 非法：" + (graded || "（空）"))
    return { unit: null, warnings: warnings }
  }
  if (graded === "script" && !String(fm.script || "")) {
    warnings.push("单元 " + id + " 声明 graded: script 但没写 script 路径")
    return { unit: null, warnings: warnings }
  }
  if (UNIT_STATUSES.indexOf(status) === -1) {
    warnings.push("单元 " + id + " 的 status 非法：" + (status || "（空）"))
    return { unit: null, warnings: warnings }
  }
  if (!/units\/algorithm\//.test(filePath.replace(/\\/g, "/"))) {
    warnings.push("单元 " + id + " 放在 units/<目录>/ 下，与 track 不符")
    return { unit: null, warnings: warnings }
  }

  // —— 正文 ——
  const statement = String(sections["题面"] || "").trim()
  const cases = parseCases(sections["测试用例"] || "")
  const asserts = cases.map(function (c) {
    return { type: "output", input: c.input, expect: c.expect, cmp: "exact" }
  })
  const related = String(sections["关联"] || "").trim()

  const unit = {
    id: id,
    track: "algorithm",
    kind: "problem",
    title: String(fm.title || ""),
    statement: statement,
    entry: {
      demo: "",
      reference: String(fm.reference || ""),
      graded: "user",
      script: "",
      language: "cpp",
    },
    asserts: asserts,
    topics: normalizeTopics(fm.topics),
    difficulty: DIFFICULTIES.indexOf(String(fm.difficulty)) !== -1 ? String(fm.difficulty) : "medium",
    source: UNIT_SOURCES.indexOf(String(fm.source)) !== -1 ? String(fm.source) : "generated",
    status: status,
    progress: "todo",
    reviewed: fm.reviewed === true || fm.reviewed === "true",
    reviewed_at: String(fm.reviewed_at || ""),
    subtracks: normalizeTracks(fm.subtracks),
    path: filePath,
    related: related,
  }
  return { unit: unit, warnings: warnings }
}
```

"use strict"
/**
 * algorithm-fill.js —— 算法轨生成侧：扫题库判缺口、渲染四件套、落盘三件套、只改 status 一行
 *
 * 本模块**只读** learning/bank/** 与工程仓 bank/**，**只写** learning/units/algorithm/（P5-1）。
 * 存量题库一个字节都不许动（G14 / P5-2）。
 *
 * 「缺什么」按**内容**判定，不看 frontmatter 的 needs_fill 标志（契约 §1.4：
 * 那个标志在存量里已经过时——51 道 CF 原题的 needs_fill 还是 true，但题面与用例其实都齐）。
 *
 * 四种形态：
 *   A 补全型：题面空（用例也空）        → LLM 产全套四件套
 *   B 补用例型：题面非空、用例空        → 题面原样保留，LLM 产用例 + 解法 + 负例
 *   C 补解型：题面非空、用例非空、解法空 → 题面与用例原样保留，LLM 只产解法 + 负例
 *   ready 已齐备：一个字都不改
 */

const fs = require("node:fs")
const path = require("node:path")
const { spawnSync } = require("node:child_process")

const { parseFrontmatter, splitSections, parseCases, parseSolution } = require("../bank/parse.js")
const { encodeCell } = require("../bank/case-codec.js")
const { normalizeTopics, normalizeTracks, DIFFICULTIES } = require("../bank/problem.js")

/** 题库里的小节名（题库文件与单元文件同名，沿用 parse.js 的叫法） */
const SECTION_STATEMENT = "题面"
const SECTION_CASES = "测试用例"
const SECTION_SOLUTION = "参考解法"

/** 四种形态 */
const SHAPES = ["A", "B", "C", "ready"]

/** 可能缺的三样 */
const MISSING_KEYS = ["statement", "cases", "solution"]

/** 产出目录（相对 learning 仓根） */
const UNITS_REL_DIR = "units/algorithm/"

/** 契约 §1.2 允许的 Unit.source 取值域 */
const UNIT_SOURCES = [
  "leetcode",
  "nowcoder",
  "self",
  "grokking",
  "scaffold",
  "generated",
  "codeforces",
  "unknown",
]

/** 题库里的 source 名 → Unit.source 的归一（存量题库用 "jz" 表示牛客） */
const SOURCE_ALIAS = { jz: "nowcoder" }

/**
 * C++ 源码归一：统一 LF、去掉末尾空行。
 *
 * md 里的 `## 参考解法` 代码块与 `<stem>.reference.cpp` **用同一份归一结果**，
 * 于是「两者逐字节一致」这件事可以直接比较（P5-6 / 契约 §3.3.1）。
 */
function canonicalCode(code) {
  return String(code === null || code === undefined ? "" : code)
    .replace(/\r\n/g, "\n")
    .replace(/\r/g, "\n")
    .replace(/\n+$/, "")
}

/**
 * 题面里的二级标题降一级（`## 输入` → `### 输入`）。
 *
 * loader C 用 `splitSections` 按 `^## ` 切正文，题面里留着二级标题会把题面截断。
 * 围栏代码块**不动**（里面的 `##` 是代码，不是标题）。
 */
function demoteHeadings(text) {
  const lines = String(text === null || text === undefined ? "" : text).split(/\r?\n/)
  let inFence = false
  return lines
    .map(function (line) {
      const trimmed = line.trim()
      if (trimmed.charAt(0) === "`" && trimmed.indexOf("```") === 0) {
        inFence = !inFence
        return line
      }
      if (inFence) return line
      if (/^##\s+\S/.test(line)) return "#" + line
      return line
    })
    .join("\n")
}

/** 把值压成一行（frontmatter 的值不能换行） */
function oneLine(text) {
  return String(text === null || text === undefined ? "" : text)
    .replace(/\r\n/g, "\n")
    .replace(/\n/g, " ")
    .trim()
}

/**
 * 列表项里的逗号会破坏 mini-YAML 的行内数组（`[a, b]` 靠逗号切分），
 * 所以写进 frontmatter 之前把半角逗号换成全角顿号。
 */
function safeListItem(text) {
  return oneLine(text).replace(/,/g, "、")
}

/**
 * 读一份题库 md，判出它属于哪种形态、缺什么。
 *
 * @param {string} absPath 题库文件的绝对路径
 * @param {"learning"|"local"} origin 来自 learning 仓还是工程仓
 * @param {string} contentRoot 相对路径的基准目录（learning 仓根 / 工程仓根）
 * @returns {object}
 */
function inspectBankFile(absPath, origin, contentRoot) {
  const rel = path.relative(contentRoot, absPath).split(path.sep).join("/")
  let text = ""
  try {
    text = fs.readFileSync(absPath, "utf8")
  } catch (err) {
    return { ok: false, stem: "", origin: origin, sourcePath: rel, warnings: ["读不到题库文件：" + rel] }
  }
  const src = text.replace(/\r\n/g, "\n")
  const fmMatch = /^---\n([\s\S]*?)\n---\n?/.exec(src)
  const fm = fmMatch ? parseFrontmatter(fmMatch[1]) : {}
  const body = fmMatch ? src.slice(fmMatch[0].length) : src
  const sections = splitSections(body)

  const statement = String(sections[SECTION_STATEMENT] || "").trim()
  const cases = parseCases(sections[SECTION_CASES] || "")
  const solution = parseSolution(sections[SECTION_SOLUTION] || "").code.trim()

  const hasStatement = statement !== ""
  const hasCases = cases.length > 0
  const hasSolution = solution !== ""

  let shape = "ready"
  if (!hasStatement) shape = "A"
  else if (!hasCases) shape = "B"
  else if (!hasSolution) shape = "C"

  const missing = []
  if (!hasStatement) missing.push("statement")
  if (!hasCases) missing.push("cases")
  if (!hasSolution) missing.push("solution")

  const stem = path.basename(absPath).replace(/\.md$/, "")
  const difficulty = DIFFICULTIES.indexOf(String(fm.difficulty)) !== -1 ? String(fm.difficulty) : "medium"
  const rawSource = oneLine(fm.source || "unknown")
  const aliased = SOURCE_ALIAS[rawSource] || rawSource
  const unitSource = UNIT_SOURCES.indexOf(aliased) !== -1 ? aliased : "unknown"

  return {
    ok: true,
    stem: stem,
    origin: origin,
    sourcePath: rel,
    unitId: "algo:" + stem,
    title: oneLine(fm.title || stem),
    difficulty: difficulty,
    topics: normalizeTopics(fm.topics),
    subtracks: normalizeTracks(fm.tracks),
    source: rawSource,
    unitSource: unitSource,
    sourceId: oneLine(fm.source_id === undefined ? "" : fm.source_id),
    url: oneLine(fm.url === undefined ? "" : fm.url),
    shape: shape,
    missing: missing,
    hasStatement: hasStatement,
    hasCases: hasCases,
    hasSolution: hasSolution,
    statement: statement,
    cases: cases.map(function (c) {
      return { input: c.input, expect: c.expect, tol: c.tol }
    }),
    solution: solution,
    warnings: [],
  }
}

/**
 * 递归列出目录下所有 .md。
 * @param {string} dir
 * @param {string} contentRoot
 * @param {"learning"|"local"} origin
 * @returns {Array<object>}
 */
function listBankFiles(dir, contentRoot, origin) {
  const acc = []
  let entries = []
  try {
    entries = fs.readdirSync(dir, { withFileTypes: true })
  } catch (err) {
    return acc
  }
  entries.sort(function (a, b) {
    return a.name < b.name ? -1 : a.name > b.name ? 1 : 0
  })
  entries.forEach(function (entry) {
    const abs = path.join(dir, entry.name)
    if (entry.isDirectory()) {
      acc.push.apply(acc, listBankFiles(abs, contentRoot, origin))
      return
    }
    if (!entry.isFile()) return
    if (!/\.md$/i.test(entry.name)) return
    const item = inspectBankFile(abs, origin, contentRoot)
    if (item.ok) acc.push(item)
  })
  return acc
}

/**
 * 统计：按形态、来源、难度、子轨、知识点、缺什么。
 * @param {Array<object>} items
 * @returns {object}
 */
function buildStats(items) {
  const stats = {
    total: items.length,
    byShape: { A: 0, B: 0, C: 0, ready: 0 },
    bySource: {},
    byDifficulty: {},
    bySubtrack: {},
    byTopic: {},
    byOrigin: { learning: 0, local: 0 },
    missing: { statement: 0, cases: 0, solution: 0 },
  }
  items.forEach(function (item) {
    stats.byShape[item.shape] += 1
    stats.bySource[item.source] = (stats.bySource[item.source] || 0) + 1
    stats.byDifficulty[item.difficulty] = (stats.byDifficulty[item.difficulty] || 0) + 1
    stats.byOrigin[item.origin] = (stats.byOrigin[item.origin] || 0) + 1
    item.subtracks.forEach(function (t) {
      stats.bySubtrack[t] = (stats.bySubtrack[t] || 0) + 1
    })
    item.topics.forEach(function (t) {
      stats.byTopic[t] = (stats.byTopic[t] || 0) + 1
    })
    item.missing.forEach(function (m) {
      stats.missing[m] += 1
    })
  })
  return stats
}

/**
 * 扫两个题库，产出缺口清单与统计。
 *
 * @param {{learningRoot?: string|null, localBank?: string|null, localContentRoot?: string|null}} opts
 * @returns {{items: Array<object>, stats: object, warnings: string[]}}
 */
function scanBank(opts) {
  const o = opts || {}
  const warnings = []
  const items = []

  if (o.learningRoot) {
    const dir = path.join(o.learningRoot, "bank")
    if (fs.existsSync(dir)) {
      items.push.apply(items, listBankFiles(dir, o.learningRoot, "learning"))
    } else {
      warnings.push("learning 仓里没有 bank 目录：" + dir)
    }
  }
  if (o.localBank && fs.existsSync(o.localBank)) {
    const localContentRoot = o.localContentRoot || path.dirname(o.localBank)
    items.push.apply(items, listBankFiles(o.localBank, localContentRoot, "local"))
  }

  // 同一个 stem 在两处都有时，先到先得（learning 优先），后者丢弃
  const seen = Object.create(null)
  const unique = []
  items.forEach(function (item) {
    if (seen[item.stem]) {
      warnings.push("题号重复，保留先出现的：" + item.stem + "（跳过 " + item.sourcePath + "）")
      return
    }
    seen[item.stem] = true
    unique.push(item)
  })
  unique.sort(function (a, b) {
    return a.stem < b.stem ? -1 : a.stem > b.stem ? 1 : 0
  })
  return { items: unique, stats: buildStats(unique), warnings: warnings }
}

/**
 * 渲染单元 md（契约 §3.3 + §3.3.1）。
 *
 * frontmatter 字段与 §3.3 的清单一一对应，另加 §3.3.1 允许的 negative / source_id / url。
 * 负例的**内容绝不进 md**（§10.1 冻结）——学习者只看得到正确解法。
 *
 * @param {object} draft
 * @returns {string}
 */
function renderUnitMarkdown(draft) {
  const d = draft || {}
  const stem = oneLine(d.stem || "")
  const topics = (d.topics || []).map(safeListItem).filter(function (t) { return t !== "" })
  const subtracks = (d.subtracks || []).map(safeListItem).filter(function (t) { return t !== "" })
  const lines = []

  lines.push("---")
  lines.push("id: algo:" + stem)
  lines.push("track: algorithm")
  lines.push("kind: problem")
  lines.push("title: " + oneLine(d.title || stem))
  lines.push("difficulty: " + (DIFFICULTIES.indexOf(String(d.difficulty)) !== -1 ? String(d.difficulty) : "medium"))
  lines.push("topics: [" + topics.join(", ") + "]")
  lines.push("source: " + (d.unitSource ? oneLine(d.unitSource) : d.source ? oneLine(d.source) : "generated"))
  if (d.sourceId) lines.push("source_id: " + oneLine(d.sourceId))
  if (d.url) lines.push("url: " + oneLine(d.url))
  lines.push("subtracks: [" + subtracks.join(", ") + "]")
  lines.push("progress: todo")
  lines.push("graded: user")
  lines.push("reference: " + UNITS_REL_DIR + stem + ".reference.cpp")
  lines.push("negative: " + UNITS_REL_DIR + stem + ".negative.cpp")
  lines.push("status: " + (d.status ? oneLine(d.status) : "draft"))
  lines.push("reviewed: false")
  lines.push('reviewed_at: ""')
  lines.push("---")
  lines.push("")
  lines.push("## " + SECTION_STATEMENT)
  lines.push("")
  lines.push(demoteHeadings(String(d.statement === undefined || d.statement === null ? "" : d.statement).trim()))
  lines.push("")
  lines.push("## " + SECTION_CASES)
  lines.push("")
  lines.push("| input | expect |")
  lines.push("|---|---|")
  ;(d.cases || []).forEach(function (c) {
    lines.push(
      "| " +
        encodeCell(String(c.input === undefined ? "" : c.input)) +
        " | " +
        encodeCell(String(c.expect === undefined ? "" : c.expect)) +
        " |"
    )
  })
  lines.push("")
  lines.push("## " + SECTION_SOLUTION)
  lines.push("")
  lines.push("```cpp")
  lines.push(canonicalCode(d.solution))
  lines.push("```")
  lines.push("")
  lines.push("## 关联")
  lines.push("")
  lines.push("- 原始题号：" + (d.sourceId ? oneLine(d.sourceId) : "无"))
  lines.push("- 来源平台：" + (d.source ? oneLine(d.source) : "unknown"))
  lines.push("- 原题链接：" + (d.url ? oneLine(d.url) : "无"))
  if (d.originPath) lines.push("- 原题库文件：" + oneLine(d.originPath))
  lines.push("")
  return lines.join("\n")
}

/**
 * 落盘三件套：md + reference.cpp + negative.cpp。
 *
 * @param {{unitsDir: string, stem: string, draft: object}} opts
 * @returns {{files: string[]}} 落盘的绝对路径
 */
function writeTriplet(opts) {
  const o = opts || {}
  const unitsDir = String(o.unitsDir || "")
  const stem = oneLine(o.stem || "")
  if (!unitsDir) throw new Error("writeTriplet 缺 unitsDir")
  if (!stem) throw new Error("writeTriplet 缺 stem")
  fs.mkdirSync(unitsDir, { recursive: true })
  const mdPath = path.join(unitsDir, stem + ".md")
  const refPath = path.join(unitsDir, stem + ".reference.cpp")
  const negPath = path.join(unitsDir, stem + ".negative.cpp")
  fs.writeFileSync(mdPath, renderUnitMarkdown(o.draft), "utf8")
  fs.writeFileSync(refPath, canonicalCode(o.draft.solution) + "\n", "utf8")
  fs.writeFileSync(negPath, canonicalCode(o.draft.negative) + "\n", "utf8")
  return { files: [mdPath, refPath, negPath] }
}

/**

  const sections = splitSections(String(text || ""))
  return canonicalCode(parseSolution(sections[SECTION_SOLUTION] || "").code)

/**
 * 只改 frontmatter 里 status 那一行，其余**逐字节**不变（G15 / P5-10）。
 *
 * 连行尾风格（CRLF / LF）都原样保留；frontmatter 里没有 status 行时补一行。
 *
 * @param {string} text
 * @param {string} status
 * @returns {string}
 */
function patchStatusLine(text, status) {
  const src = String(text === null || text === undefined ? "" : text)
  const fm = /^---[ \t]*\r?\n([\s\S]*?)\r?\n---[ \t]*(?:\r?\n|$)/.exec(src)
  if (!fm) throw new Error("单元文件缺少 frontmatter，改不了 status")
  const head = src.slice(0, fm.index)
  const body = fm[1]
  const tail = src.slice(fm.index + fm[0].length)
  const re = /(^|\r?\n)([ \t]*status[ \t]*:[ \t]*)([^\r\n]*)/
  if (re.test(body)) {
    const newBody = body.replace(re, function (all, pre, key) {
      return pre + key + status
    })
    return head + newBody + tail
  }
  const eol = body.indexOf("\r\n") !== -1 ? "\r\n" : "\n"
  return head + body + eol + "status: " + status + tail
}

function statusEntryPath(entry) {
  const text = String(entry || "")
  if (text.length < 4) return text
  return text.slice(3)
}

function runGitStatus(root) {
  const res = spawnSync(

    stderr: String(res.stderr || ""),
    error: "",
  }
}

 * 命令固定：`git -c core.quotepath=false status --porcelain -z --untracked-files=all`，

 */
function checkLearningClean(opts) {
  const o = opts || {}
  const root = String(o.learningRoot || "")
  if (!root) {
    return {
      ok: false,
      entries: [],
      blocked: [],
      allowed: [],
      reason: "没解析到 learning 仓根目录，无法查脏",
      blockedBy: "no-root",
    }
  }
  const runner = typeof o.gitRunner === "function" ? o.gitRunner : runGitStatus
  const res = runner(root)
  if (!res.ok) {
    return {
      ok: false,
      entries: [],
      blocked: [],
      allowed: [],
      reason: "查脏失败（git 跑不通）：" + (res.error || res.stderr || "未知原因"),
      blockedBy: "git-error",
    }
  }
  const entries = String(res.stdout || "")
    .split("\0")
    .filter(function (s) {
      return s !== ""
    })
  const allowPrefix = o.allowPrefix === undefined ? UNITS_REL_DIR : String(o.allowPrefix)
  const blocked = []
  const allowed = []
  entries.forEach(function (entry) {
    const p = statusEntryPath(entry).replace(/\\/g, "/")
    if (allowPrefix && p.indexOf(allowPrefix) === 0) allowed.push(entry)
    else blocked.push(entry)
  })
  if (blocked.length > 0) {
    return {
      ok: false,
      entries: entries,
      blocked: blocked,
      allowed: allowed,
      reason:
        "learning 仓有 " +
        blocked.length +

        blocked.slice(0, 5).join("、"),
      blockedBy: "dirty",
    }
  }
  return { ok: true, entries: entries, blocked: [], allowed: allowed, reason: "", blockedBy: "" }
}

 *
 * 覆盖报告靠它判断「这道题还欠不欠」：

 * 而是靠 units/algorithm/ 下多了一份 status: verified 的单元——这就是契约 §12 的验收线。
 *
 * @param {string} unitsDir 单元目录
 * @returns {Object} {stem: status}
 */
function readUnitStatuses(unitsDir) {
  const out = {}
  const dir = String(unitsDir || "")
  if (dir === "" || !fs.existsSync(dir)) return out
  let names = []
  try {
    names = fs.readdirSync(dir)
  } catch (err) {
    return out
  }
  names.forEach(function (name) {
    if (!name.endsWith(".md")) return
    const stem = name.slice(0, name.length - 3)
    if (stem === "plan") return
    let text = ""
    try {
      text = fs.readFileSync(path.join(dir, name), "utf8")
    } catch (err) {
      return
    }
    const m = /^---\r?\n([\s\S]*?)\r?\n---\r?\n?/.exec(text)
    if (!m) return
    const fm = parseFrontmatter(m[1]) || {}
    const status = String(fm.status || "").trim()
    if (status !== "") out[stem] = status
  })
  return out
}

## Task 3: 提示词的四件套分支（`core/llm/prompts.js`）

一次 LLM 调用要产出**四件套**（题面 / 用例 / 参考解法 / 负例），所以提示词得能说清这四样，也要能说清「哪几样已经存在、原样保留」。

**关键设计：`buildPrompt` 与 `parseResponse` 都是纯函数**（G10 / 设计 §7.3），所以扩展只能是**加可选参数**，不能改已有调用的行为。

**向后兼容的做法**：
- `buildPrompt("generate", ctx)`：只有 `ctx.mode === "skeleton"` 时走新分支，其它参数**一个字都不变**；
- `parseResponse(text, kind)`：加**可选**第三参 `opts`；两参调用（含 M6 已有的测试）行为不变；
- `buildGenerated` 的返回值**多两个字段** `negative` / `negativeNote`，缺省是空串——既有的逐字段断言不受影响。

**Files:**
- Modify: `projects/apps/study-hub/core/llm/prompts.js`
- Create: `projects/apps/study-hub/tests/supply-algorithm-prompt.test.js`

**Interfaces:**
- Consumes：`core/bank/problem.js` 的 `normalizeTopics` / `DIFFICULTIES`
- Produces：
  - `buildPrompt("generate", {mode:"skeleton", shape, stem, title, difficulty, topics, url, statement, cases})` → `{system, user}`
  - `parseResponse(text, "generate", {mode:"skeleton", need: [...]})` → `{ok:true, problem:{statement?, cases?, solution?, negative, negativeNote, title, difficulty, topics, solutionLang}}`

```javascript
/**
 * 四件套的提示词（算法轨批量补题用）。
 *
 * 形态决定「哪几件要模型给」：
 *   A 题面与用例都缺 → 题面、用例、解法、负例都要
 *   B 只缺用例      → 题面原样保留，要用例、解法、负例
 *   C 只缺解法      → 题面与用例原样保留，要解法、负例
 *
 * @param {object} ctx {mode, shape, stem, title, difficulty, topics, url, statement, cases}
 * @returns {{system: string, user: string}}
 */
function buildSkeletonPrompt(ctx) {
  const c = ctx || {}
  const shape = String(c.shape || "A")
  const need = SKELETON_NEEDS[shape] || SKELETON_NEEDS.A
  const cases = Array.isArray(c.cases) ? c.cases : []
  const caseLines = cases.length
    ? cases.map(function (item) {
        return "- " + String(item.input || "") + " → " + String(item.expect || "")
      }).join("\n")
    : "（缺失，需要你补）"
  const statement = String(c.statement || "").trim() || "（缺失，需要你补）"

  const rules = []
  rules.push("1. 判题契约：程序从 stdin 读入、从 stdout 输出，自带 main 函数，不要写 class Solution 之类的包装。")
  if (need.indexOf("statement") !== -1) {
    rules.push("2. 题面缺失，必须新写：说清输入、输出、约束，不能依赖上下文。")
  } else {
    rules.push("2. 题面已经存在，原样保留，不要改写、不要润色。")
  }
  if (need.indexOf("cases") !== -1) {
    rules.push("3. 至少给 3 个测试用例，其中至少 1 个是边界情况；expect 必须与 solution 的实际输出逐字一致。")
  } else {
    rules.push("3. 测试用例已经存在，原样保留；solution 必须能通过上面列出的全部用例，expect 就是程序的输出。")
  }
  rules.push("4. solution 是正确的 C++ 参考解法：完整程序、自带 main 函数，能通过上面全部测试用例。")
  rules.push("5. negative 是故意写错的 C++ 解法：完整程序、自带 main 函数、能编译通过，但逻辑上算错——")
  rules.push("   在至少一个测试用例上给出与 expect 不同的输出。")
  rules.push("6. negative 不能与 solution 完全相同，也不能只是把 solution 换个变量名。")
  rules.push("7. negativeNote 用一句话说明负例错在哪（只给人看，不要泄露正确答案）。")

  const fields = []
  if (need.indexOf("statement") !== -1) fields.push("title、statement")
  if (need.indexOf("cases") !== -1) fields.push("cases")
  fields.push("solution、negative、negativeNote")

  const lines = []
  lines.push("请为下面这道题补齐内容。")

  lines.push("题号：" + String(c.stem || "未命名"))
  lines.push("标题：" + String(c.title || "未命名"))

  lines.push("")
  lines.push("当前题面：")
  lines.push(statement)
  lines.push("")
  lines.push("当前测试用例（input → expect）：")
  lines.push(caseLines)
  lines.push("")
  lines.push("要求：")
  lines.push(rules.join("\n"))
  lines.push("")
```

**2.5 新增 `buildSkeleton`**（放在 `buildGenerated` 之后）：

```javascript
/**
 * 四件套的解析结果 → 骨架。
 * 哪些件是必填由 need 决定（形态 B/C 的题面与用例来自题库，不让模型给）。
 * @param {object} obj
 * @param {string[]} need
 * @returns {object}
 */
function buildSkeleton(obj, need) {
  const want = Array.isArray(need) && need.length ? need : SKELETON_NEEDS.A
  const out = {}
  if (want.indexOf("statement") !== -1) {
    const statement = String(obj.statement || "").trim()
    if (statement === "") return { ok: false, reason: "生成结果缺题面" }
    out.statement = statement
  }
  if (want.indexOf("cases") !== -1) {
    const cases = normalizeCaseList(obj.cases)
    if (cases.length === 0) return { ok: false, reason: "生成结果缺测试用例" }
    out.cases = cases
  }
  if (want.indexOf("solution") !== -1) {
    const solution = String(obj.solution || "").trim()
    if (solution === "") return { ok: false, reason: "生成结果缺参考解法" }
    out.solution = solution
  }
  if (want.indexOf("negative") !== -1) {
    const negative = String(obj.negative || "").trim()
    if (negative === "") return { ok: false, reason: "生成结果缺负例" }
    out.negative = negative
  }
  out.title = String(obj.title || "").trim()
  out.difficulty = DIFFICULTIES.indexOf(String(obj.difficulty)) !== -1 ? String(obj.difficulty) : "medium"
  out.topics = topicText(obj.topics) === "未标注" ? [] : normalizeTopics(obj.topics)
```

```javascript
/**
 * 解析模型回复。
 * @param {string} text
 * @param {"explain"|"hint"|"grade-idea"|"generate"|"fill"} kind
 * @param {object} [opts] 可选；generate 的 skeleton 模式用 {mode:"skeleton", need:[...]}
 * @returns {object} 成功时带 ok:true；失败时带 ok:false 与中文 reason
 */
function parseResponse(text, kind, opts) {
  const raw = text === null || text === undefined ? "" : String(text).trim()
  const context = opts || {}
  // ……explain / hint / grade-idea / fill 分支原样不动……

  if (kind === "generate") {
    const obj = extractJson(raw)
    if (!obj) {
      return { ok: false, kind: kind, reason: "模型返回的不是合法 JSON，无法生成题目", raw: raw }
    }
    if (context.mode === "skeleton") {
      const built = buildSkeleton(obj, context.need)
      if (!built.ok) return { ok: false, kind: kind, reason: built.reason, raw: raw }
      return { ok: true, kind: kind, problem: built.problem }
    }
    const built = buildGenerated(obj)
    if (!built.ok) return { ok: false, kind: kind, reason: built.reason, raw: raw }
    return { ok: true, kind: kind, problem: built.problem }
  }
```

## Task 4: 校验侧（`core/supply/algorithm-verify.js`）

这一步是 P5 的**命门**：**每一份产物都要真的 `g++` 编译、真的执行**。

- 参考解法 × **全部**用例 → 必须 `verdict === "pass"`（P5-8）；
- 负例 × **同一批**用例 → 必须 `verdict ∈ {wrong_answer, runtime_error, timeout}`（P5-4 / P5-9）；
- 负例**全过**也算失败——那是「假判题器」的信号。

**不许用字符串比对冒充执行**（P5-7）：本模块直接调消费侧那一套 `judge/runner.js` 的 `judge()` 与 `judge/sandbox.js` 的沙箱。供给侧与消费侧共用一个可信判读机制（设计 §6.3）。

**执行环境**：G18 要求一切执行都在 `os.tmpdir()` 下的临时目录里跑，**禁止**在 learning 仓工作树里产生任何文件——`judge()` 自带的沙箱满足这条；本模块**只读** learning 仓，只写单元 md 的 `status` 一行。

**Files:**
- Create: `projects/apps/study-hub/core/supply/algorithm-verify.js`
- Create: `projects/apps/study-hub/tests/supply-algorithm-verify.test.js`

**Interfaces:**
- Consumes：
  - `judge/runner.js` 的 `judge({problem, code, language, timeoutMs, toolchain})`（**只读不改**）
  - `judge/sandbox.js` 的 `resolveToolchain`（**只读不改**）
  - `core/bank/parse.js` 的 `parseFrontmatter` / `splitSections` / `parseCases`
  - `core/supply/algorithm-fill.js` 的 `canonicalCode` / `patchStatusLine`
- Produces：
  - `verifyAlgorithmUnit(params) -> Promise<result>`，`result` = `{ok, status:"verified"|"rejected", reason, checks[], reference, negative}`
  - `verifyAlgorithmUnits(params) -> Promise<summary>`，`summary` = `{checked, verified, rejected, results[]}`（并把 `status` 写回单元 md 的那一行）
  - 常量 `NEGATIVE_REJECTED_VERDICTS`

创建 `projects/apps/study-hub/core/supply/algorithm-verify.js`：

```javascript
"use strict"
/**
 * algorithm-verify.js —— 算法轨校验侧：真实编译执行
 *
 * 复用**消费侧同一套**执行器（judge/runner.js 的 judge() + judge/sandbox.js 的沙箱），
 * 不许用字符串比对冒充执行（P5-7）。
 *
 * 判定顺序（契约 §10.1 冻结）：
 *   1. 参考解法 × 全部用例 → verdict 必须是 pass
 *   2. 负例 × 同一批用例     → verdict 必须在 {wrong_answer, runtime_error, timeout} 里
 *   3. 负例 pass           → 不算被拒（用例太弱，挡不住错解）
 *   4. 负例 compile_error  → 不算被拒（负例本身没写对）
 *
 * 单元级结论词只有 verified / rejected；pass / wrong_answer / timeout /
 * compile_error / runtime_error 是**单次执行**的结论（G20 的五类，不增不改）。
 *
 * 本模块**只读** learning 仓；唯一的写动作是把单元 md 的 status 改一行（G15 / P5-10）。
 */

const fs = require("node:fs")
const path = require("node:path")

const { judge } = require("../../judge/runner.js")
const { resolveToolchain } = require("../../judge/sandbox.js")
const { parseFrontmatter, splitSections, parseCases } = require("../bank/parse.js")
const { canonicalCode, patchStatusLine } = require("./algorithm-fill.js")

/** 负例「被拒」的三种 verdict（契约 §10.1 冻结） */
const NEGATIVE_REJECTED_VERDICTS = ["wrong_answer", "runtime_error", "timeout"]

/** 单元文件的小节名 */
const SECTION_CASES = "测试用例"
const SECTION_SOLUTION = "参考解法"

/**
 * 读单元文件：frontmatter + 正文小节。
 * @param {string} unitPath
 * @returns {{fm: object, body: string, sections: object, text: string}}
 */
function readUnitFile(unitPath) {
  const text = fs.readFileSync(unitPath, "utf8")
  const src = text.replace(/\r\n/g, "\n")
  const fmMatch = /^---\n([\s\S]*?)\n---\n?/.exec(src)
  if (!fmMatch) throw new Error("单元文件缺少 frontmatter：" + path.basename(unitPath))
  const fm = parseFrontmatter(fmMatch[1])
  const body = src.slice(fmMatch[0].length)
  return { fm: fm, body: body, sections: splitSections(body), text: text }
}

/**
 * 从正文里抠出 `## 参考解法` 的代码块（归一后）。
 * @param {object} sections
 * @returns {string}
 */
function solutionBlockOf(sections) {
  const raw = String((sections && sections[SECTION_SOLUTION]) || "")
  const fence = /```([A-Za-z0-9+#_-]*)\n([\s\S]*?)```/.exec(raw)
  return fence ? canonicalCode(fence[2]) : ""
}

/** 把 judge() 的返回值压成要记进账的形状 */
function summarize(result) {
  const r = result || {}
  return {
    verdict: String(r.verdict || ""),
    passedCases: Number(r.passedCases || 0),
    totalCases: Number(r.totalCases || 0),
    message: String(r.message || ""),
    compilerOutput: String(r.compilerOutput || ""),
    failedCase: r.failedCase || null,
  }
}

/**
 * 校验一个算法单元。
 *
 * @param {{unitPath: string, learningRoot: string, toolchain?: object, timeoutMs?: number}} params
 * @returns {Promise<{ok: boolean, status: string, reason: string, checks: Array, reference: object|null, negative: object|null}>}
 */
async function verifyAlgorithmUnit(params) {
  const p = params || {}
  const checks = []
  const unitPath = String(p.unitPath || "")
  const learningRoot = String(p.learningRoot || "")

  /** 结构层面的不合格：直接判 rejected */
  function reject(reason, name, detail) {
    checks.push({ name: name, ok: false, detail: detail || reason })
    return {
      ok: false,
      status: "rejected",
      reason: reason,
      checks: checks,
      reference: null,
      negative: null,
    }
  }

  if (!unitPath) return reject("没给单元文件路径", "单元文件", "没给单元文件路径")

  let parsed
  try {
    parsed = readUnitFile(unitPath)
  } catch (err) {
    return reject(err.message, "单元文件", err.message)
  }

  const fm = parsed.fm
  const referenceRel = String(fm.reference || "")
  const negativeRel = String(fm.negative || "")

  if (!referenceRel) return reject("单元没有 reference 路径，判不了", "参考解法路径", "frontmatter 里没有 reference")
  if (!negativeRel) return reject("单元没有负例文件路径，不合格", "负例路径", "frontmatter 里没有 negative")

  const referenceAbs = path.resolve(learningRoot, referenceRel)
  const negativeAbs = path.resolve(learningRoot, negativeRel)
  if (!fs.existsSync(referenceAbs)) {
    return reject("参考解法文件不存在：" + referenceRel, "参考解法文件", referenceRel)
  }
  if (!fs.existsSync(negativeAbs)) {
    return reject("负例文件不存在：" + negativeRel, "负例文件", negativeRel)
  }

  const referenceCode = fs.readFileSync(referenceAbs, "utf8")
  const negativeCode = fs.readFileSync(negativeAbs, "utf8")

  if (!/\bmain\s*\(/.test(referenceCode)) {
    return reject("参考解法没有 main 函数，不是完整的 stdin→stdout 程序", "参考解法结构", "找不到 main(")
  }
  if (!/\bmain\s*\(/.test(negativeCode)) {
    return reject("负例没有 main 函数", "负例结构", "找不到 main(")
  }
  if (canonicalCode(referenceCode) === canonicalCode(negativeCode)) {
    return reject("负例与参考解法完全相同，等于没测", "负例与解法", "两份代码逐字节相同")
  }

  const block = solutionBlockOf(parsed.sections)
  if (block === "") {
    return reject("单元文件的「## 参考解法」小节是空的", "参考解法代码块", "小节里没有代码块")
  }
  if (block !== canonicalCode(referenceCode)) {
    return reject("参考解法文件与单元文件里的代码块不一致", "参考解法双份一致", "md 代码块与 .reference.cpp 不一致")
  }

  const cases = parseCases(parsed.sections[SECTION_CASES] || "")
  if (cases.length === 0) {
    return reject("单元没有测试用例，判不了", "测试用例", "「## 测试用例」小节里没有数据行")
  }

  const toolchain = p.toolchain || resolveToolchain({})

  // —— 1) 参考解法 × 全部用例 ——
  const refResult = await judge({
    problem: { cases: cases },
    code: referenceCode,
    language: "cpp",
    timeoutMs: p.timeoutMs,
    toolchain: toolchain,
  })
  checks.push({
    name: "参考解法全用例通过",
    ok: refResult.verdict === "pass",
    detail: refResult.verdict + "：" + refResult.message,
  })
  if (refResult.verdict !== "pass") {
    return {
      ok: false,
      status: "rejected",
      reason: "参考解法没有全部通过（" + refResult.verdict + "）：" + refResult.message,
      checks: checks,
      reference: summarize(refResult),
      negative: null,
    }
  }

  // —— 2) 负例 × 同一批用例 ——
  const negResult = await judge({
    problem: { cases: cases },
    code: negativeCode,
    language: "cpp",
    timeoutMs: p.timeoutMs,
    toolchain: toolchain,
  })
  checks.push({
    name: "负例被拒绝",
    ok: NEGATIVE_REJECTED_VERDICTS.indexOf(negResult.verdict) !== -1,
    detail: negResult.verdict + "：" + negResult.message,
  })
  if (negResult.verdict === "pass") {
    return {
      ok: false,
      status: "rejected",
      reason: "负例竟然全部通过，说明测试用例太弱，挡不住错解",
      checks: checks,
      reference: summarize(refResult),
      negative: summarize(negResult),
    }
  }
  if (negResult.verdict === "compile_error") {
    return {
      ok: false,
      status: "rejected",
      reason: "负例编译失败，负例本身无效",
      checks: checks,
      reference: summarize(refResult),
      negative: summarize(negResult),
    }
  }
  if (NEGATIVE_REJECTED_VERDICTS.indexOf(negResult.verdict) === -1) {
    return {
      ok: false,
      status: "rejected",
      reason: "负例的结论无法判定：" + negResult.verdict,
      checks: checks,
      reference: summarize(refResult),
      negative: summarize(negResult),
    }
  }

  return {
    ok: true,
    status: "verified",
    reason: "负例被拒绝（" + negResult.verdict + "）",
    checks: checks,
    reference: summarize(refResult),
    negative: summarize(negResult),
  }
}

/**
 * 批量校验 units/algorithm/ 下的全部单元，并把 status 写回单元 md 的那一行。
 *
 * @param {{unitsDir: string, learningRoot: string, toolchain?: object, timeoutMs?: number, write?: boolean}} params
 * @returns {Promise<{checked: number, verified: number, rejected: number, results: Array}>}
 */
async function verifyAlgorithmUnits(params) {
  const o = params || {}
  const unitsDir = String(o.unitsDir || "")
  const summary = { checked: 0, verified: 0, rejected: 0, results: [] }
  let names = []
  try {
    names = fs
      .readdirSync(unitsDir)
      .filter(function (name) {
        return /\.md$/i.test(name)
      })
      .sort()
  } catch (err) {
    return summary
  }
  for (let i = 0; i < names.length; i += 1) {
    const unitPath = path.join(unitsDir, names[i])
    const res = await verifyAlgorithmUnit({
      unitPath: unitPath,
      learningRoot: String(o.learningRoot || ""),
      toolchain: o.toolchain,
      timeoutMs: o.timeoutMs,
    })
    summary.checked += 1
    if (res.status === "verified") summary.verified += 1
    else summary.rejected += 1
    summary.results.push({
      unit: "algo:" + names[i].replace(/\.md$/i, ""),
      status: res.status,
      reason: res.reason,
    })
    if (o.write !== false) {
      const text = fs.readFileSync(unitPath, "utf8")
      fs.writeFileSync(unitPath, patchStatusLine(text, res.status), "utf8")
    }
  }
  return summary
}
```

```javascript
  const raw = store.getSetting(key, String(fallback))
  const value = Number(raw)
  if (!Number.isFinite(value) || value < 0) return fallback
  return value
}

/** 参数优先，其次 settings，最后默认值 */
function pickNumber(value, store, key, fallback) {
  if (value === undefined || value === null || value === "") {
    return readNumberSetting(store, key, fallback)
  }
  const n = Number(value)
  if (!Number.isFinite(n) || n < 0) return fallback
  return n
}

/**

}

/**
 * 算本轮要处理哪些题（**不调 LLM、不写盘**）。
 *
 * P4 的 `core/supply/plan.js` 用它取 `stats` 做算法轨缺口计数（耦合面第 2 处）。
 *
 * @param {{items?: Array, store: object, resume?: boolean, retryRejected?: boolean, limit?: number|null}} params
 * @returns {{items: Array, planned: Array, skipped: Array, stats: object, warnings: string[]}}
 */
function planBatch(params) {
  const o = params || {}
  const items = Array.isArray(o.items) ? o.items : []
  const store = o.store
  const resume = o.resume === true
  const retryRejected = o.retryRejected === true
  // units：{stem: status}，磁盘上 units/algorithm/ 下**已经有的**单元状态。
  // 存量题库是只读的，所以「这道题补过没有」只能看这里（P5-1 / P5-11）。
  const units = o.units && typeof o.units === "object" ? o.units : {}
  const planned = []
  const skipped = []

  items.forEach(function (item) {
    if (item.shape === "ready") {
      skipped.push({ stem: item.stem, why: "已齐备，不动" })
      return
    }
    // 磁盘上已经有 verified 的单元 → 不重复花钱（不管有没有 --resume）
    if (units[item.stem] === "verified") {
      skipped.push({ stem: item.stem, why: "已经有 verified 的单元" })
      return
    }
    if (units[item.stem] === "rejected" && !retryRejected) {
      skipped.push({ stem: item.stem, why: "已有 rejected 的单元（要 --retry-rejected 才重做）" })
      return
    }
    const state = readItemState(store, item.stem)
    if (resume) {
      if (state.state === "verified") {
        skipped.push({ stem: item.stem, why: "已 verified" })
        return
      }
      if (state.state === "rejected" && !retryRejected) {
        skipped.push({ stem: item.stem, why: "已 rejected（要 --retry-rejected 才重做）" })
        return
      }
    }
    planned.push(item)
  })

  const limit = o.limit === undefined || o.limit === null ? null : Number(o.limit)
  const limited = limit !== null && Number.isFinite(limit) && limit > 0 ? planned.slice(0, limit) : planned

  return { items: items, planned: limited, skipped: skipped, stats: buildStats(items), warnings: [] }
}

/** 默认的等待 */
function defaultSleep(ms) {
  return new Promise(function (resolve) {
    setTimeout(resolve, ms)
  })
}

/**
 * 跑一批。
 *
 * @param {{
 *   items: Array, client: object, store: object,
 *   batchId?: string, learningRoot: string, unitsDir: string,
 *   dryRun?: boolean, resume?: boolean, retryRejected?: boolean, limit?: number|null,
 *   maxRetries?: number|null, sessionLimit?: number|null, dailyLimit?: number|null, rateMs?: number|null,
 *   now?: Function, clock?: Function, sleep?: Function, onProgress?: Function, gitRunner?: Function
 * }} params
 * @returns {Promise<object>} 批次汇总（持久化时只取契约 §5 的 12 个字段）
 */
async function runBatch(params) {
  const o = params || {}
  const store = o.store
  const now = typeof o.now === "function" ? o.now : function () {
    return new Date()
  }
  const clock = typeof o.clock === "function" ? o.clock : Date.now
  const sleep = typeof o.sleep === "function" ? o.sleep : defaultSleep
  const onProgress = typeof o.onProgress === "function" ? o.onProgress : function () {}

  const batchId = String(o.batchId || makeBatchId(now()))
  const maxRetries = pickNumber(o.maxRetries, store, SETTING_KEYS.maxRetries, 2)
  const sessionLimit = pickNumber(o.sessionLimit, store, SETTING_KEYS.sessionLimit, 800)
  const dailyLimit = pickNumber(o.dailyLimit, store, SETTING_KEYS.dailyLimit, 800)
  const rateMs = pickNumber(o.rateMs, store, SETTING_KEYS.rateMs, 1200)

  const plan = planBatch({
    items: o.items,
    store: store,
    resume: o.resume === true,
    retryRejected: o.retryRejected === true,
    limit: o.limit,
    // 磁盘上已经有的单元：verified 的不再花钱，rejected 的要 --retry-rejected 才重做
    units: readUnitStatuses(o.unitsDir),
  })

  const summary = {
    batchId: batchId,
    track: "algorithm",
    planned: plan.planned.length,
    done: 0,
    verified: 0,
    rejected: 0,
    failed: 0,
    skipped: plan.skipped.length,
    llmCalls: 0,
    stopped: false,
    startedAt: now().toISOString(),
    updatedAt: now().toISOString(),
    // —— reason 不落 settings（契约 §5 的 12 个字段里没有它），只给调用方看 ——
    reason: "",
  }

  // —— dry-run：只算计划，不调 LLM、不写文件 ——
  if (o.dryRun === true) {
    writeRunSummary(store, summary)
    return summary
  }

  // —— 写回前查脏（G14 / P5-3）——
  const clean = checkLearningClean({
    learningRoot: String(o.learningRoot || ""),
    gitRunner: o.gitRunner,
  })
  if (!clean.ok) {
    summary.stopped = true
    summary.reason = clean.reason
    summary.updatedAt = now().toISOString()
    writeRunSummary(store, summary)
    return summary
  }

  const sessionCountKey = SETTING_KEYS.callsSessionPrefix + batchId
  const dailyCountKey = SETTING_KEYS.callsDailyPrefix + dateKey(now())
  let sessionUsed = readNumberSetting(store, sessionCountKey, 0)
  let dailyUsed = readNumberSetting(store, dailyCountKey, 0)
  let lastCallStamp = 0
  const attemptsLimit = 1 + maxRetries

  for (let i = 0; i < plan.planned.length; i += 1) {
    const item = plan.planned[i]
    let attempts = 0
    let lastReason = ""
    let lastOutcome = "failed"
    let budgetStopped = false

    while (attempts < attemptsLimit) {
      attempts += 1

      // —— 预算检查（P5-12）：到顶就停，绝不烧穿 ——
      if (sessionUsed >= sessionLimit || dailyUsed >= dailyLimit) {
        budgetStopped = true
        summary.stopped = true
        summary.reason =
          (sessionUsed >= sessionLimit
            ? "达到单批次调用上限（" + sessionLimit + "）"
            : "达到当日调用上限（" + dailyLimit + "）") +
          "，还欠 " +
          (plan.planned.length - i) +
          " 个"
        break
      }

      // —— 限速：两次调用之间的最小间隔 ——
      if (lastCallStamp > 0) {
        const wait = rateMs - (clock() - lastCallStamp)
        if (wait > 0) await sleep(wait)
      }

      const prompt = buildPrompt("generate", {
        mode: "skeleton",
        shape: item.shape,
        stem: item.stem,
        title: item.title,
        difficulty: item.difficulty,
        topics: item.topics,
        url: item.url,
        statement: item.statement,
        cases: item.cases,
      })

      let raw = ""
      try {
        raw = await o.client.complete({ system: prompt.system, user: prompt.user, temperature: 0.6 })
      } catch (err) {
        raw = ""
        lastReason = "调 LLM 失败：" + (err && err.message ? err.message : String(err))
      }
      lastCallStamp = clock()
      sessionUsed += 1
      dailyUsed += 1
      summary.llmCalls += 1
      store.setSetting(sessionCountKey, String(sessionUsed))
      store.setSetting(dailyCountKey, String(dailyUsed))

      if (!raw) {
        lastOutcome = "failed"
        continue
      }

      const parsed = parseResponse(raw, "generate", {
        mode: "skeleton",
        need: SKELETON_NEEDS[item.shape] || SKELETON_NEEDS.A,
      })
      if (!parsed.ok) {
        lastReason = parsed.reason
        lastOutcome = "failed"
        continue
      }

      const draft = {
        stem: item.stem,
        title: item.title,
        difficulty: item.difficulty,
        topics: item.topics,
        subtracks: item.subtracks,
        source: item.source,
        unitSource: item.unitSource,
        sourceId: item.sourceId,
        url: item.url,
        originPath: item.sourcePath,
        // 题面与用例：**题库有的原样保留，缺的才用模型给的**（P5 的边界）
        statement: item.hasStatement ? item.statement : parsed.problem.statement,
        cases: item.hasCases ? item.cases : parsed.problem.cases,
        solution: parsed.problem.solution,
        negative: parsed.problem.negative,
        negativeNote: parsed.problem.negativeNote,
        status: "draft",
      }

      // —— 结构自检：main 函数、负例不能与解法相同 ——
      if (!/\bmain\s*\(/.test(draft.solution)) {
        lastReason = "参考解法里没有 main 函数"
        lastOutcome = "failed"
        continue
      }
      if (!/\bmain\s*\(/.test(draft.negative)) {
        lastReason = "负例里没有 main 函数"
        lastOutcome = "failed"
        continue
      }
      if (canonicalCode(draft.solution) === canonicalCode(draft.negative)) {
        lastReason = "负例与参考解法完全相同"
        lastOutcome = "failed"
        continue
      }

      // —— 落盘三件套（先落 draft）——
      writeTriplet({ unitsDir: String(o.unitsDir || ""), stem: item.stem, draft: draft })

      // —— 真编译真执行（P5-7）——
      const verdict = await verifyAlgorithmUnit({
        unitPath: path.join(String(o.unitsDir || ""), item.stem + ".md"),
        learningRoot: String(o.learningRoot || ""),
      })

      // —— 只改 status 那一行（P5-10 / G15）——
      const mdPath = path.join(String(o.unitsDir || ""), item.stem + ".md")
      fs.writeFileSync(mdPath, patchStatusLine(fs.readFileSync(mdPath, "utf8"), verdict.status), "utf8")

      if (verdict.ok) {
        lastOutcome = "verified"
        lastReason = verdict.reason
        break
      }
      lastOutcome = "rejected"
      lastReason = verdict.reason
      // 校验不合格：还有次数就换一次再试
    }

    if (budgetStopped) break

    summary.done += 1
    if (lastOutcome === "verified") summary.verified += 1
    else if (lastOutcome === "rejected") summary.rejected += 1
    else summary.failed += 1

    writeItemState(store, item.stem, lastOutcome, attempts, lastReason, now().toISOString())
    summary.updatedAt = now().toISOString()
    writeRunSummary(store, summary)
    onProgress({
      stem: item.stem,
      state: lastOutcome,
      reason: lastReason,
      index: i + 1,
      total: plan.planned.length,
    })
  }

  summary.updatedAt = now().toISOString()
  writeRunSummary(store, summary)
  return summary
}

function buildCoverageReport(params) {
  const o = params || {}
  const items = Array.isArray(o.items) ? o.items : []
  const stats = buildStats(items)
  // units：{stem: status}，来自 algorithm-fill.js 的 readUnitStatuses(unitsDir)。

  const units = o.units && typeof o.units === "object" ? o.units : {}
  const debts = items.filter(function (item) {
    if (item.shape === "ready") return false
    return units[item.stem] !== "verified"
  })
  const filled = items.filter(function (item) {
    if (item.shape === "ready") return false
    return units[item.stem] === "verified"
  })
  const missing = { statement: 0, cases: 0, solution: 0 }
  const debtBySource = {}
  const debtByDifficulty = {}
  const debtBySubtrack = {}
  const debtByTopic = {}

  debts.forEach(function (item) {
    item.missing.forEach(function (m) {
      missing[m] += 1
    })
    debtBySource[item.source] = (debtBySource[item.source] || 0) + 1
    debtByDifficulty[item.difficulty] = (debtByDifficulty[item.difficulty] || 0) + 1
    item.subtracks.forEach(function (t) {
      debtBySubtrack[t] = (debtBySubtrack[t] || 0) + 1
    })
    const topic = item.topics.length ? item.topics[0] : "未标注"
    debtByTopic[topic] = (debtByTopic[topic] || 0) + 1
  })

  const run = o.store && o.batchId ? readRunSummary(o.store, o.batchId) : null

  return {
    total: items.length,
    // 题库里本来就齐的（形态 ready）
    bankReady: stats.byShape.ready,
    // 本计划已经补出来的（units/algorithm/ 下 status 是 verified）
    filled: filled.length,
    // 不再欠的总数
    ready: stats.byShape.ready + filled.length,
    debt: debts.length,
    byShape: stats.byShape,
    bySource: stats.bySource,
    byDifficulty: stats.byDifficulty,
    bySubtrack: stats.bySubtrack,
    byTopic: stats.byTopic,
    missing: missing,
    debtBySource: debtBySource,
    debtByDifficulty: debtByDifficulty,
    debtBySubtrack: debtBySubtrack,
    debtByTopic: debtByTopic,
    run: run,
  }
}

/** 计数表排成「k v」的顿号串 */
function formatCounts(counts) {
  const keys = Object.keys(counts || {})
  if (keys.length === 0) return "无"
  keys.sort(function (a, b) {
    return counts[b] - counts[a]
  })
  return keys
    .map(function (k) {
      return k + " " + counts[k]
    })
    .join("、")
}

/** 取计数表的前 n 项 */
function topCounts(counts, n) {
  const out = {}
  const keys = Object.keys(counts || {}).sort(function (a, b) {
    return counts[b] - counts[a]
  })
  keys.slice(0, n).forEach(function (k) {
    out[k] = counts[k]
  })
  return out
}
```

```javascript
/**
 * 解析算法轨的命令行参数。
 *
 * @param {string[]} argv
 * @returns {{options: object, error: string}}
 */
function parseAlgorithmArgs(argv) {
  const args = Array.isArray(argv) ? argv.slice() : []
  const options = {
    command: "",
    track: "",
    batch: false,
    limit: null,
    resume: false,
    retryRejected: false,
    dryRun: false,
    session: "",
    unit: "",
  }
  let error = ""
  let i = 0
  while (i < args.length && error === "") {
    const arg = String(args[i])
    if (arg === "--batch") {
      options.batch = true
      i += 1
      continue
    }
    if (arg === "--resume") {
      options.resume = true
      i += 1
      continue
    }
    if (arg === "--retry-rejected") {
      options.retryRejected = true
      i += 1
      continue
    }

      options.dryRun = true
      i += 1
      continue
    }
    if (arg === "--track" || arg === "--limit" || arg === "--session" || arg === "--unit") {
      if (i + 1 >= args.length) {
        error = "选项 " + arg + " 后面缺值"
        break

      if (arg === "--limit") {

          options.session = value
        }
      }
      if (arg === "--unit") options.unit = value
      i += 2
      continue
    }
    if (arg.charAt(0) === "-") {
      error = "不认识的选项：" + arg
      break
    }
    if (options.command === "") {
      options.command = arg
      i += 1
      continue
    }
    error = "多了一个位置参数：" + arg
  }
  return { options: options, error: error }
}

 *   learningRoot?: string, localBank?: string, gitRunner?: Function, write?: Function
 * }} params
 * @returns {Promise<{code: number, output: string}>}
 */
async function runAlgorithmCommand(params) {
  const o = params || {}
  const argv = Array.isArray(o.argv) ? o.argv : []
  const env = o.env || process.env
  const store = o.store
  const lines = []
  const say = function (text) {
    lines.push(String(text))
  }

  const parsed = parseAlgorithmArgs(argv)
  if (parsed.error) {
    say("参数错：" + parsed.error)
    say(USAGE)
    return { code: 1, output: lines.join("\n") }
  }
  const options = parsed.options
  if (COMMANDS.indexOf(options.command) === -1) {
    say("子命令非法：" + (options.command || "（空）") + "。算法轨只接 plan / generate / verify / report。")
    say(USAGE)
    return { code: 1, output: lines.join("\n") }
  }
  if (options.track && options.track !== "algorithm") {
    say("算法轨分支只接 --track algorithm，收到：" + options.track)
    return { code: 1, output: lines.join("\n") }
  }

  // —— learning 仓路径（G16：不硬编码，解析不到就降级不抛错）——
  const learning = resolveLearningRoot(env, o.learningRoot)
  if (!learning.ok) {
    say("解析不到 learning 仓：" + (learning.reason || "未知原因"))
    say("用环境变量 STUDY_HUB_LEARNING_ROOT 指到 learning 仓根目录。")
    return { code: 1, output: lines.join("\n") }
  }
  const learningRoot = learning.root
  const unitsDir = path.join(learningRoot, "units", "algorithm")
  const localBank = localBankDir(env, o.localBank)

  // ——— plan ———
  if (options.command === "plan") {
    const scan = fill.scanBank({ learningRoot: learningRoot, localBank: localBank })
    // 磁盘上已经补过的题不再算缺口（存量题库是只读的，缺口靠 units/algorithm/ 消）
    const units = fill.readUnitStatuses(unitsDir)
    const plan = batch.planBatch({ items: scan.items, store: store, limit: options.limit, units: units })
    say("算法轨缺口清单（共 " + plan.stats.total + " 题）：")
    plan.items.forEach(function (item) {
      if (item.shape === "ready") return
      if (units[item.stem] === "verified") return
      say("  " + item.stem + "  形态 " + item.shape + "  缺 " + item.missing.join("/") + "  来源 " + item.source)
    })
    say("待补 " + plan.planned.length + " 题；跳过 " + plan.skipped.length + " 题")
    const clean = fill.checkLearningClean({ learningRoot: learningRoot, gitRunner: o.gitRunner })
    if (clean.ok) {
      fs.mkdirSync(unitsDir, { recursive: true })
      const jsonPath = path.join(unitsDir, "plan.json")
      fs.writeFileSync(
        jsonPath,
        JSON.stringify(
          {
            track: "algorithm",
            total: plan.stats.total,
            planned: plan.planned.length,
            skipped: plan.skipped.length,
            byShape: plan.stats.byShape,
            missing: plan.stats.missing,
            items: plan.items.map(function (item) {
              return {
                stem: item.stem,
                shape: item.shape,
                missing: item.missing,
                source: item.source,
                difficulty: item.difficulty,
                subtracks: item.subtracks,
                topics: item.topics,
                originPath: item.sourcePath,
              }
            }),
          },
          null,
          2
        ),
        "utf8"
      )
      say("缺口清单已写入：" + jsonPath)
    } else {
      say("没写 plan.json（learning 仓有未提交改动）：" + clean.reason)
    }
    return { code: 0, output: lines.join("\n") }
  }

  // ——— generate ———
  if (options.command === "generate") {
    const client = o.client
    if (!client || typeof client.complete !== "function" || client.name === "null") {
      say("【LLM 未启用】批量补题需要 LLM 才能生成内容。")
      say("请配置环境变量 ARK_API_KEY 或 ANTHROPIC_API_KEY 后重试。")
      say("App 的其余功能（排程、判题、复习、进度）不受影响。")
      return { code: 2, output: lines.join("\n") }
    }
    const scan = fill.scanBank({ learningRoot: learningRoot, localBank: localBank })
    const batchId = options.session || batch.makeBatchId(new Date())
    const summary = await batch.runBatch({
      items: scan.items,
      client: client,
      store: store,
      batchId: batchId,
      learningRoot: learningRoot,
      unitsDir: unitsDir,
      dryRun: options.dryRun,
      resume: options.resume,
      retryRejected: options.retryRejected,
      limit: options.limit,
      gitRunner: o.gitRunner,
      onProgress: function (p) {
        say("  " + p.stem + "  " + p.state + "（" + p.index + "/" + p.total + "）" + (p.reason ? "  " + p.reason : ""))
      },
    })
    say("批次 " + summary.batchId + "：计划 " + summary.planned + " 题，做了 " + summary.done + " 题")
    say("  通过 " + summary.verified + "，被拒 " + summary.rejected + "，失败 " + summary.failed + "，跳过 " + summary.skipped)
    say("  LLM 调用 " + summary.llmCalls + " 次")
    if (summary.stopped) {
      say(summary.reason + "。用 --resume 接着跑。")
    }
    return { code: 0, output: lines.join("\n") }
  }

  // ——— verify ———
  if (options.command === "verify") {
    if (options.unit) {
      const stem = options.unit.indexOf("algo:") === 0 ? options.unit.slice(5) : options.unit
      const unitPath = path.join(unitsDir, stem + ".md")
      if (!fs.existsSync(unitPath)) {
        say("单元不存在：" + options.unit)
        return { code: 1, output: lines.join("\n") }
      }
      const res = await verifyAlgorithmUnit({ unitPath: unitPath, learningRoot: learningRoot })
      say(options.unit + " → " + res.status + "：" + res.reason)
      return { code: 0, output: lines.join("\n") }
    }
    const summary = await verifyAlgorithmUnits({ unitsDir: unitsDir, learningRoot: learningRoot })
    say("校验了 " + summary.checked + " 个单元：通过 " + summary.verified + "，被拒 " + summary.rejected)
    summary.results.forEach(function (r) {
      if (r.status === "verified") return
      say("  " + r.unit + "  " + r.status + "：" + r.reason)
    })
    return { code: 0, output: lines.join("\n") }
  }

  // ——— report ———
  const scan = fill.scanBank({ learningRoot: learningRoot, localBank: localBank })
  const report = batch.buildCoverageReport({
    items: scan.items,
    store: store,
    batchId: options.session,
    units: fill.readUnitStatuses(unitsDir),
  })
  say(batch.renderCoverageReport(report))
  return { code: 0, output: lines.join("\n") }
}

module.exports = {
  COMMANDS: COMMANDS,
  USAGE: USAGE,
  parseAlgorithmArgs: parseAlgorithmArgs,
  runAlgorithmCommand: runAlgorithmCommand,
}
```

## Task 6: 覆盖报告 + `core/supply/plan.js` 的算法轨缺口计数

覆盖报告回答一个问题：**还欠什么**。

- 按**知识点**分组；
- 缺题面 / 缺用例 / 缺参考解法，各多少；

```javascript
  lines.push("source: " + (o.source || "leetcode"))
  lines.push("source_id: " + (o.sourceId || "7"))
  lines.push("title: " + (o.title || "反转字符串"))
  lines.push("difficulty: " + (o.difficulty || "easy"))
  lines.push("topics: [字符串]")
  lines.push("tracks: [" + (o.subtrack || "fundamentals") + "]")
  lines.push("status: todo")
  lines.push("needs_fill: true")
  lines.push("---")
  lines.push("")
  lines.push("## 题面")
  lines.push("")
  if (o.statement) lines.push(o.statement)
  lines.push("")
  lines.push("## 测试用例")
  lines.push("")
  lines.push("| input | expect |")
  lines.push("|---|---|")
  if (o.cases) {
    o.cases.forEach(function (c) {
      lines.push("| " + c.input + " | " + c.expect + " |")
    })
  }
  lines.push("")
  lines.push("## 参考解法")
  lines.push("")
  fs.writeFileSync(abs, lines.join("\n"), "utf8")
  return abs
}

/** 目录内容的 sha256 清单 */
function digestTree(dir) {
  const out = {}
  function walk(d) {
    if (!fs.existsSync(d)) return
    for (const name of fs.readdirSync(d)) {
      const p = path.join(d, name)
      if (fs.statSync(p).isDirectory()) walk(p)
      else out[path.relative(dir, p).split(path.sep).join("/")] = crypto
        .createHash("sha256")
        .update(fs.readFileSync(p))
        .digest("hex")
    }
  }
  walk(dir)
  return out
}
```
