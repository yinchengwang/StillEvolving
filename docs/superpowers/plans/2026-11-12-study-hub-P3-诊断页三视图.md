## 统计口径（P3 的核心决策，先定死再写代码）

这一节是 P3 全部数字的来源。**照抄执行，不许在实现时临时改口径。**

### 1. 单元级掌握度（公式一个字不许改）

```
首次通过率 = firstPass / attempts            ← 反复重试通过不算掌握
遗忘因子   = 0.5 ^ (距上次练习天数 / 14)      ← 半衰期 14 天
掌握度     = (0.7 × 首次通过率 + 0.3 × e^(-失误次数/2)) × 遗忘因子
```

- `attempts`：该**单元**的提交总次数。
- `firstPass`：该单元「第一次尝试就通过」的次数（最多 1）。
- `lapses`：该单元**没通过**的提交次数。
- `lastAt`：该单元最后一次提交的时间。
- 从没练过（`attempts === 0`）→ 掌握度 **0**。
- 出口统一走 `core/mastery/mastery.js` 的 `masteryOf`（契约 §6.5「口径统一」铁律）。P3 只加一个签名上换名的薄封装 `masteryOfUnit(unitId, stat, nowIso)`，**数值与 `masteryOf` 完全一致**。

### 2. 知识点级掌握度（`scope='topic'`）

```
知识点掌握度 = 该知识点下「练过的单元」的单元掌握度算术平均
知识点覆盖度 = 练过的单元数 / 期望题量
```

- 键：`<track>:<topic>`（P3-1）。
- **只统计练过的单元**（`attempts > 0`）。一个知识点下有 10 个单元、只练过 2 个 → 这 2 个的均值就是该知识点的掌握度；覆盖度负责说「还有 8 个没碰」。
- 期望题量三级口径不变（`expected.js` 的既有逻辑），键换成复合键：
  ① `insights.expected_override.<track>:<topic>` → ② 题库里带这个复合键的单元数 → ③ `insights.expected_min_questions`（默认 **5**）。取 `max(②, ③)`。旧的裸名覆盖键 `insights.expected_override.<topic>` 继续能读（P3-3）。
- 档位 = `diagnose(mastery, coverage)`，四档标签与处方文案沿用 `mastery.js` 的 `diagnoseLabel` / `diagnoseAction`。

### 3. 轨道级掌握度（`scope='track'`）

```
轨道掌握度 = 该轨「练过的单元」的单元掌握度算术平均
轨道覆盖度 = 练过的单元数 / 该轨单元总数
```

- 键：`algorithm` / `database` / `ai`（顶层轨代码）。
- 三轨用**同一套公式**（契约设计文档 §4.4「三轨用同一套公式——所以可比」），所以三轨的数值可以直接横向比。
- `unitCount` = 该轨**全部**已加载单元数（含没练过的）；覆盖度的分母就是它，分子是练过的单元数。

### 4. 六轴（契约 §8.3.1，一个字不改）

| 轴 id | 中文标签 | 定义 |
|---|---|---|
| `algorithm` | 算法 | 轨道级掌握度（`mastery` 表 `scope='track'`，`scope_id='algorithm'`） |
| `database` | 数据库 | 同上，`scope_id='database'` |
| `ai` | AI | 同上，`scope_id='ai'` |
| `c` | C/C++ | 算法轨里 `subtracks` 含 `engineering` **或** `entry.language === "cpp"` 的**练过的单元**掌握度均值 |
| `python` | Python | `entry.language === "python"` 的**练过的单元**掌握度均值 |
| `sql` | SQL | `topics` 里含 `"SQL"`（**大小写不敏感**）的**练过的单元**掌握度均值 |

- 六根轴**顺序固定**：`algorithm` → `database` → `ai` → `c` → `python` → `sql`。
- **没有数据的轴：`value = 0`，并且不出现在 `weak` 里。**
- 已知退化（P3-5）：loader A 的算法单元 `entry.language` 恒为 `"cpp"`，所以今天 `c` 轴 ≡ `algorithm` 轴。这是契约定义的行为，不许改口径去「凑好看」。

### 5. 弱项 / 强项清单

```
weak   = 练过（attempts > 0）且 mastery < 0.5 的单元，掌握度升序，unit_id 升序定序
strong = 练过（attempts > 0）且 mastery >= 0.5 的单元，掌握度降序，unit_id 升序定序
```

- 每项字段：`{ unit_id, track, title, mastery, topic }`（契约 §8.3.1 冻结）。
- `topic` = 该单元的第一个知识点；没有知识点（loader B 的卡恒为 `[]`）时是空串 `""`。
- **服务端返回完整清单**（不截断），前端只显示前 12 条——这样命令行里也能看到全量。

### 6. 期望题量（复合键）

三级口径（照抄 `core/mastery/expected.js` 的既有逻辑，只换键）：

| 优先级 | 来源 | 说明 |
|---|---|---|
| ① 覆盖值 | `insights.expected_override.<track>:<topic>` | 手工指定某轨某知识点的期望题量，存在且是正数就直接用 |
| ①' 兼容 | `insights.expected_override.<topic>` | 旧的裸名键，读不到 ① 时才用 |
| ② 题库单元数 | 带这个复合键的单元数 | 「这个知识点一共就这么多单元」 |
| ③ 下限常量 | `insights.expected_min_questions`，默认 **5** | 「至少要练够 5 个单元才叫练透」 |

**②③ 合成：`期望题量 = max(②, ③)`。** 来源标记仍是 `"override"` / `"bank"` / `"floor"` 三档。

### 7. 热力图

- **会话**：取最近 **20** 个会话（`store.listSessions(20)`），按 `started_at` **升序**排，`index` 从 **1** 开始。超过 20 个只留最近的 20 个。

### 8. 与旧 `/api/insights` 的口径差异（**重要，别混用**）

| | 旧 `/api/insights` 的知识点掌握度 | P3 的知识点 / 轨道掌握度 |
|---|---|---|
| 算法 | 把该知识点下所有题目的提交流水**合并**算一次 | 先算**每个单元**的掌握度，再取**均值** |
| 公式 | `masteryOf(合并统计量)` | `mean(masteryOf(每个单元的统计量))` |
| 覆盖度分子 | 练过的不同题目数 | 练过的**单元**数（同一个东西，只是改名） |

两者数值不同，**都对**，但不可混用：

- 旧接口的公式**一个字不改**（它照旧服务旧页面与旧测试）。
- P3 之所以选「均值」，是为了让三层口径自洽：轨道 = 它的单元的均值，知识点 = 它的单元的均值，而契约明写 `c` / `python` / `sql` 三轴是「**单元掌握度均值**」。如果轨道级用「合并流水」，就会出现「三轨轴是合并口径、`c` 轴是均值口径」的混搭，横向比较就说不清了。

```javascript
"use strict"
/**
 * expected.js —— 「期望题量」口径：覆盖度的分母
 *
 * 期望题量 = 这个知识点要练多少题，才算「练透」。
 *
 * 三级口径（自上而下）：
 *   ① settings 的 insights.expected_override.<track>:<topic> → 手工指定，直接用
 *      （旧的 insights.expected_override.<topic> 裸名键继续能读，作为兼容兜底）
 *   ② 题库里带这个复合键的单元数                        → 这个知识点一共就这么多单元
 *   ③ settings 的 insights.expected_min_questions（默认 5）→ 至少要练够这么多单元
 *
 * ②③ 合成：期望题量 = max(题库单元数, 下限常量)。
 * 下限存在的理由：题库里只有 1 个单元的冷门知识点，练 1 个就是 100% 覆盖，
 * 会被误判成「掌握」——下限把这个洞堵上。
 *
 * 复合键的形状是 `<track>:<topic>`，轨用**顶层轨代码**（algorithm / database / ai），
 * 不是单元 id 前缀（algo / db / ai）。见契约 §4.3 与本计划「统计口径」第 6 节。
 *
 * 退化：题库不可用（纯本地模式 / learning 仓没连 / bank 目录不存在）
 * 或这个 topic 只出现在流水里时，题库计数为 0 → 全部走下限，不抛错。
 */

const { trackOfIdPrefix } = require("../track/tracks.js")

/** 期望题量的默认下限（题） */
const DEFAULT_MIN_EXPECTED = 5

/** 下限常量的 settings 键 */
const SETTING_MIN = "insights.expected_min_questions"

/** 逐 topic 覆盖值的 settings 键前缀 */
const SETTING_OVERRIDE_PREFIX = "insights.expected_override."

/** 复合键的分隔符 */
const KEY_SEP = ":"

/** 裸知识点名默认归的顶层轨（历史数据全是算法轨） */
const DEFAULT_TRACK = "algorithm"

/**
 * 读下限常量。非法值退回默认 5。
 * @param {Object<string, string>} settings
 * @returns {number}
 */
function minExpectedFrom(settings) {
  const raw = (settings || {})[SETTING_MIN]
  if (raw === undefined || raw === null || String(raw).trim() === "") return DEFAULT_MIN_EXPECTED
  const value = Number(raw)
  if (!Number.isFinite(value) || value <= 0) return DEFAULT_MIN_EXPECTED
  return Math.floor(value)
}

/**
 * 拼复合键。
 * @param {string} track 顶层轨代码；空串按 algorithm
 * @param {string} topic 知识点名
 * @returns {string} "<track>:<topic>"；知识点为空返回 ""
 */
function topicKey(track, topic) {
  const name = String(topic === null || topic === undefined ? "" : topic).trim()
  if (name === "") return ""
  const code = String(track === null || track === undefined ? "" : track).trim()
  return (code === "" ? DEFAULT_TRACK : code) + KEY_SEP + name
}

/**
 * 拆复合键。裸名（没有分隔符）按算法轨处理。
 * @param {string} key
 * @returns {{track: string, topic: string}}
 */
function splitKey(key) {
  const raw = String(key === null || key === undefined ? "" : key)
  const index = raw.indexOf(KEY_SEP)
  if (index <= 0) return { track: DEFAULT_TRACK, topic: raw }
  return { track: raw.slice(0, index), topic: raw.slice(index + 1) }
}

/**
 * 由单元 id 的前缀推顶层轨。
 *   algo:xxx → algorithm；db:xxx → database；ai:xxx → ai
 *   没有前缀的老 id → algorithm
 * @param {string} unitId
 * @returns {string}
 */
function trackOfUnitId(unitId) {
  const raw = String(unitId === null || unitId === undefined ? "" : unitId).trim()
  if (raw === "") return DEFAULT_TRACK
  const index = raw.indexOf(KEY_SEP)
  if (index <= 0) return DEFAULT_TRACK
  const track = trackOfIdPrefix(raw.slice(0, index))
  return track && track.code ? String(track.code) : DEFAULT_TRACK
}

/**
 * 单元自己的轨：优先用 unit.track，没有就用 id 前缀推。
 * @param {{id?: string, track?: string}} unit
 * @returns {string}
 */
function trackOfUnit(unit) {
  const u = unit || {}
  const declared = String(u.track === null || u.track === undefined ? "" : u.track).trim()
  if (declared === "algorithm" || declared === "database" || declared === "ai") return declared
  return trackOfUnitId(u.id)
}

/**
 * 数出题库里每个 topic 有多少个单元。**键是复合键。**
 * @param {Array<{id: string, track?: string, topics: string[]}>} units
 * @returns {Object<string, number>}
 */
function bankTopicCounts(units) {
  const counts = {}
  ;(units || []).forEach(function (unit) {
    const track = trackOfUnit(unit)
    ;(unit.topics || []).forEach(function (topic) {
      const key = topicKey(track, topic)
      if (key === "") return
      counts[key] = (counts[key] || 0) + 1
    })
  })
  return counts
}

/**
 * 读一个覆盖值。正整数才算数，非法值当没写。
 * @param {Object<string, string>} settings
 * @param {string} name 覆盖值的名字（复合键或裸名）
 * @returns {number|null}
 */
function readOverride(settings, name) {
  const raw = (settings || {})[SETTING_OVERRIDE_PREFIX + name]
  if (raw === undefined || raw === null || String(raw).trim() === "") return null
  const value = Number(raw)
  if (!Number.isFinite(value) || value <= 0) return null
  return Math.floor(value)
}

/**
 * 题库计数：先查复合键，查不到再查裸名。
 * @param {Object<string, number>} bankCounts
 * @param {string} key 复合键
 * @param {string} bare 裸知识点名
 * @returns {number}
 */
function pickBankCount(bankCounts, key, bare) {
  const all = bankCounts || {}
  const composite = Number(all[key] || 0)
  if (Number.isFinite(composite) && composite > 0) return composite
  const legacy = Number(all[bare] || 0)
  return Number.isFinite(legacy) ? legacy : 0
}

/**
 * 算一个 topic 的期望题量。
 * @param {string} key 复合键 "<track>:<topic>"（裸名也认）
 * @param {Object<string, number>} bankCounts 键是复合键
 * @param {Object<string, string>} settings
 * @returns {{expected: number, source: "override"|"bank"|"floor"}}
 */
function expectedFor(key, bankCounts, settings) {
  const all = settings || {}
  const parts = splitKey(key)
  const bare = parts.topic

  // ① 覆盖值：复合键优先，裸名兜底
  const composite = readOverride(all, parts.track + KEY_SEP + bare)
  if (composite !== null) return { expected: composite, source: "override" }
  const legacy = readOverride(all, bare)
  if (legacy !== null) return { expected: legacy, source: "override" }

  // ②③ 题库单元数与下限取大
  const min = minExpectedFrom(all)
  const bank = pickBankCount(bankCounts, key, bare)
  const safeBank = Number.isFinite(bank) && bank > 0 ? Math.floor(bank) : 0
  if (safeBank >= min) return { expected: safeBank, source: "bank" }
  return { expected: min, source: "floor" }
}

/**
 * 给一批 topic 批量算期望题量。
 * @param {string[]} keys 复合键（裸名也认）
 * @param {Object<string, number>} bankCounts
 * @param {Object<string, string>} settings
 * @returns {Object<string, {expected: number, source: string}>}
 */
function buildExpectedMap(keys, bankCounts, settings) {
  const out = {}
  ;(keys || []).forEach(function (key) {
    const name = String(key)
    out[name] = expectedFor(name, bankCounts, settings)
  })
  return out
}

module.exports = {
  DEFAULT_MIN_EXPECTED: DEFAULT_MIN_EXPECTED,
  SETTING_MIN: SETTING_MIN,
  SETTING_OVERRIDE_PREFIX: SETTING_OVERRIDE_PREFIX,
  KEY_SEP: KEY_SEP,
  DEFAULT_TRACK: DEFAULT_TRACK,
  minExpectedFrom: minExpectedFrom,
  topicKey: topicKey,
  splitKey: splitKey,
  trackOfUnitId: trackOfUnitId,
  trackOfUnit: trackOfUnit,
  bankTopicCounts: bankTopicCounts,
  expectedFor: expectedFor,
  buildExpectedMap: buildExpectedMap,
}
```

```javascript
"use strict"
/**
 * track-mastery.js —— 跨轨掌握度三层聚合（P3 新建）
 *
 * 纯函数，无 IO。输入只有两样：**单元清单**（Unit[]）与**作答流水摘要**。
 * 输出三层掌握度、六根轴、弱强清单。数值口径见契约 §8.3.2。
 *
 * 三层：
 *   单元级   = mastery.js 的 masteryOf 公式（一个字不改）
 *   知识点级 = 该知识点下「练过的单元」的单元掌握度算术平均
 *   轨道级   = 该轨「练过的单元」的单元掌握度算术平均
 *
 * 为什么知识点与轨道都用「单元均值」而不是「合并流水」：
 * 契约 §8.3.1 明写 c / python / sql 三轴是「单元掌握度均值」，
 * 如果轨道级用合并流水，三轨轴与三根子轴就是两套口径，横向比较说不清。
 * 旧 /api/insights 仍用合并流水口径，那是另一条链路，两者不可混用。
 *
 * 「练过」的定义：掌握度 > 0（masteryOf 对 attempts=0 返回 0，
 * 所以掌握度为 0 的单元就是没练过的单元，不进任何均值）。
 */

const {
  MASTERY_THRESHOLD,
  masteryOfUnit,
  coverageOfUnits,
  diagnose,
  diagnoseLabel,
  diagnoseAction,
} = require("./mastery.js")
const { topicKey, trackOfUnit } = require("./expected.js")
const { TRACK_CODES, labelOf } = require("../track/tracks.js")

/**
 * 单元 id 归一：unit_id 优先，其次 problem_id；没有前缀的老 id 归算法轨。
 * @param {{unit_id?: string, problem_id?: string}} row
 * @returns {string} 归一后的单元 id；取不到返回 ""
 */
function unitIdOf(row) {
  const source = row || {}
  const raw = String(source.unit_id || source.problem_id || "").trim()
  if (raw === "") return ""
  if (raw.indexOf(":") === -1) return "algo:" + raw
  return raw
}

/**
 * 取一个单元的掌握度。没练过的（拿不到值或值为 0）返回 null。
 * @param {Object<string, number>} unitMastery
 * @param {string} unitId
 * @returns {number|null}
 */
function practicedValue(unitMastery, unitId) {
  const value = unitMastery ? unitMastery[unitId] : undefined
  if (typeof value !== "number" || !Number.isFinite(value) || value <= 0) return null
  return value
}

/**
 * 从作答流水派生单元级统计。
 * @param {Array<{id?: number, unit_id?: string, problem_id?: string, ts: string, verdict: string}>} attempts
 * @returns {Object<string, {attempts: number, firstPass: number, lapses: number, lastAt: string|null}>}
 */
function deriveUnitStats(attempts) {
  const groups = {}
  ;(attempts || []).forEach(function (row) {
    const id = unitIdOf(row)
    if (id === "") return
    if (!groups[id]) groups[id] = []
    groups[id].push(row)
  })

  const stats = {}
  Object.keys(groups).forEach(function (id) {
    // 按时间排序；时间相同按自增 id 排序——「第一次尝试」必须是真正的第一次
    const list = groups[id].slice().sort(function (a, b) {
      const ta = String(a.ts || "")
      const tb = String(b.ts || "")
      if (ta !== tb) return ta < tb ? -1 : 1
      return Number(a.id || 0) - Number(b.id || 0)
    })
    const stat = { attempts: list.length, firstPass: 0, lapses: 0, lastAt: null }
    list.forEach(function (row, index) {
      const passed = String(row.verdict || "") === "pass"
      if (index === 0 && passed) stat.firstPass = 1
      if (!passed) stat.lapses += 1
      const ts = String(row.ts || "")
      if (ts !== "") {
        const ms = Date.parse(ts)
        if (Number.isFinite(ms) && (stat.lastAt === null || ms > Date.parse(stat.lastAt))) {
          stat.lastAt = ts
        }
      }
    })
    stats[id] = stat
  })
  return stats
}

/**
 * 单元掌握度。没练过的单元不出现在结果里。
 * @param {Object<string, object>} unitStats
 * @param {string} nowIso
 * @returns {Object<string, number>}
 */
function computeUnitMastery(unitStats, nowIso) {
  const out = {}
  Object.keys(unitStats || {}).forEach(function (id) {
    const stat = unitStats[id]
    if (!stat || Number(stat.attempts || 0) <= 0) return
    out[id] = masteryOfUnit(id, stat, nowIso)
  })
  return out
}

/**
 * 知识点行。键是复合键 <track>:<topic>。
 * @param {object[]} units
 * @param {Object<string, number>} unitMastery
 * @param {Object<string, {expected: number, source: string}>} expectedMap 键是复合键
 * @returns {Array<object>}
 */
function topicRowsFor(units, unitMastery, expectedMap) {
  const groups = {}
  ;(units || []).forEach(function (unit) {
    if (!unit || !unit.id) return
    const track = trackOfUnit(unit)
    const topics = Array.isArray(unit.topics) ? unit.topics : []
    topics.forEach(function (topic) {
      const key = topicKey(track, topic)
      if (key === "") return
      if (!groups[key]) {
        groups[key] = { id: key, track: track, topic: String(topic).trim(), sum: 0, count: 0 }
      }
      const value = practicedValue(unitMastery, unit.id)
      if (value === null) return
      groups[key].sum += value
      groups[key].count += 1
    })
  })

  const rows = Object.keys(groups).map(function (key) {
    const group = groups[key]
    const value = group.count > 0 ? group.sum / group.count : 0
    const info = (expectedMap && expectedMap[key]) || { expected: 0, source: "floor" }
    const expected = Number(info.expected) || 0
    const coverage = coverageOfUnits(group.count, expected)
    const bucket = diagnose(value, coverage)
    return {
      id: group.id,
      track: group.track,
      topic: group.topic,
      mastery: value,
      coverage: coverage,
      bucket: bucket,
      label: diagnoseLabel(bucket),
      action: diagnoseAction(bucket),
      unitCount: group.count,
    }
  })
  rows.sort(function (a, b) {
    if (a.mastery !== b.mastery) return a.mastery - b.mastery
    if (a.id === b.id) return 0
    return a.id < b.id ? -1 : 1
  })
  return rows
}

/**
 * 轨道行。顺序固定：algorithm → database → ai。
 * @param {object[]} units
 * @param {Object<string, number>} unitMastery
 * @returns {Array<object>}
 */
function trackRowsFor(units, unitMastery) {
  const list = Array.isArray(units) ? units : []
  return TRACK_CODES.map(function (code) {
    const all = list.filter(function (unit) {
      return unit && trackOfUnit(unit) === code
    })
    let sum = 0
    let count = 0
    all.forEach(function (unit) {
      const value = practicedValue(unitMastery, unit.id)
      if (value === null) return
      sum += value
      count += 1
    })
    const value = count > 0 ? sum / count : 0
    const coverage = coverageOfUnits(count, all.length)
    const bucket = diagnose(value, coverage)
    return {
      track: code,
      label: labelOf(code),
      mastery: value,
      coverage: coverage,
      bucket: bucket,
      label2: diagnoseLabel(bucket),
      action: diagnoseAction(bucket),
      unitCount: all.length,
    }
  })
}

/**
 * 六根轴。顺序固定：algorithm → database → ai → c → python → sql。
 * @param {object[]} trackRows trackRowsFor 的返回值
 * @param {object[]} units
 * @param {Object<string, number>} unitMastery
 * @returns {Array<{id: string, label: string, value: number}>}
 */
function radarAxesFor(trackRows, units, unitMastery) {
  const trackValue = {}
  ;(trackRows || []).forEach(function (row) {
    trackValue[String(row.track)] = Number(row.mastery) || 0
  })

  const practiced = (Array.isArray(units) ? units : []).filter(function (unit) {
    return unit && practicedValue(unitMastery, unit.id) !== null
  })

  function meanOf(list) {
    if (!list.length) return 0
    let sum = 0
    list.forEach(function (unit) {
      sum += practicedValue(unitMastery, unit.id)
    })
    return sum / list.length
  }

  // c 轴：算法轨里 subtracks 含 engineering 或 entry.language === "cpp"
  const cUnits = practiced.filter(function (unit) {
    if (trackOfUnit(unit) !== "algorithm") return false
    const subtracks = Array.isArray(unit.subtracks) ? unit.subtracks : []
    if (subtracks.indexOf("engineering") !== -1) return true
    return String((unit.entry && unit.entry.language) || "") === "cpp"
  })

  // python 轴：entry.language === "python"
  const pythonUnits = practiced.filter(function (unit) {
    return String((unit.entry && unit.entry.language) || "") === "python"
  })

  // sql 轴：topics 里含 "SQL"（去掉空白后小写比较，命中子串即算）
  const sqlUnits = practiced.filter(function (unit) {
    const topics = Array.isArray(unit.topics) ? unit.topics : []
    return topics.some(function (topic) {
      return String(topic || "").replace(/\s+/g, "").toLowerCase().indexOf("sql") !== -1
    })
  })

  return [
    { id: "algorithm", label: "算法", value: trackValue.algorithm || 0 },
    { id: "database", label: "数据库", value: trackValue.database || 0 },
    { id: "ai", label: "AI", value: trackValue.ai || 0 },
    { id: "c", label: "C/C++", value: meanOf(cUnits) },
    { id: "python", label: "Python", value: meanOf(pythonUnits) },
    { id: "sql", label: "SQL", value: meanOf(sqlUnits) },
  ]
}

/**
 * 练过的单元清单（弱强清单的公共底座）。
 * @param {object[]} units
 * @param {Object<string, number>} unitMastery
 * @returns {Array<{unit_id: string, track: string, title: string, mastery: number, topic: string}>}
 */
function unitRows(units, unitMastery) {
  const rows = []
  ;(Array.isArray(units) ? units : []).forEach(function (unit) {
    if (!unit || !unit.id) return
    const value = practicedValue(unitMastery, unit.id)
    if (value === null) return
    const topics = Array.isArray(unit.topics) ? unit.topics : []
    rows.push({
      unit_id: String(unit.id),
      track: trackOfUnit(unit),
      title: String(unit.title === null || unit.title === undefined ? "" : unit.title),
      mastery: value,
      topic: topics.length > 0 ? String(topics[0]) : "",
    })
  })
  return rows
}

/**
 * 弱项清单：练过且掌握度 < 0.5，掌握度升序。
 * @param {object[]} units
 * @param {Object<string, number>} unitMastery
 * @returns {Array<object>}
 */
function weakUnitsFor(units, unitMastery) {
  return unitRows(units, unitMastery)
    .filter(function (row) {
      return row.mastery < MASTERY_THRESHOLD
    })
    .sort(function (a, b) {
      if (a.mastery !== b.mastery) return a.mastery - b.mastery
      if (a.unit_id === b.unit_id) return 0
      return a.unit_id < b.unit_id ? -1 : 1
    })
}

/**
 * 强项清单：练过且掌握度 >= 0.5，掌握度降序。
 * @param {object[]} units
 * @param {Object<string, number>} unitMastery
 * @returns {Array<object>}
 */
function strongUnitsFor(units, unitMastery) {
  return unitRows(units, unitMastery)
    .filter(function (row) {
      return row.mastery >= MASTERY_THRESHOLD
    })
    .sort(function (a, b) {
      if (a.mastery !== b.mastery) return b.mastery - a.mastery
      if (a.unit_id === b.unit_id) return 0
      return a.unit_id < b.unit_id ? -1 : 1
    })
}

}
```

```javascript
"use strict"
/**
 * topic-stats.js —— 从作答流水派生每个「知识点」的统计量
 *
 * 纯函数，无 IO。口径对应设计文档 §4.3 的「首次通过率 = 首次尝试就过的比例」：
 *   attempts   = 该知识点下所有单元的提交总次数
 *   firstPass  = 该知识点下「第一次尝试就通过」的单元数（反复重试通过不算）
 *   lapses     = 该知识点下没通过的提交次数（失误次数）
 *   lastAt     = 该知识点下最后一次提交的时间
 *   unitCount  = 该知识点下练过的不同单元数（覆盖度的分子）
 *
 * P3 起知识点带轨：一条记录是「某轨的某个知识点」，所以每行给三份信息：
 *   id    = "algorithm:数组"（复合键，唯一；与 topics.id / mastery.scope_id 同形）
 *   track = "algorithm"（顶层轨代码）
 *   topic = "数组"（裸知识点名，给旧页面显示用）
 *
 * 单元 id 归一跟跨轨聚合用同一套规则（core/mastery/track-mastery.js 的 unitIdOf）：
 * unit_id 优先，其次 problem_id；没有前缀的老 id 归算法轨。
 * 单元对象的主键字段叫 id，喂给 unitIdOf 时包一层——规则只有一处。
 *
 * 题库里查不到知识点的单元不计入——没有知识点归属就没法诊断。
 */

const { unitIdOf } = require("./track-mastery.js")
const { topicKey, trackOfUnit } = require("./expected.js")

/** 一次作答视为「通过」的判定 */
function isPass(verdict) {
  return String(verdict || "") === "pass"
}

/**
 * 单元 id 归一。单元对象的主键字段是 id，unitIdOf 读的是 unit_id / problem_id——
 * 这里包一层喂给它，规则（无前缀归算法轨）仍然只有 unitIdOf 一处实现。
 * @param {{id?: string, unit_id?: string, problem_id?: string}} unit
 * @returns {string} 归一后的单元 id；取不到返回 ""
 */
function unitKeyOf(unit) {
  const source = unit || {}
  return unitIdOf({ unit_id: source.id || source.unit_id || source.problem_id })
}

/**
 * 派生知识点统计。
 * @param {Array<{id?: number, unit_id?: string, problem_id?: string, ts: string, verdict: string}>} attempts
 * @param {Array<{id?: string, unit_id?: string, track?: string, topics?: string[]}>} units
 * @returns {Array<{id: string, track: string, topic: string, attempts: number, firstPass: number, lapses: number, lastAt: string|null, unitCount: number}>}
 */
function deriveTopicStats(attempts, units) {
  // 单元 id → {track, topics}
  const unitsOfId = {}
  ;(units || []).forEach(function (unit) {
    const id = unitKeyOf(unit)
    if (id === "") return
    const topics = (unit.topics || []).map(String).filter(function (t) {
      return t !== ""
    })
    unitsOfId[id] = { track: trackOfUnit(unit), topics: topics }
  })

  // 单元 id → 该单元的历次作答
  const attemptsOfUnit = {}
  ;(attempts || []).forEach(function (attempt) {
    const id = unitIdOf(attempt)
    if (id === "") return
    if (!attemptsOfUnit[id]) attemptsOfUnit[id] = []
    attemptsOfUnit[id].push(attempt)
  })

  const stats = {}

  Object.keys(attemptsOfUnit).forEach(function (id) {
    const unit = unitsOfId[id]
    if (!unit || unit.topics.length === 0) return

    // 按时间排序；时间相同按自增 id 排序——「第一次尝试」必须是真正的第一次
    const list = attemptsOfUnit[id].slice().sort(function (a, b) {
      const ta = String(a.ts || "")
      const tb = String(b.ts || "")
      if (ta !== tb) return ta < tb ? -1 : 1
      return Number(a.id || 0) - Number(b.id || 0)
    })

    const firstPassed = isPass(list[0].verdict)
    let lapses = 0
    let lastAt = null
    let lastMs = -Infinity
    list.forEach(function (attempt) {
      if (!isPass(attempt.verdict)) lapses += 1
      const ts = String(attempt.ts || "")
      const ms = Date.parse(ts)
      if (ts !== "" && Number.isFinite(ms) && ms > lastMs) {
        lastMs = ms
        lastAt = ts
      }
    })

    unit.topics.forEach(function (topic) {
      const key = topicKey(unit.track, topic)
      if (key === "") return
      if (!stats[key]) {
        stats[key] = {
          id: key,
          track: unit.track,
          topic: topic,
          attempts: 0,
          firstPass: 0,
          lapses: 0,
          lastAt: null,
          unitCount: 0,
        }
      }
      const row = stats[key]
      row.attempts += list.length
      row.unitCount += 1
      if (firstPassed) row.firstPass += 1
      row.lapses += lapses
      if (lastAt !== null && (row.lastAt === null || Date.parse(lastAt) > Date.parse(row.lastAt))) {
        row.lastAt = lastAt
      }
    })
  })

  return Object.keys(stats)
    .map(function (key) {
      return stats[key]
    })
    .sort(function (a, b) {
      if (a.id === b.id) return 0
      return a.id < b.id ? -1 : 1
    })
}

module.exports = { deriveTopicStats: deriveTopicStats }
```

**为什么排序按 `id` 不按 `topic`**：`id` 是复合键，同一轨内排序与按裸名排序一致；跨轨时先按轨排（algorithm → database → ai），同一轨内的知识点顺序不受影响。旧测试「结果按 topic 名排序」在单轨下依然成立。

```javascript
  db.exec("UPDATE topics SET id = 'algorithm:' || id WHERE id NOT LIKE '%:%'")
  db.exec("UPDATE topics SET track = 'algorithm' WHERE track IS NULL OR track = ''")
  db.exec("UPDATE mastery SET scope_id = 'algorithm:' || scope_id WHERE scope = 'topic' AND scope_id NOT LIKE '%:%'")
```

**为什么只有这三条**（契约 §4.4 冻结的就是这三条，一句不多一句不少）：

- 第一条把裸知识点名并入算法轨——历史数据全是算法轨，复合键化后 id 形如 `algorithm:数组`。
- 第二条补齐 P0 加的 `track` 列（正常情况下默认值就是 `'algorithm'`，这条是兜底）。
- 第三条把知识点级掌握度一并复合键化——`mastery.scope='topic'` 的 `scope_id` 与 `topics.id` 同形，不一起改就会出现两套键。

**幂等性**：三条都是 `UPDATE ... WHERE 条件不成立时什么也不改`，第二次跑结果与第一次完全相同。`tests/db.test.js` 里那条「再跑一次不炸、不重复、不变形」的断言就是查这个。

**不写防撞 DELETE**：裸键行与复合键行同时存在的库只可能来自人工改库。`replaceTopics` 是「先 DELETE 后 INSERT」，P3 之后库里不会再出现裸键行；真撞上了让 SQLite 报错，比静默丢一行数据诚实。

```javascript
/**
 * 处置优先级排序：档位 → 掌握度 → 复合键。
 *
 * 规则与 core/mastery/mastery.js 的 sortByUrgency 一致（档位 → 掌握度 → 名字），
 * 只是末级换成复合键——两轨都有「索引」时不会打架。不改原数组。
 * @param {Array<object>} rows
 * @returns {Array<object>}
 */
function sortRows(rows) {
  return (rows || []).slice().sort(function (a, b) {
    const ia = URGENCY_ORDER.indexOf(a.bucket)
    const ib = URGENCY_ORDER.indexOf(b.bucket)
    const pa = ia === -1 ? URGENCY_ORDER.length : ia
    const pb = ib === -1 ? URGENCY_ORDER.length : ib
    if (pa !== pb) return pa - pb
    if (a.mastery !== b.mastery) return a.mastery - b.mastery
    if (a.id === b.id) return 0
    return a.id < b.id ? -1 : 1
  })
}
```

```javascript
/** 假 res：把 writeHead / end 记下来 */
function fakeRes() {
  const res = { status: 0, body: null }
  res.writeHead = function (status) {
    res.status = status
  }
  res.end = function (text) {
    res.body = text ? JSON.parse(text) : null
  }
  return res
}

/** 回 JSON——与 server/app.js 的 sendJson 同一个写法 */
function sendJson(res, status, body) {
  const text = JSON.stringify(body)
  res.writeHead(status, { "content-type": "application/json; charset=utf-8" })
  res.end(text)
}

/** 调一次 /api/diagnose */

  assert.strictEqual(route.pattern, "/api/diagnose")
  const res = fakeRes()
  const query = new URLSearchParams(view === undefined || view === null ? "" : "view=" + view)
  await route.handler({}, res, {}, query)
  return res
}
```

```javascript
/**
 * api-diagnose.js —— GET /api/diagnose：一个接口，三个视图
 *
 * 视图（契约 §8.3）：
 *   view=mastery（缺省）—— 三轨并列 + 知识点明细（下钻用）
 *   view=radar          —— 六轴雷达 + 弱项清单 + 强项清单
 *   view=heatmap        —— 会话热力图
 *
 * 数值全部来自 core/mastery/track-mastery.js（纯函数），这一层只做装配与 HTTP。
 * 优雅降级（G17）：单元清单拿不到就交空视图，绝不 500。
 */

const { HttpError } = require("./router.js")
const { TRACK_CODES } = require("../core/track/tracks.js")
const {
  bankTopicCounts,
  buildExpectedMap,
  trackOfUnit,
  trackOfUnitId,
} = require("../core/mastery/expected.js")
const tm = require("../core/mastery/track-mastery.js")

/** 三个视图名 */
const VIEWS = ["mastery", "radar", "heatmap"]

/** 热力图最多回看多少个会话 */
const HEATMAP_SESSIONS = 20

/** 单元级结论词（G20 冻结的五类）。热力图的格子只有这五种 + pending */
const VERDICTS = ["pass", "wrong_answer", "timeout", "compile_error", "runtime_error"]

/**
 * 取单元清单。
 *
 * 优先用 ctx.units——那是 server/app.js 启动时 loadUnits 出来的那一份，
 * 带 entry.language（六轴的 c / python 两轴要看它），而 units 表只存摘要字段（契约 §4.2）。
 * 没有就退回 ctx.provider.list()（旧题库清单，没有 entry → c / python 两轴为 0，
 * 属于 G17 的优雅降级，不是错误）。
 * @param {{units?: object[], provider?: object}} ctx
 * @returns {Promise<object[]>}
 */
async function unitsOf(ctx) {
  if (Array.isArray(ctx.units)) return ctx.units
  if (ctx.provider && typeof ctx.provider.list === "function") {
    try {
      const list = await ctx.provider.list()
      return Array.isArray(list) ? list : []
    } catch (err) {
      // 题库不可用（纯本地模式 / learning 仓没连）——空视图，不报错
      return []
    }
  }
  return []
}

/**
 * 算三层掌握度（纯装配；数值口径全在 core/mastery/track-mastery.js 里）。
 * @param {{store: object}} ctx
 * @param {object[]} units
 * @param {string} nowIso
 * @returns {object}
 */
function buildModel(ctx, units, nowIso) {
  const store = ctx.store
  const attempts = store.listAttemptSummaries()
  const unitStats = tm.deriveUnitStats(attempts)
  const unitMastery = tm.computeUnitMastery(unitStats, nowIso)
  const bankCounts = bankTopicCounts(units)
  const expectedMap = buildExpectedMap(Object.keys(bankCounts), bankCounts, store.allSettings())
  return {
    attempts: attempts,
    unitStats: unitStats,
    unitMastery: unitMastery,
    expectedMap: expectedMap,
    trackRows: tm.trackRowsFor(units, unitMastery),
    topicRows: tm.topicRowsFor(units, unitMastery, expectedMap),
  }
}

/**
 * 把三层掌握度物化进 mastery 表（整体覆盖，幂等——Task 4 的 replaceMastery）。
 * @param {{store: object}} ctx
 * @param {object} model
 * @param {string} nowIso
 * @returns {void}
 */
function materialize(ctx, model, nowIso) {
  const rows = []
  Object.keys(model.unitMastery).forEach(function (unitId) {
    rows.push({
      scope: "unit",
      scope_id: unitId,
      level: model.unitMastery[unitId],
      updated_at: nowIso,
    })
  })
  model.topicRows.forEach(function (row) {
    rows.push({ scope: "topic", scope_id: row.id, level: row.mastery, updated_at: nowIso })
  })
  model.trackRows.forEach(function (row) {
    rows.push({ scope: "track", scope_id: row.track, level: row.mastery, updated_at: nowIso })
  })
  tm.materializeMastery(ctx.store, rows)
}

/**
 * view=mastery：三轨并列 + 知识点明细。
 *
 * summary 四个数的口径（契约 §8.3.1 只给了字段名，这里定死）：
 *   unitCount     = 练过的单元数（有过作答记录的单元）
 *   topicCount    = 练过的知识点数（至少有一个单元练过）
 *   sessionCount  = 会话总数
 *   totalAttempts = 总提交数
 *
 * @param {{store: object}} ctx
 * @param {object} model
 * @param {object[]} units
 * @returns {object}
 */
function masteryView(ctx, model, units) {
  const store = ctx.store
  const sessions = typeof store.listSessions === "function" ? store.listSessions() : []
  const practicedTopics = model.topicRows.filter(function (row) {
    return row.unitCount > 0
  })
  return {
    view: "mastery",
    tracks: model.trackRows,
    // 契约 §8.3.1 的 topics 行就这七个字段——内部算用的 id / unitCount 不外传
    topics: model.topicRows.map(function (row) {
      return {
        track: row.track,
        topic: row.topic,
        mastery: row.mastery,
        coverage: row.coverage,
        bucket: row.bucket,
        label: row.label,
        action: row.action,
      }
    }),
    summary: {
      unitCount: Object.keys(model.unitMastery).length,
      topicCount: practicedTopics.length,
      sessionCount: sessions.length,
      totalAttempts: model.attempts.length,
    },
  }
}

/**
 * view=radar：六轴 + 弱项 + 强项。
 *
 * 契约 §8.3.1：algorithm / database / ai 三根轴取自 mastery 表的 scope='track'。
 * 所以这里先读表；读不到（表是空的）才退回本次算出来的轨道值。
 * @param {{store: object}} ctx
 * @param {object} model
 * @param {object[]} units
 * @returns {object}
 */
function radarView(ctx, model, units) {
  const levels = {}
  if (typeof ctx.store.listMastery === "function") {
    ;(ctx.store.listMastery("track") || []).forEach(function (row) {
      levels[String(row.scope_id)] = Number(row.level) || 0
    })
  }
  const trackRows = TRACK_CODES.map(function (code) {
    const fromTable = levels[code]
    const row = model.trackRows.filter(function (item) {
      return item.track === code
    })[0]
    const value = typeof fromTable === "number" ? fromTable : row ? row.mastery : 0
    return { track: code, mastery: value }
  })
  return {
    view: "radar",
    axes: tm.radarAxesFor(trackRows, units, model.unitMastery),
    weak: tm.weakUnitsFor(units, model.unitMastery),
    strong: tm.strongUnitsFor(units, model.unitMastery),
  }
}

/**
 * 某单元的作答流水。新的 listAttemptsByUnit 没有时退回旧的 listAttemptsByProblem
 * （把单元 id 的前缀去掉——旧流水存的是不带前缀的题号）。
 * @param {object} store
 * @param {string} unitId
 * @returns {object[]}
 */
function attemptsOfUnit(store, unitId) {
  if (!unitId) return []
  if (typeof store.listAttemptsByUnit === "function") {
    const rows = store.listAttemptsByUnit(unitId)
    return Array.isArray(rows) ? rows : []
  }
  if (typeof store.listAttemptsByProblem === "function") {
    const index = unitId.indexOf(":")
    const bare = index === -1 ? unitId : unitId.slice(index + 1)
    const rows = store.listAttemptsByProblem(bare)
    return Array.isArray(rows) ? rows : []
  }
  return []
}

/**
 * 格子的状态：该单元最近一次作答的结论；没作答过就是 pending。
 * 队列里还是 pending / skipped 的项一律 pending。
 * @param {{state?: string}} item 队列项
 * @param {object[]} attempts 该单元的作答流水
 * @returns {string} 六种之一
 */
function cellState(item, attempts) {
  const state = String((item && item.state) || "")
  if (state === "pending" || state === "skipped") return "pending"
  const list = (attempts || []).slice().sort(function (a, b) {
    const ta = String(a.ts || "")
    const tb = String(b.ts || "")
    if (ta !== tb) return ta < tb ? -1 : 1
    return Number(a.id || 0) - Number(b.id || 0)
  })
  if (!list.length) return "pending"
  const verdict = String(list[list.length - 1].verdict || "")
  return VERDICTS.indexOf(verdict) === -1 ? "pending" : verdict
}

/**
 * view=heatmap：会话热力图。
 *
 * 横轴是会话序号（最近 HEATMAP_SESSIONS 个会话，按时间升序，序号从 1 开始）；
 * 纵轴是三轨；格子是那个单元的最近一次作答结论。
 * @param {{store: object}} ctx
 * @param {object[]} units
 * @returns {object}
 */
function heatmapView(ctx, units) {
  const store = ctx.store
  const trackOfId = {}
  ;(units || []).forEach(function (unit) {
    if (unit && unit.id) trackOfId[String(unit.id)] = trackOfUnit(unit)
  })

  const recent =
    typeof store.listSessions === "function" ? store.listSessions(HEATMAP_SESSIONS) || [] : []
  // listSessions 是 started_at DESC；排成升序，序号从 1 开始
  const ordered = recent.slice().sort(function (a, b) {
    const ta = String(a.started_at || "")
    const tb = String(b.started_at || "")
    if (ta !== tb) return ta < tb ? -1 : 1
    return String(a.id) < String(b.id) ? -1 : 1
  })

  const sessions = []
  const cells = []
  ordered.forEach(function (session, index) {
    sessions.push({ id: session.id, index: index + 1, started_at: session.started_at })
    const queue = typeof store.listQueue === "function" ? store.listQueue(session.id) || [] : []
    queue.forEach(function (item) {
      const unitId = String(item.unit_id || "")
      cells.push({
        session_id: session.id,
        track: trackOfId[unitId] || trackOfUnitId(unitId),
        state: cellState(item, attemptsOfUnit(store, unitId)),
        seq: Number(item.seq) || 0,
      })
    })
  })
  return { view: "heatmap", sessions: sessions, cells: cells }
}

/**
 * 组装 P3 的诊断路由。
 * @param {{store: object, provider?: object, sendJson: Function, units?: object[], nowIso?: string}} ctx
 *   units：启动时 loadUnits 的结果（可选，缺省退回 provider.list()）
 *   nowIso：当前时刻（可选，测试用；缺省取系统时间）
 * @returns {Array<{method: string, pattern: string, handler: Function}>}
 */
function buildDiagnoseRoutes(ctx) {
  return [
    {
      method: "GET",
      pattern: "/api/diagnose",
      handler: async function (req, res, params, query) {
        const raw = query.get("view")
        const view = raw === null || String(raw).trim() === "" ? "mastery" : String(raw).trim()
        if (VIEWS.indexOf(view) === -1) {
          throw new HttpError(400, "诊断视图只能是 mastery / radar / heatmap")
        }
        const nowIso = ctx.nowIso || new Date().toISOString()
        const units = await unitsOf(ctx)
        const model = buildModel(ctx, units, nowIso)
        // 先物化再读表：radar 的三轨轴取自 mastery 表的 scope='track'
        materialize(ctx, model, nowIso)

        let body
        if (view === "radar") body = radarView(ctx, model, units)
        else if (view === "heatmap") body = heatmapView(ctx, units)
        else body = masteryView(ctx, model, units)
        ctx.sendJson(res, 200, body)
      },
    },
  ]
}
```

**⑤ 新增热力图的常量与函数**——插在 `barSvg` 函数**之后**、`return {` **之前**：

```javascript
  /**
   * 热力图的六种格子状态。
   *
   * 颜色只做分组（通过 / 没通过 / 没作答），**状态本身由格子里的汉字承载**——
   * 色觉障碍与黑白打印都还能读。每个状态另带一个中文全称，写进格子的 tooltip。
   */
  const HEATMAP_STATES = {
    pass: { mark: "通", label: "通过", text: "#0d1512" },
    wrong_answer: { mark: "错", label: "答错", text: "#1a0d06" },
    timeout: { mark: "超", label: "超时", text: "#1a0d06" },
    compile_error: { mark: "编", label: "编译错误", text: "#1a0d06" },
    runtime_error: { mark: "崩", label: "运行时错误", text: "#1a0d06" },
    pending: { mark: "待", label: "未作答", text: "#e8e8e6" },
  }

  /** 图例的固定顺序 */
  const HEATMAP_STATE_ORDER = [
    "pass",
    "wrong_answer",
    "timeout",
    "compile_error",
    "runtime_error",
    "pending",
  ]

  /**
   * 状态 → 颜色。四种失败共用一种颜色：颜色只分组，状态看汉字。
   * @param {string} state
   * @param {object} [theme]
   * @returns {string}
   */
  function heatmapStateColor(state, theme) {
    const t = Object.assign({}, DEFAULT_THEME, theme || {})
    const key = String(state === null || state === undefined ? "" : state)
    if (key === "pass") return t.series3
    if (key === "pending") return t.track
    if (HEATMAP_STATES[key]) return t.series2
    return t.track
  }

  /**
   * 会话热力图。
   *
   * 横轴 = 会话序号（用 sessions 里的 index，从 1 开始；没给就按数组下标 +1）；
   * 纵轴 = 三轨（tracks 的顺序）；
   * 格子 = 那次作答的结果（cells 每项一格）。
   * 同一会话同一轨有多个单元时横向排开，列宽按全表最多的那一格数定。
   *
   * @param {{sessions: Array<{id: string, index?: number, started_at?: string}>,
   *          cells: Array<{session_id: string, track: string, state: string, seq?: number, title?: string}>,
   *          tracks?: string[], trackLabels?: Object<string, string>,
   *          width?: number, height?: number, cellSize?: number, title?: string, theme?: object}} options
   * @returns {string}
   */
  function heatmapSvg(options) {
    const opts = options || {}
    const theme = Object.assign({}, DEFAULT_THEME, opts.theme || {})
    const sessions = Array.isArray(opts.sessions) ? opts.sessions : []
    const cells = Array.isArray(opts.cells) ? opts.cells : []
    const tracks =
      Array.isArray(opts.tracks) && opts.tracks.length > 0
        ? opts.tracks
        : ["algorithm", "database", "ai"]
    const trackLabels =
      opts.trackLabels && typeof opts.trackLabels === "object" ? opts.trackLabels : {}
    const title = String(opts.title || "会话热力图")
    const cellSize = Number(opts.cellSize) > 0 ? Number(opts.cellSize) : 16
    const gap = 3
    const padLeft = 64
    const padTop = 30
    const padRight = 16
    const padBottom = 28
    const parts = []

    // 一个会话都没有：给中文占位文案，别画一张空图
    if (sessions.length === 0) {
      const width = Number(opts.width) > 0 ? Number(opts.width) : 320
      const height = Number(opts.height) > 0 ? Number(opts.height) : 120
      parts.push(
        '<svg class="chart chart-heatmap" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 ' +
          num(width) +
          " " +
          num(height) +
          '" role="img" aria-label="' +
          escapeXml(title) +
          '">'
      )
      parts.push("<title>" + escapeXml(title) + "</title>")
      parts.push(
        '<text class="chart-empty" x="' +
          num(width / 2) +
          '" y="' +
          num(height / 2) +
          '" text-anchor="middle" dominant-baseline="middle" fill="' +
          theme.muted +
          '" font-size="13">还没有会话记录</text>'
      )
      parts.push("</svg>")
      return parts.join("")
    }

    // 会话 → 列下标
    const columnOf = {}
    sessions.forEach(function (session, index) {
      columnOf[String(session.id)] = index
    })

    // 每一列每一轨最多几个格子——定列宽
    const slotCount = {}
    cells.forEach(function (cell) {
      const key = String(cell.session_id) + "|" + String(cell.track)
      slotCount[key] = (slotCount[key] || 0) + 1
    })
    let maxSlots = 1
    Object.keys(slotCount).forEach(function (key) {
      if (slotCount[key] > maxSlots) maxSlots = slotCount[key]
    })

    const colWidth = maxSlots * (cellSize + gap)
    const rowHeight = cellSize + gap + 10
    const width =
      Number(opts.width) > 0 ? Number(opts.width) : padLeft + sessions.length * colWidth + padRight
    const height =
      Number(opts.height) > 0
        ? Number(opts.height)
        : padTop + tracks.length * rowHeight + padBottom

    parts.push(
      '<svg class="chart chart-heatmap" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 ' +
        num(width) +
        " " +
        num(height) +
        '" role="img" aria-label="' +
        escapeXml(title) +
        '">'
    )
    parts.push("<title>" + escapeXml(title) + "</title>")

    // 图例：一行中文。颜色只分组，状态看汉字
    const legend = HEATMAP_STATE_ORDER.map(function (key) {
      return HEATMAP_STATES[key].mark + " " + HEATMAP_STATES[key].label
    }).join("　")
    parts.push(
      '<text class="chart-legend" x="' +
        num(padLeft) +
        '" y="' +
        num(14) +
        '" fill="' +
        theme.muted +
        '" font-size="11">' +
        escapeXml(legend) +
        "</text>"
    )

    // 纵轴：三轨的名字
    tracks.forEach(function (track, rowIndex) {
      const y = padTop + rowIndex * rowHeight + cellSize / 2
      const name = String(trackLabels[track] || track)
      parts.push(
        '<text class="chart-axis-label" x="' +
          num(padLeft - 8) +
          '" y="' +
          num(y) +
          '" text-anchor="end" dominant-baseline="middle" fill="' +
          theme.muted +
          '" font-size="12">' +
          escapeXml(name) +
          "</text>"
      )
    })

    // 横轴：会话序号
    sessions.forEach(function (session, index) {
      const label = Number.isFinite(Number(session.index)) ? Number(session.index) : index + 1
      const x = padLeft + index * colWidth + colWidth / 2
      parts.push(
        '<text class="chart-axis-label" x="' +
          num(x) +
          '" y="' +
          num(padTop + tracks.length * rowHeight + 12) +
          '" text-anchor="middle" fill="' +
          theme.muted +
          '" font-size="10">' +
          num(label) +
          "</text>"
      )
    })

    // 格子：先按（会话、轨、seq）定序，同会话同轨横向排开
    const placed = []
    cells.forEach(function (cell) {
      const column = columnOf[String(cell.session_id)]
      if (column === undefined) return
      const row = tracks.indexOf(String(cell.track))
      if (row === -1) return
      placed.push({ cell: cell, column: column, row: row })
    })
    placed.sort(function (a, b) {
      if (a.column !== b.column) return a.column - b.column
      if (a.row !== b.row) return a.row - b.row
      return Number(a.cell.seq || 0) - Number(b.cell.seq || 0)
    })

    const used = {}
    placed.forEach(function (item) {
      const cell = item.cell
      const key = String(cell.session_id) + "|" + String(cell.track)
      const slot = used[key] || 0
      used[key] = slot + 1
      const state = HEATMAP_STATES[cell.state] ? String(cell.state) : "pending"
```

```javascript
  /** 三轨的中文名（接口给了 label 就用接口的，这个只是兜底） */
  const TRACK_LABELS = { algorithm: "算法", database: "数据库", ai: "AI" }

  /** 三轨的固定顺序（热力图的纵轴用它） */
  const TRACK_CODES = ["algorithm", "database", "ai"]

  /** 四档 → 药丸色调。四档的中文标签由接口给，这里只映射颜色 */
  const BUCKET_TONE = {
    "weak-dense": "bad",
    "weak-sparse": "warn",
    "strong-sparse": "accent",
    "strong-dense": "ok",
  }

  /** 下钻明细最多列几行 */
  const MAX_TOPIC_ROWS = 12

  /** 弱项 / 强项清单最多列几行 */
  const MAX_WEAK_ROWS = 12

  const UI =
    (typeof globalThis !== "undefined" &&
      (globalThis.AlgoPlanUI ||
        (globalThis.StudyHub && globalThis.StudyHub.ui) ||
        (globalThis.AlgoPlan && globalThis.AlgoPlan.ui))) ||

  /* ---------------- 纯函数层 ---------------- */

  /** 0..1 → 整数百分比 */
  function percent(value) {
    const n = Number(value)
    if (!Number.isFinite(n) || n <= 0) return "0%"
    return String(Math.min(100, Math.round(n * 100))) + "%"
  }

  /** 轨名的中文兜底 */
  function trackLabelOf(track) {
    const key = String(track || "")
    return TRACK_LABELS[key] || key
  }

  /** 四档 → 条形颜色：弱档橙、强档绿、没诊断出来用蓝 */
  function bucketColor(bucket) {
    const theme = Charts.DEFAULT_THEME
    const key = String(bucket || "")
    if (key === "weak-dense" || key === "weak-sparse") return theme.series2
    if (key === "strong-dense" || key === "strong-sparse") return theme.series3
    return theme.series1
  }

  /**
   * 三轨并列的条形行。
   * @param {object} payload /api/diagnose?view=mastery 的响应
   * @returns {Array<object>}
   */
  function trackBarRows(payload) {
    const data = payload || {}
    const list = Array.isArray(data.tracks) ? data.tracks : []
    return list.map(function (item) {
      const track = String((item && item.track) || "")
      const mastery = Number((item && item.mastery) || 0)
      const coverage = Number((item && item.coverage) || 0)
      return {
        track: track,
        label: String((item && item.label) || trackLabelOf(track)),
        mastery: mastery,
        coverage: coverage,
        display: percent(mastery),
        coverageDisplay: percent(coverage),
        bucket: String((item && item.bucket) || ""),
        bucketLabel: String((item && item.label2) || ""),
        action: String((item && item.action) || ""),
        unitCount: Number((item && item.unitCount) || 0),
      }
    })
  }

  /**
   * 下钻明细：某一条轨的知识点，按掌握度从低到高。
   * @param {object} payload
   * @param {string} track 轨代码
   * @param {number} [limit] 最多几行
   * @returns {Array<object>}
   */
  function topicRowsForTrack(payload, track, limit) {
    const data = payload || {}
    const all = Array.isArray(data.topics) ? data.topics : []
    const max = Number(limit) > 0 ? Number(limit) : MAX_TOPIC_ROWS
    return all
      .filter(function (item) {
        return String((item && item.track) || "") === String(track || "")
      })
      .map(function (item) {
        const bucket = String((item && item.bucket) || "")
        const mastery = Number((item && item.mastery) || 0)
        const topic = String((item && item.topic) || "")
        return {
          key: String(track || "") + ":" + topic,
          track: String((item && item.track) || ""),
          topic: topic,
          mastery: mastery,
          display: percent(mastery),
          coverage: Number((item && item.coverage) || 0),
          coverageDisplay: percent((item && item.coverage) || 0),
          bucket: bucket,
          bucketLabel: String((item && item.label) || ""),
          action: String((item && item.action) || ""),
          color: bucketColor(bucket),
        }
      })
      .sort(function (a, b) {
        return a.mastery - b.mastery
      })
      .slice(0, max)
  }

  /**
   * 概览数字块：四个数。
   * @param {object} payload
   * @returns {Array<{label: string, value: string}>}
   */
  function summaryCards(payload) {
    const data = payload || {}
    const s = data.summary || {}
    return [
      { label: "练过单元", value: String(Number(s.unitCount) || 0) },
      { label: "练过知识点", value: String(Number(s.topicCount) || 0) },
      { label: "会话数", value: String(Number(s.sessionCount) || 0) },
      { label: "总提交数", value: String(Number(s.totalAttempts) || 0) },
    ]
  }

  /**
   * 雷达六轴。顺序由接口给（契约 §8.3.1 固定六轴顺序），前端不重排。
   * @param {object} payload
   * @returns {Array<object>}
   */
  function radarAxes(payload) {
    const data = payload || {}
    const list = Array.isArray(data.axes) ? data.axes : []
    return list.map(function (item) {
      const id = String((item && item.id) || "")
      const value = Number((item && item.value) || 0)
      return {
        id: id,
        label: String((item && item.label) || trackLabelOf(id)),
        value: value,
        display: percent(value),
      }
    })
  }

  /**
   * 一句建议。
   *
   * 接口的清单只给掌握度、没有覆盖度——算不出四档，所以前端不自己判档，
   * 只把掌握度写进句子里，给一句能执行的话。
   * @param {object} row
   * @param {boolean} weak true = 弱项，false = 强项
   * @returns {string}
   */
  function adviceFor(row, weak) {
    const item = row || {}
    const display = String(item.display || percent(item.mastery))
    if (weak) {
      return "掌握度 " + display + "——先补这个概念的笔记，别急着刷题"
    }
    return "掌握度 " + display + "——已掌握，不用主动排"
  }

  /**
   * 弱项清单。
   * @param {object} payload
   * @param {number} [limit]
   * @returns {Array<object>}
   */
  function weakRows(payload, limit) {
    const data = payload || {}
    const list = Array.isArray(data.weak) ? data.weak : []
    const max = Number(limit) > 0 ? Number(limit) : MAX_WEAK_ROWS
    return list.slice(0, max).map(function (item) {
      const track = String((item && item.track) || "")
      const mastery = Number((item && item.mastery) || 0)
      const row = {
        unit_id: String((item && item.unit_id) || ""),
        track: track,
        trackLabel: trackLabelOf(track),
        title: String((item && item.title) || ""),
        topic: String((item && item.topic) || ""),
        mastery: mastery,
        display: percent(mastery),
      }
      row.advice = adviceFor(row, true)
      return row
    })
  }

  function strongRows(payload, limit) {

  /**
   * 热力图图例：六种状态。颜色只分组，状态看汉字与中文全称。
   * @returns {Array<{state: string, mark: string, label: string, color: string}>}
   */
  function legendItems() {
    const theme = Charts.DEFAULT_THEME
    return Charts.HEATMAP_STATE_ORDER.map(function (state) {
      const meta = Charts.HEATMAP_STATES[state] || { mark: "?", label: String(state) }
      return {
        state: state,
        mark: meta.mark,
        label: meta.label,
        color: Charts.heatmapStateColor(state, theme),
      }
    })
  }

  /**
   * 热力图按会话分组。
   * @param {object} payload
   * @returns {Array<{id: string, index: number, cells: Array<object>}>}
   */
  function heatmapRows(payload) {
    const data = payload || {}
    const sessions = Array.isArray(data.sessions) ? data.sessions : []
    const cells = Array.isArray(data.cells) ? data.cells : []
    return sessions.map(function (session, position) {
      const sid = String((session && session.id) || "")
      const index = Number(session && session.index) > 0 ? Number(session.index) : position + 1
      const mine = cells.filter(function (cell) {
        return String((cell && cell.session_id) || "") === sid
      })
      return {
        id: sid,
        index: index,
        startedAt: String((session && session.started_at) || ""),
        cells: mine.map(function (cell) {
          const state = String((cell && cell.state) || "pending")
          const meta = Charts.HEATMAP_STATES[state] || { mark: "?", label: state }
          const track = String((cell && cell.track) || "")
          return {
            session_id: sid,
            track: track,
            trackLabel: trackLabelOf(track),
            state: state,
            mark: meta.mark,
            label: meta.label,
            seq: Number((cell && cell.seq) || 0),
          }
        }),
      }
    })
  }

  /* ---------------- 视图模型 ---------------- */

  /**
   * 三轨总览的主卡文案：挑覆盖度大于 0 的轨里掌握度最低的那条。
   * @param {Array<object>} tracks
   * @returns {{title: string, text: string}}
   */
  function masteryHero(tracks) {
    const list = Array.isArray(tracks) ? tracks : []
    if (list.length === 0) {
      return { title: "还没有练习记录", text: "先去做几道题，这里才有得诊断。" }
    }
    let weakest = null
    list.forEach(function (item) {
      if (Number(item.coverage) <= 0) return
      if (!weakest || Number(item.mastery) < Number(weakest.mastery)) weakest = item
    })
    if (!weakest) {
      return { title: "还没有可诊断的轨", text: "先去做几道题，这里才有得诊断。" }
    }
    return {
      title: "先治这一条轨",
      text:
        weakest.label +
        " 掌握度 " +
        weakest.display +
        "——" +
        (weakest.action || "先补量"),
    }
  }

  /**
   * 雷达的主卡文案：六轴里最短的那块板。
   * @param {Array<object>} axes
   * @returns {{title: string, text: string}}
   */
  function radarHero(axes) {
    const list = Array.isArray(axes) ? axes : []
    let weakest = null
    list.forEach(function (item) {
      if (Number(item.value) <= 0) return
      if (!weakest || Number(item.value) < Number(weakest.value)) weakest = item
    })
    if (!weakest) {
      return { title: "还没有练习记录", text: "先去做几道题，这里才有得诊断。" }
    }
    return {
      title: "最短的那块板",
      text:
        weakest.label +
        " 掌握度 " +
        weakest.display +
        "——先补这个概念的笔记，别急着刷题",
    }
  }

  /**
   * 热力图的主卡文案：最近一次会话的结果。
   * @param {Array<object>} rows
   * @returns {{title: string, text: string}}
   */
  function heatmapHero(rows) {
    const list = Array.isArray(rows) ? rows : []
    if (list.length === 0) {
      return { title: "还没有会话记录", text: "先去做几道题，这里才有得诊断。" }
    }
    const last = list[list.length - 1]
    let passed = 0
    let answered = 0
    last.cells.forEach(function (cell) {
      if (cell.state === "pass") passed += 1
      if (cell.state !== "pending") answered += 1
    })
    return {
      title: "最近一次会话",
      text: "第 " + last.index + " 次会话：通过 " + passed + " 个，作答 " + answered + " 个。",
    }
  }

  /**
   * 三轨总览视图模型。
   * @param {object} payload
   * @returns {object}
   */
  function buildMasteryView(payload) {
    const data = payload || {}
    const tracks = trackBarRows(data)
    return {
      view: "mastery",
      title: "三轨总览",
      hero: masteryHero(tracks),
      tracks: tracks,
      drilldown: tracks.map(function (track) {
        return {
          track: track.track,
          label: track.label,
          rows: topicRowsForTrack(data, track.track),
        }
      }),
      cards: summaryCards(data),
      table: {
        columns: ["轨", "掌握度", "覆盖度", "诊断", "单元数"],
        rows: tracks.map(function (track) {
          return [
            track.label,
            track.display,
            track.coverageDisplay,
            track.bucketLabel || "未诊断",
            String(track.unitCount),
          ]
        }),
      },
    }
  }

  /**
   * 六轴雷达视图模型。
   * @param {object} payload
   * @returns {object}
   */
  function buildRadarView(payload) {
    const data = payload || {}
    const axes = radarAxes(data)
    return {
      view: "radar",
      title: "六轴雷达",
      hero: radarHero(axes),
      axes: axes,
      weak: weakRows(data),
      strong: strongRows(data),
      table: {
        columns: ["维度", "掌握度"],
        rows: axes.map(function (axis) {
          return [axis.label, axis.display]
        }),
      },
    }
  }

  /**
   * 会话热力图视图模型。
   * @param {object} payload
   * @returns {object}
   */
  function buildHeatmapView(payload) {
    const data = payload || {}
    const rows = heatmapRows(data)
    const tableRows = []
    rows.forEach(function (row) {
      row.cells.forEach(function (cell) {
        tableRows.push([String(row.index), cell.trackLabel, cell.label, String(cell.seq)])
      })
    })
    return {
      view: "heatmap",
      title: "会话热力图",
      hero: heatmapHero(rows),
      sessions: Array.isArray(data.sessions) ? data.sessions : [],
      sessionRows: rows,
      cells: Array.isArray(data.cells) ? data.cells : [],
      legend: legendItems(),
      table: {
        columns: ["会话", "轨", "结果", "序号"],
        rows: tableRows,
      },
    }
  }

  /**
   * 按视图名分发。名字不认识就回落到三轨总览。
   * @param {object} payload
   * @param {string} view
   * @returns {object}
   */
  function buildDiagnoseView(payload, view) {
    const name = String(view || "")
    if (name === "radar") return buildRadarView(payload)
    if (name === "heatmap") return buildHeatmapView(payload)
    return buildMasteryView(payload)
  }

  /**
   * 最弱的那条轨（覆盖度大于 0 的里面挑掌握度最低的）。
   * 下钻默认落在它身上。
   * @param {object} model 视图模型
   * @returns {string} 轨代码，空串表示没有
   */
  function weakestTrack(model) {
    const tracks = (model && model.tracks) || []
    let best = null
    tracks.forEach(function (item) {
      if (Number(item.coverage) <= 0) return
      if (!best || Number(item.mastery) < Number(best.mastery)) best = item
    })
    return best ? String(best.track) : ""
  }

  /** 三轨并列：一条轨一张卡，卡里两根条（掌握度 / 覆盖度） */
  function trackCards(make, C, model, opts) {
    const options = opts || {}
    const wrap = make("div", { class: "diag-tracks" }, [])
    model.tracks.forEach(function (track) {
      const selected = track.track === options.drillTrack
      const card = make(
        "div",
        {
          class: "diag-track",
          role: "button",
          tabindex: "0",
          "aria-pressed": selected ? "true" : "false",
          onclick: function () {
            if (typeof options.onSelectTrack === "function") options.onSelectTrack(track.track)
          },
        },
        []
      )
      const head = make("div", { class: "diag-track-head" }, [])
      head.appendChild(make("span", { class: "diag-track-name", text: track.label }))
      if (track.bucketLabel) {
        head.appendChild(UI.pill(track.bucketLabel, BUCKET_TONE[track.bucket]))
      }
      card.appendChild(head)
      card.appendChild(
        chartHost(
          make,
          C.barSvg({
            rows: [
              {
                label: "掌握度",
                value: track.mastery,
                display: track.display,
                color: C.DEFAULT_THEME.series1,
              },
              {
                label: "覆盖度",
                value: track.coverage,
                display: track.coverageDisplay,
                color: C.DEFAULT_THEME.series2,
              },

            max: 1,
            width: 320,
            labelWidth: 56,
            valueWidth: 48,
            title: track.label + " 的掌握度与覆盖度",
          })
        )
      )
      card.appendChild(make("p", { class: "diag-track-action", text: track.action || "" }))
      wrap.appendChild(card)
    })
    return wrap
  }

  /** 下钻明细：选中那条轨的知识点 */
  function drilldown(make, C, model, opts) {
    const options = opts || {}
    const selected = String(options.drillTrack || "")
    let target = null
    model.drilldown.forEach(function (item) {
      if (item.track === selected) target = item
    })
    if (!target) {
      return UI.empty("点上面任意一条轨", "选中之后这里会列出那条轨的知识点与处方。")
    }
    const wrap = make("div", { class: "diag-drill" }, [])
    wrap.appendChild(
      chartHost(
        make,
        C.barSvg({
          rows: target.rows.map(function (row) {
            return { label: row.topic, value: row.mastery, display: row.display, color: row.color }
          }),
          max: 1,
          width: 520,
          title: target.label + " 的知识点掌握度",
        })
      )
    )
    wrap.appendChild(topicList(make, target.rows))
    return wrap
  }

  /** 下钻的知识点行：名字 + 数字 + 档位药丸 + 处方 */
  function topicList(make, rows) {
    if (!rows.length) {
      return UI.empty("这条轨还没有知识点", "先做几道题，这里才有得诊断。")
    }
    const list = make("ul", { class: "diag-advice" }, [])
    rows.forEach(function (row) {
      const item = make("li", { class: "diag-topic" }, [])
      item.appendChild(make("span", { class: "diag-topic-name", text: row.topic }))
      item.appendChild(make("span", { class: "diag-topic-pct", text: row.display }))
      if (row.bucketLabel) {
        item.appendChild(UI.pill(row.bucketLabel, BUCKET_TONE[row.bucket]))
      }
      item.appendChild(make("span", { class: "diag-topic-action", text: row.action || "" }))
      list.appendChild(item)
    })
    return list
  }

  /** 清单行（弱项 / 强项）：名字 + 数字 + 轨名药丸 + 建议 */
  function listRows(make, rows, emptyTitle, emptyHint) {
    if (!rows.length) return UI.empty(emptyTitle, emptyHint)
    const list = make("ul", { class: "diag-advice" }, [])
    rows.forEach(function (row) {
      const item = make("li", { class: "diag-topic" }, [])
      item.appendChild(
        make("span", { class: "diag-topic-name", text: row.title || row.unit_id })
      )
      item.appendChild(make("span", { class: "diag-topic-pct", text: row.display }))

    let drill = ""

      view.textContent = ""

      try {
        if (!cache[active]) {
          cache[active] = await app.getJson("/api/diagnose?view=" + active)
        }
        const model = buildDiagnoseView(cache[active], active)
        view.textContent = ""
        mountDiagnose(view, model, chartsGlobal() || Charts, make, {
          activeView: active,

          })
        )
      }
    }

    await paint()
  }

    buildRadarView: buildRadarView,
```

**② 加一个按 class 里的词找节点的辅助函数**（药丸的 class 是 `pill warn` 这种带色调后缀的，精确匹配找不到）——放在 `findByClass` 后面：

```javascript
/**
 * 在树里找出所有「class 里含这个词」的节点。
 * 药丸的 class 是 "pill warn" 这种带色调后缀的，光按 className 精确匹配找不到。
 */
function findAllByClassToken(node, token) {
  const out = []
  function walk(n) {
    if (!n) return
    const tokens = String(n.className || "").split(/\s+/)
    if (tokens.indexOf(token) !== -1) out.push(n)
    ;(n.children || []).forEach(walk)
  }
  walk(node)
  return out
}
```
