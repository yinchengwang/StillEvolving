# 学习中枢 App（study-hub）—— P1 会话队列与首页实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 study-hub 从「按天推下一题」改成「按次数排一次会话」——跨轨配额（最大余数法）→ 轨内优先级 → 跨轨交错成形 → 队列落库 → 会话生命周期（开始 / 取下一个 / 暂停 / 完成）→ 首页按队列展示（已完成打勾、当前标黄、未开始置灰），并在设置页把「会话长度」与「三轨权重」调成自己的节奏。

**Architecture:** 服务端**只排不判**。`core/scheduler/` 下四个纯函数模块——`quota.js`（跨轨配额）、`prioritize.js`（轨内优先级）、`queue.js`（跨轨交错）、`pool.js`（候选池与到期集合）——都不碰数据库；`server/api-session.js` 把它们串成会话生命周期，写进 `sessions` / `session_queue` 两张表；前端新增 `web/pages/session.js`（队列式首页）与 `web/pages/settings.js`（会话设置），`web/app.js` 补最小 hash 解析器与 `window.StudyHub` 全局。

**Tech Stack:** Node.js ≥ 24（`node:sqlite` / `node:http` / `node:test` / `node:crypto` / `node:child_process`）、原生 JS + CSS、零 npm 依赖、零构建、零第三方图表库。

**Spec:** `docs/superpowers/specs/2026-11-12-study-hub-design.md`（设计意图；实现形状以接口契约为准）。

**接口契约:** `docs/superpowers/plans/2026-11-12-study-hub-接口契约.md`（**权威**）。本计划 Task 1 先把 P1 需要的增补回写进契约，再动手写代码——契约里没有的名字不许先出现在代码里。

**代码位置:** `projects/apps/study-hub/`（在 `projects` 子模块里提交与推送）；本计划文档放父仓 `StillEvolving/docs/superpowers/plans/`。

### P1 专属约束

| # | 约束 | 精确值 |
|---|---|---|
| G39 | **只排不判** | P1 的会话链路**不跑断言、不跑编译、不写 `attempts`**。`POST /api/session/submit` 只做「把这个单元标记为完成」：队列项置 `done`、`done_count++`、`unit_progress` 置 `done`、所有复习卡 `units_since += 1`。判题在 P2 接入。 |
| G40 | **会话长度按单元数计** | 会话长度 = 单元个数，默认 `3`（`session.default_count`），可调 `1`–`10`（`session.min_count` / `session.max_count`）。**没有 `today` 视图、没有日历打卡、没有「连续 N 天」指标。** |
| G41 | **候选池口径（冻结）** | 单元进候选池 ⟺ `status === "verified"` ∧（`progress !== "done"` ∨ 该单元已到期）。`draft` / `rejected` / `todo` 一律不进。**进度以 `unit_progress` 表为准**（`units` 表没有 `progress` 列）；表里没有的单元按 `todo` 处理。 |
| G42 | **配额算法逐字实现** | `allocateQuota` 必须照契约 §6.1 的五步：需求度 → 有效权重 → 最大余数法 → 候选回收 → 空池兜底。余数相同时按 `tracks` 数组的**声明顺序**优先。同输入必同输出（不读时钟、不用 `Math.random`）。 |
| G43 | **队列交错规则（冻结）** | 轨内顺序由 `prioritize` 给定，`buildQueue` **不重排**；跨轨 round-robin 交错；**连续同轨上限 = 该轨配额的 2 倍（下限 2）**；只剩一条轨有名额时上限不适用（否则那条轨永远排不进去）；`seq` 从 1 开始连续。 |
| G44 | **SM-2 双触发** | 到期 ⟺ `next_review_at <= now`（日期通道）∨ `units_since >= K`（次数通道，`K` 默认 5，`review.count_trigger_k` 可配）。**任何轨完成一个单元，所有卡 `units_since += 1`。** `interval_days` 仍按日历天算（G22）。 |
| G45 | **P1 的 verdict 是 `null`** | `POST /api/session/submit` 在 P1 阶段 `verdict` 恒为 `null`、`judged` 恒为 `false`——`null` 表示「还没判」，**不是** G20 之外的第六类 verdict。P2 接入判题后 `verdict` 才取五类之一。 |
| G46 | **会话队列落库** | 队列写在 `session_queue` 表（`session_id` / `unit_id` / `seq` / `state`），`state ∈ pending / current / done / skipped`。关掉浏览器再打开，队列必须还在（验收线）。同一会话里同时最多一个 `current`。 |
| G47 | **首页版式（冻结）** | 首页是**会话队列式**：顶部提示「上次还有 N 个没做完」→ `.panel hero` 放当前单元与主行动 → `.panel` 放队列清单（**已完成打勾 ✓、当前标黄、未开始置灰**）→ `.panel quiet` 放三轨掌握度小块作背景。 |
| G48 | **P1 拥有的 settings 键** | `session.default_count` / `session.min_count` / `session.max_count` / `track.weight.algorithm|database|ai` / `track.enabled.algorithm|database|ai` / `review.count_trigger_k`。`review.daily_quota_questions` 等旧键**保留在表里但 P1 不读**。 |
| G49 | **前端全局与别名** | P1 起前端全局是 `window.StudyHub`；`window.AlgoPlan` **保留为同一个对象的别名**（`window.AlgoPlan === window.StudyHub`），旧页面脚本（today / answer / review / rounds）不改也能工作。 |
| G50 | **提交不许用 `git add -A`** | `projects` 子模块里有别人的未提交改动。提交命令一律**写死路径**：`git add apps/study-hub/<具体文件> ...`。**严禁 `git add -A` / `git add .` / `git commit -a`。** |
| G51 | **P1 不写 learning 仓** | P1 只读 learning 仓（轮次清单、单元文件），**一次都不写**。因此 G13 / G14 / G15 在 P1 没有触发场景——真到了要写的时候（供给流水线回写 `reviewed`），再按那三条走。 |
| G52 | **测试离线且自带数据** | P1 的测试**不联网、不依赖 learning 仓、不依赖 numpy**。单元数据用假的 `units` 行注入；numpy 探测用注入的假探测器。 |
| G53 | **DOM 桩约束** | `tests/helpers/dom-stub.js` 没有 `querySelector` / `innerHTML` / `parentNode.replaceChild` / `MutationObserver`。新页面的可测逻辑必须抽成**纯函数**并 `module.exports` 导出，渲染层用 `PAGES.<key>.render(view)` 驱动。 |
| G54 | **store 方法归属裁决** | 契约 §4.3 的 15 个新方法里，`units` / `mastery` / `unit_progress` 三组由 **P0** 交付；`sessions` / `session_queue` 两组由 **P1** 交付（P0 用不到会话表）。P1 在 `server/db.js` 上**只做加法**。 |
| G55 | **settings 读写走 store** | 一律用 `store.getSetting(key, fallback)` / `store.setSetting(key, value)`；字符串转数字时 `Number()` 非有限或 `< 0` → 回落默认值。设置值**永远不落进 API key 一类的敏感位**。 |

```js
"use strict"
/**
 * quota.js —— 跨轨配额分配（最大余数法 / Hare quota）
 *
 * 一次会话的 N 个单元要分给三条轨。分法（契约 §6.1，逐字实现）：
 *   1. 需求度   demand[t] = 1 + min(1, due[t] / 5)   复习积压多的轨加权
 *   2. 有效权重 w'[t] = w[t] × demand[t]
 *   3. 配额     n[t] = floor(N × w'[t] / Σw')      余数按小数从大到小补给前面
 *   4. 回收     某轨候选不够时，多余配额按 w' 比例分给仍有候选的轨
 *   5. 兜底     所有轨都没候选 → needMore = true
 *
 * 纯函数：同输入必同输出（不读时钟、不用随机数）。
 */

const { labelOf } = require("../track/tracks.js")

/**
 * 最大余数法：把 total 个名额按 weight 比例分给 items。
 * 余数相同时按 items 的声明顺序优先。
 * @param {Array<{key: string, weight: number}>} items
 * @param {number} total
 * @returns {{[key: string]: number}}
 */
function largestRemainder(items, total) {
  const list = items || []
  const out = {}
  list.forEach(function (item) {
    out[item.key] = 0
  })
  const count = Math.max(0, Math.trunc(Number(total) || 0))
  if (list.length === 0 || count === 0) return out

  const sum = list.reduce(function (acc, item) {
    return acc + Math.max(0, Number(item.weight) || 0)
  }, 0)

  if (sum <= 0) {
    // 权重全为 0：各轨等分，余数按声明顺序补给靠前的轨
    const each = Math.floor(count / list.length)
    let rest = count - each * list.length
    list.forEach(function (item) {
      out[item.key] = each
      if (rest > 0) {
        out[item.key] += 1
        rest -= 1
      }
    })
    return out
  }

  const rests = []
  let used = 0
  list.forEach(function (item, index) {
    const weight = Math.max(0, Number(item.weight) || 0)
    const exact = (count * weight) / sum
    const base = Math.floor(exact)
    out[item.key] = base
    used += base
    rests.push({ key: item.key, index: index, rest: exact - base })
  })
  rests.sort(function (a, b) {
    if (b.rest !== a.rest) return b.rest - a.rest
    return a.index - b.index
  })
  let left = count - used
  for (let i = 0; i < rests.length && left > 0; i++) {
    out[rests[i].key] += 1
    left -= 1
  }
  return out
}

/**
 * 分配一次会话的跨轨配额。
 * @param {{n: number, tracks: Array<{track: string, weight: number, due: number, candidates: number}>, minPerTrack?: number}} input
 * @returns {{quota: {[track: string]: number}, demand: {[track: string]: number}, weights: {[track: string]: number}, needMore: boolean, reasons: string[]}}
 */
function allocateQuota(input) {
  const src = input || {}
  const tracks = Array.isArray(src.tracks) ? src.tracks : []
  const n = Math.max(0, Math.trunc(Number(src.n) || 0))
  const minPerTrack =
    src.minPerTrack === undefined || src.minPerTrack === null
      ? 0
      : Math.max(0, Math.trunc(Number(src.minPerTrack)))

  const demand = {}
  const weights = {}
  const quota = {}
  const reasons = []

  if (tracks.length === 0) {
    return {
      quota: quota,
      demand: demand,
      weights: weights,
      needMore: true,
      reasons: ["没有可用的轨道，无法分配配额"],
    }
  }

  const rows = tracks.map(function (t) {
    const item = t || {}
    const track = String(item.track === undefined || item.track === null ? "" : item.track)
    const due = Math.max(0, Number(item.due) || 0)
    const candidates = Math.max(0, Math.trunc(Number(item.candidates) || 0))
    const weight = Math.max(0, Number(item.weight) || 0)
    const d = 1 + Math.min(1, due / 5)
    demand[track] = d
    weights[track] = weight * d
    quota[track] = 0
    return { track: track, due: due, candidates: candidates, weight: weights[track] }
  })

  const live = rows.filter(function (row) {
    return row.candidates > 0
  })
  const totalCandidates = rows.reduce(function (acc, row) {
    return acc + row.candidates
  }, 0)

  if (totalCandidates === 0) {
    reasons.push("没有可学的单元，建议去供给流水线补内容")
    return { quota: quota, demand: demand, weights: weights, needMore: true, reasons: reasons }
  }

  const weightItems = live.map(function (row) {
    return { key: row.track, weight: row.weight }
  })

  // 第一步：minPerTrack 保底（默认 0，等于不保底），剩下的名额按有效权重分
  let alloc = {}
  if (minPerTrack > 0) {
    const wants = live.map(function (row) {
      return { key: row.track, want: Math.min(minPerTrack, row.candidates) }
    })
    const reserved = wants.reduce(function (acc, w) {
      return acc + w.want
    }, 0)
    if (reserved >= n) {
      // 名额不够保底：按声明顺序每轨先给一个
      let left = n
      wants.forEach(function (w) {
        if (left > 0) {
          alloc[w.key] = 1
          left -= 1
        } else {
          alloc[w.key] = 0
        }
      })
    } else {
      const rest = largestRemainder(weightItems, n - reserved)
      wants.forEach(function (w) {
        alloc[w.key] = w.want + rest[w.key]
      })
    }
  } else {
    alloc = largestRemainder(weightItems, n)
  }

  // 第二步：候选不够的轨压到候选数，多出来的名额按有效权重分给仍有候选的轨
  let deficit = 0
  live.forEach(function (row) {
    if (alloc[row.track] > row.candidates) {
      deficit += alloc[row.track] - row.candidates
      alloc[row.track] = row.candidates
      reasons.push(
        labelOf(row.track) + "轨可学的单元不够（只有 " + row.candidates + " 个），多出来的名额分给了其它轨"
      )
    }
  })

  while (deficit > 0) {
    const receivers = live.filter(function (row) {
      return alloc[row.track] < row.candidates
    })
    if (receivers.length === 0) break
    const give = largestRemainder(
      receivers.map(function (row) {
        return { key: row.track, weight: row.weight }
      }),
      deficit
    )
    let moved = 0
    receivers.forEach(function (row) {
      const room = row.candidates - alloc[row.track]
      const take = Math.min(give[row.track], room)
      alloc[row.track] += take
      moved += take
    })
    if (moved === 0) break
    deficit -= moved
  }

  live.forEach(function (row) {
    quota[row.track] = alloc[row.track] || 0
  })

  const planned = live.reduce(function (acc, row) {
    return acc + quota[row.track]
  }, 0)
  if (planned < n) {
    reasons.push("可学的单元不够 " + n + " 个，这次只排 " + planned + " 个")
  }

  return {
    quota: quota,
    demand: demand,
    weights: weights,
    needMore: totalCandidates === 0 || totalCandidates < n,
    reasons: reasons,
  }
}

module.exports = { allocateQuota: allocateQuota, largestRemainder: largestRemainder }
```

```js
"use strict"
/**
 * prioritize.js —— 轨内优先级
 *
 * 一轨内部的排序键（从高到低）：
 *   1. 到期复习的单元（dueUnitIds）
 *   2. 当前轮次里未完成的单元（按 roundOrder 的下标）
 *   3. 其余新单元（掌握度升序——越弱越先；再按 id 升序）
 *   4. 已完成的单元排到最后（仍可被选，可能要重练）
 *
 * 纯函数：不碰数据库，同输入必同输出。
 */

/** 排位：数字越小越靠前 */
const RANK_DUE = 0
const RANK_ROUND = 1
const RANK_NEW = 2
const RANK_DONE = 3

/**
 * 把 Set 或数组统一成 Set。
 * @param {Set<string>|string[]|null|undefined} value
 * @returns {Set<string>}
 */
function toSet(value) {
  if (!value) return new Set()
  if (value instanceof Set) return value
  if (Array.isArray(value)) {
    const out = new Set()
    value.forEach(function (item) {
      out.add(String(item))
    })
    return out
  }
  return new Set()
}

/**
 * 读掌握度；没有记录按 0 算（0 = 越弱越先）。
 * @param {{[unitId: string]: number}} mastery
 * @param {string} id
 * @returns {number}
 */
function levelOf(mastery, id) {
  const raw = Number(mastery[id])
  if (!Number.isFinite(raw)) return 0
  return raw
}

/**
 * 给一轨的候选单元排出优先级顺序。
 * @param {Array<object>} units
 * @param {{dueUnitIds?: Set<string>|string[], currentRoundUnitIds?: Set<string>|string[], roundOrder?: string[], masteryByUnit?: {[unitId: string]: number}, doneUnitIds?: Set<string>|string[]}} ctx
 * @returns {Array<object>}
 */
function prioritize(units, ctx) {
  const c = ctx || {}
  const due = toSet(c.dueUnitIds)
  const round = toSet(c.currentRoundUnitIds)
  const done = toSet(c.doneUnitIds)
  const order = Array.isArray(c.roundOrder) ? c.roundOrder : []
  const mastery = c.masteryByUnit || {}

  const orderIndex = {}
  order.forEach(function (id, index) {
    orderIndex[String(id)] = index
  })

  const list = (units || []).slice()
  list.sort(function (a, b) {
    const ra = rankOf(a)
    const rb = rankOf(b)
    if (ra !== rb) return ra - rb
    if (ra === RANK_ROUND) {
      const ia = orderIndex[String(a.id)]
      const ib = orderIndex[String(b.id)]
      const va = ia === undefined ? Number.MAX_SAFE_INTEGER : ia
      const vb = ib === undefined ? Number.MAX_SAFE_INTEGER : ib
      if (va !== vb) return va - vb
    }
    if (ra === RANK_NEW) {
      const ma = levelOf(mastery, a.id)
      const mb = levelOf(mastery, b.id)
      if (ma !== mb) return ma - mb
    }
    const ida = String(a.id)
    const idb = String(b.id)
    if (ida < idb) return -1
    if (ida > idb) return 1
    return 0
  })
  return list

  /**
   * 一个单元的排位。
   * @param {object} unit
   * @returns {number}
   */
  function rankOf(unit) {
    const id = String(unit && unit.id)
    if (due.has(id)) return RANK_DUE
    if (done.has(id)) return RANK_DONE
    if (round.has(id)) return RANK_ROUND
    return RANK_NEW
  }
}

module.exports = { prioritize: prioritize }
```

```js
"use strict"
/**
 * queue.js —— 队列成形：把各轨的候选交错成一条队列
 *
 * 规则（契约 §6.2）：
 *   1. 轨内顺序由调用方给，本函数不重排
 *   2. 跨轨 round-robin 交错，按轨的配额取数
 *   3. 连续同轨上限 = 该轨配额的 2 倍（下限 2）；只剩一条轨有名额时上限不适用
 *   4. seq 从 1 开始连续
 *
 * 纯函数：同输入必同输出。
 */

/**
 * 把每轨的候选单元排成一条跨轨交错的队列。
 * @param {{quota: {[track: string]: number}, pools: {[track: string]: Array<object>}}} input
 * @returns {Array<{unit: object, track: string, seq: number}>}
 */
function buildQueue(input) {
  const src = input || {}
  const quota = src.quota || {}
  const pools = src.pools || {}
  const codes = Object.keys(quota)
  if (codes.length === 0) return []

  const states = codes.map(function (code) {
    const count = Math.max(0, Math.trunc(Number(quota[code]) || 0))
    return {
      code: code,
      quota: count,
      left: count,
      pool: Array.isArray(pools[code]) ? pools[code] : [],
      index: 0,
    }
  })

  const out = []
  let lastCode = null
  let streak = 0
  let cursor = 0

  while (true) {
    // 还有名额、并且池子里还有货的轨
    const alive = states.filter(function (s) {
      return s.left > 0 && s.index < s.pool.length
    })
    if (alive.length === 0) break

    let picked = null
    for (let step = 0; step < states.length; step++) {
      const idx = (cursor + step) % states.length
      const s = states[idx]
      if (s.left <= 0 || s.index >= s.pool.length) continue
      // 连续同轨上限 = 配额的两倍（下限 2）
      const cap = Math.max(2, 2 * s.quota)
      if (alive.length > 1 && s.code === lastCode && streak >= cap) continue
      picked = { state: s, index: idx }
      break
    }

    if (!picked) {
      // 只剩一条轨还有货：连续上限对它不适用，否则这条轨永远排不进去
      if (alive.length !== 1) break
      picked = { state: alive[0], index: states.indexOf(alive[0]) }
    }

    const s = picked.state
    const unit = s.pool[s.index]
    s.index += 1
    s.left -= 1
    out.push({ unit: unit, track: s.code, seq: out.length + 1 })

    if (s.code === lastCode) {
      streak += 1
    } else {
      lastCode = s.code
      streak = 1
    }
    cursor = (picked.index + 1) % states.length
  }

  return out
}

module.exports = { buildQueue: buildQueue }
```

```js
/**
 * 次数通道判定：units_since >= k。
 * 公式不动，只是多一条触发条件（契约 §6.4）。
 * @param {{units_since?: number}} card
 * @param {number} k 阈值 K
 * @returns {boolean}
 */
function isDueByCount(card, k) {
  const limit = Number(k)
  if (!Number.isFinite(limit) || limit <= 0) return false
  const since = Number(card && card.units_since)
  if (!Number.isFinite(since)) return false
  return since >= limit
}

/**
 * 所有卡的 units_since += n。
 * 返回新数组，不改原数组、不改原对象。
 * @param {Array<object>} cards
 * @param {number} [n]
 * @returns {Array<object>}
 */
function bumpUnitsSince(cards, n) {
  const step = n === undefined || n === null ? 1 : Math.trunc(Number(n))
  return (cards || []).map(function (card) {
    const out = Object.assign({}, card)
    const since = Number(out.units_since)
    out.units_since = (Number.isFinite(since) ? since : 0) + step
    return out
  })
}

/**
 * grade 的变体：跑完 SM-2 更新后把 units_since 归零，并把 unit_id 带走。
 * @param {object} card
 * @param {number} quality 0~5
 * @param {{nowIso?: string, k?: number}} opts
 * @returns {object}
 */
function gradeWithCount(card, quality, opts) {
  const options = opts || {}
  const graded = grade(card, quality, options.nowIso)
  graded.units_since = 0
  const src = card || {}
  const unitId = src.unit_id === undefined || src.unit_id === null ? "" : String(src.unit_id)
  if (unitId !== "") {
    graded.unit_id = unitId
  } else if (src.problem_id) {
    // 老卡只有 problem_id：带前缀的（db:mvcc / ai:cnn）原样用，
    // 不带前缀的（lc-00007）按算法轨补前缀
    const legacy = String(src.problem_id)
    graded.unit_id = legacy.indexOf(":") >= 0 ? legacy : "algo:" + legacy
  }
  return graded
}

/**
 * 双触发判定：日期通道 ∨ 次数通道。
 * @param {object} card
 * @param {string} nowIso
 * @param {number} k
 * @returns {boolean}
 */
function isDueEither(card, nowIso, k) {
  return isDue(card, nowIso) || isDueByCount(card, k)
}
```

```js
}

/**
 * 算出到期单元集合。
 * @param {Array<object>} cards review_cards 表的行
 * @param {{[unitId: string]: object}} unitsById 单元 id → unit
 * @param {{nowIso?: string, k?: number}} opts
 * @returns {{dueUnitIds: Set<string>, dueByTrack: {[track: string]: number}, unknownUnitIds: string[]}}
 */
function collectDue(cards, unitsById, opts) {
  const options = opts || {}
  const nowIso = options.nowIso || new Date().toISOString()
  const k = options.k === undefined || options.k === null ? 5 : Number(options.k)
  const byId = unitsById || {}
  const dueUnitIds = new Set()
  const dueByTrack = {}
  const unknownUnitIds = []
  const seenUnknown = new Set()

  ;(cards || []).forEach(function (card) {
    const unitId = resolveUnitId(card)
    if (unitId === "") return
    const due = isDue(card, nowIso) || isDueByCount(card, k)
    if (!due) return
    const unit = byId[unitId]
    if (!unit) {
      // 卡指向的单元已经不在库里：记下来，别让它悄悄消失
      if (!seenUnknown.has(unitId)) {
        seenUnknown.add(unitId)
        unknownUnitIds.push(unitId)
      }
      return
    }
    dueUnitIds.add(unitId)
    const track = String(unit.track || "")
    dueByTrack[track] = (dueByTrack[track] || 0) + 1
  })

  return { dueUnitIds: dueUnitIds, dueByTrack: dueByTrack, unknownUnitIds: unknownUnitIds }
}

/**
 * 按轨建候选池并统计。
 * @param {{units: Array<object>, progressByUnit?: {[unitId: string]: string}, dueUnitIds?: Set<string>|string[], tracks?: string[]}} input
 * @returns {{pools: {[track: string]: Array<object>}, counts: {[track: string]: {candidates: number, due: number}}, dueUnitIds: Set<string>}}
 */
function collectPools(input) {
  const src = input || {}
  const units = Array.isArray(src.units) ? src.units : []
  const progressByUnit = src.progressByUnit || {}
  const dueUnitIds = src.dueUnitIds instanceof Set ? src.dueUnitIds : new Set(src.dueUnitIds || [])
  const tracks =
    Array.isArray(src.tracks) && src.tracks.length > 0 ? src.tracks : TRACK_CODES.slice()

  const pools = {}
  const counts = {}
  tracks.forEach(function (track) {
    pools[track] = []
    counts[track] = { candidates: 0, due: 0 }
  })

  units.forEach(function (unit) {
    if (!unit) return
    const track = String(unit.track || "")
    if (!Object.prototype.hasOwnProperty.call(pools, track)) return
    const id = String(unit.id || "")
    if (id === "") return
    if (String(unit.status || "") !== "verified") return
    const progress = String(progressByUnit[id] || "todo")
    const due = dueUnitIds.has(id)
    if (progress === "done" && !due) return
    pools[track].push(unit)
    counts[track].candidates += 1
    if (due) counts[track].due += 1
  })

  return { pools: pools, counts: counts, dueUnitIds: dueUnitIds }
}

module.exports = {
  collectDue: collectDue,
  collectPools: collectPools,
  resolveUnitId: resolveUnitId,
}
```

```js
 * 会话行 → 会话对象（tracks 从 JSON 字符串还原成数组）。
 * @param {object|null} row
 * @returns {object|undefined}
 */
function toSession(row) {
  if (!row) return undefined
  let tracks = []
  try {
    const parsed = JSON.parse(String(row.tracks || "[]"))
    if (Array.isArray(parsed)) {
      tracks = parsed.map(function (t) {
        return String(t)
      })
    }
  } catch (err) {
    tracks = []
  }
  return {
    id: String(row.id),
    started_at: String(row.started_at),
    ended_at: row.ended_at === null || row.ended_at === undefined ? null : String(row.ended_at),
    planned_count: Number(row.planned_count || 0),
    done_count: Number(row.done_count || 0),
    tracks: tracks,
  }
}

/**
 * P1 的数据迁移（幂等）：
 *   1. 补齐 P0 该加的列（列不存在就 ALTER TABLE ADD COLUMN）
 *   2. 确保 sessions / session_queue 两张表在（DDL 抄自契约 §4.2）
 *   3. 给老行回填 unit_id（'algo:' || problem_id）
 *
 * 第 2 步是兜底：P0 的 SCHEMA 里已经有这两张表，CREATE TABLE IF NOT EXISTS 是幂等的，
 * 不会改动 P0 建出来的表；万一 P0 的 migrate 没跑到，P1 自己也活得下来。
 * @param {import("node:sqlite").DatabaseSync} db
 * @returns {{applied: string[], warnings: string[]}}
 */
function migrateUnitIds(db) {
  const applied = []
  const warnings = []

  const columnNames = function (table) {
    try {
      return db
        .prepare("PRAGMA table_info(" + table + ")")
        .all()
        .map(function (row) {
          return String(row.name)
        })
    } catch (err) {
      warnings.push("读不到 " + table + " 的列信息：" + String(err && err.message ? err.message : err))
      return []
    }
  }

  const ensureColumn = function (table, column, ddl) {
    if (columnNames(table).indexOf(column) !== -1) return
    db.exec(ddl)
    applied.push(ddl)
  }

  ensureColumn("attempts", "unit_id", "ALTER TABLE attempts ADD COLUMN unit_id TEXT")
  ensureColumn(
    "attempts",
    "track",
    "ALTER TABLE attempts ADD COLUMN track TEXT NOT NULL DEFAULT 'algorithm'"
  )
  ensureColumn(
    "attempts",
    "assert_total",
    "ALTER TABLE attempts ADD COLUMN assert_total INTEGER NOT NULL DEFAULT 0"
  )
  ensureColumn(
    "attempts",
    "assert_passed",
    "ALTER TABLE attempts ADD COLUMN assert_passed INTEGER NOT NULL DEFAULT 0"
  )
  ensureColumn("review_cards", "unit_id", "ALTER TABLE review_cards ADD COLUMN unit_id TEXT")
  ensureColumn(
    "review_cards",
    "units_since",
    "ALTER TABLE review_cards ADD COLUMN units_since INTEGER NOT NULL DEFAULT 0"
  )

  const sessionTables = [
    `CREATE TABLE IF NOT EXISTS sessions (
       id            TEXT PRIMARY KEY,
       started_at    TEXT NOT NULL,
       ended_at      TEXT,
       planned_count INTEGER NOT NULL DEFAULT 0,
       done_count    INTEGER NOT NULL DEFAULT 0,
       tracks        TEXT NOT NULL DEFAULT ''
     )`,
    `CREATE TABLE IF NOT EXISTS session_queue (
       session_id TEXT NOT NULL,
       unit_id    TEXT NOT NULL,
       seq        INTEGER NOT NULL,
       state      TEXT NOT NULL DEFAULT 'pending',
       PRIMARY KEY (session_id, unit_id)
     )`,
  ]
  sessionTables.forEach(function (ddl) {
    db.exec(ddl)
  })

  const backfill = [
    "UPDATE attempts SET unit_id = 'algo:' || problem_id WHERE unit_id IS NULL AND problem_id NOT LIKE '%:%'",
    "UPDATE review_cards SET unit_id = 'algo:' || problem_id WHERE unit_id IS NULL AND problem_id NOT LIKE '%:%'",
  ]
  backfill.forEach(function (sql) {
    db.exec(sql)
    applied.push(sql)
  })

  return { applied: applied, warnings: warnings }
}
```

```js
"use strict"
/**
 * plan.js —— 组装一次会话的学习计划
 *
 * 把「谁到期了 → 谁最该学 → 这次排几个 → 怎么交错」串成一步：
 *   1. 到期集合（日期通道 ∨ 次数通道）
 *   2. 环境门禁（缺 numpy 的单元不进池）
 *   3. 候选池（verified ∧（未完成 ∨ 到期））
 *   4. 轨内优先级（到期 > 当前轮次 > 新单元）
 *   5. 跨轨配额（最大余数法）
 *   6. 跨轨交错成一条队列
 *
 * 纯函数：不读数据库、不读盘、不读时钟（nowIso 由调用方给）。
 */

const { allocateQuota } = require("./quota.js")
const { buildQueue } = require("./queue.js")
const { prioritize } = require("./prioritize.js")
const { collectDue, collectPools } = require("./pool.js")

/**
 * 这个单元要不要 numpy。
 * AI 轨的 13 张卡全部 import numpy；数据库轨只有 clustering 这张要（契约 §14.1）。
 * @param {object} unit
 * @returns {string} 需要 numpy 时给一句中文说明；不需要则空串
 */
function numpyRequirement(unit) {
  const id = String((unit && unit.id) || "")
  const track = String((unit && unit.track) || "")
  if (track === "ai") return "AI 轨的卡依赖 numpy"
  if (id === "db:clustering") return "这张卡依赖 numpy"
  return ""
}

/**
 * 单元索引：按 id、按去前缀的 id、按标题各建一张表。
 * @param {{[unitId: string]: object}} unitsById
 * @returns {{byId: Map, byStem: Map, byTitle: Map}}
 */
function buildUnitIndex(unitsById) {
  const byId = new Map()
  const byStem = new Map()
  const byTitle = new Map()
  Object.keys(unitsById || {}).forEach(function (id) {
    const unit = unitsById[id]
    byId.set(String(id), unit)
    const text = String(id)
    const stem = text.indexOf(":") >= 0 ? text.slice(text.indexOf(":") + 1) : text
    if (!byStem.has(stem)) byStem.set(stem, unit)
    const title = String((unit && unit.title) || "")
    if (title && !byTitle.has(title)) byTitle.set(title, unit)
  })
  return { byId: byId, byStem: byStem, byTitle: byTitle }
}

/**
 * 轮次条目对上单元：先按 id，再按去前缀的 id，再按标题。
 * @param {object} item
 * @param {{byId: Map, byStem: Map, byTitle: Map}} index
 * @returns {object|null}
 */
function matchUnit(item, index) {
  if (!item) return null
  const id = String(item.id || "")
  if (id && index.byId.has(id)) return index.byId.get(id)
  if (id && index.byStem.has(id)) return index.byStem.get(id)
  const title = String(item.title || "")
  if (title && index.byTitle.has(title)) return index.byTitle.get(title)
  return null
}

/**
 * 当前轮次上下文：哪些单元在当前轮次里、排第几、哪些已经做完。
 * @param {Array<object>} rounds parseRounds 的 rounds
 * @param {{[unitId: string]: object}} unitsById
 * @returns {{currentRoundUnitIds: Set<string>, roundOrder: string[], doneUnitIds: Set<string>, roundId: string}}
 */
function roundContext(rounds, unitsById) {
  const out = {
    currentRoundUnitIds: new Set(),
    roundOrder: [],
    doneUnitIds: new Set(),
    roundId: "",
  }
  const list = Array.isArray(rounds) ? rounds : []
  if (list.length === 0) return out
  let round = null
  list.forEach(function (r) {
    if (!round && r && r.status === "active") round = r
  })
  if (!round) round = list[list.length - 1]
  if (!round) return out
  out.roundId = String(round.id || "")
  const index = buildUnitIndex(unitsById)
  ;(round.items || []).forEach(function (item) {
    const unit = matchUnit(item, index)
    if (!unit) return
    const unitId = String(unit.id)
    out.roundOrder.push(unitId)
    if (String(item.status) === "done") out.doneUnitIds.add(unitId)
    else out.currentRoundUnitIds.add(unitId)
  })
  return out
}

/**
 * 排一次会话的完整计划。
 * @param {{
 *   n: number,
 *   nowIso: string,
 *   k: number,
 *   units: Array<object>,
 *   progressByUnit?: {[unitId: string]: string},
 *   cards?: Array<object>,
 *   masteryByUnit?: {[unitId: string]: number},
 *   rounds?: Array<object>,
 *   tracks: Array<{code: string, label: string, weight: number, enabled: boolean}>,
 *   env?: {numpy?: {ok: boolean}}
 * }} input
 * @returns {object} 计划
 */
function buildPlan(input) {
  const src = input || {}
  const nowIso = src.nowIso || new Date().toISOString()
  const k = Number(src.k === undefined || src.k === null ? 5 : src.k)
  const n = Number(src.n === undefined || src.n === null ? 3 : src.n)
  const units = Array.isArray(src.units) ? src.units : []
  const progressByUnit = src.progressByUnit || {}
  const cards = Array.isArray(src.cards) ? src.cards : []
  const masteryByUnit = src.masteryByUnit || {}
  const tracks = Array.isArray(src.tracks) ? src.tracks : []
  const numpyOk = !!(src.env && src.env.numpy && src.env.numpy.ok)
  const warnings = []

  const unitsById = {}
  units.forEach(function (unit) {
    if (unit && unit.id) unitsById[String(unit.id)] = unit
  })

  // 1. 到期集合（日期通道 ∨ 次数通道）
  const due = collectDue(cards, unitsById, { nowIso: nowIso, k: k })
  if (due.unknownUnitIds.length > 0) {
    warnings.push("有 " + due.unknownUnitIds.length + " 张复习卡指向了已不存在的单元，已跳过")
  }

  // 2. 环境门禁：缺 numpy 的单元不进池
  const kept = []
  units.forEach(function (unit) {
    const need = numpyRequirement(unit)
    if (need && !numpyOk) {
      const title = String((unit && unit.title) || (unit && unit.id) || "")
      warnings.push("「" + title + "」" + need + "，环境缺失，这次跳过")
      return
    }
    kept.push(unit)
  })

  // 3. 候选池
  const raw = collectPools({
    units: kept,
    progressByUnit: progressByUnit,
    dueUnitIds: due.dueUnitIds,
  })

  // 4. 轮次上下文与已完成集合
  const round = roundContext(src.rounds, unitsById)
  const doneUnitIds = new Set()
  Object.keys(progressByUnit).forEach(function (id) {
    if (String(progressByUnit[id]) === "done") doneUnitIds.add(id)
  })
  round.doneUnitIds.forEach(function (id) {
    doneUnitIds.add(id)
  })

  // 5. 轨内优先级
  const pools = {}
  tracks.forEach(function (t) {
    const code = String(t.code)
    pools[code] = prioritize(raw.pools[code] || [], {
      dueUnitIds: due.dueUnitIds,
      currentRoundUnitIds: round.currentRoundUnitIds,
      roundOrder: round.roundOrder,
      masteryByUnit: masteryByUnit,
      doneUnitIds: doneUnitIds,
    })
  })

  // 6. 跨轨配额（关掉的轨不参与）
  const quotaInput = tracks
    .filter(function (t) {
      return t.enabled !== false
    })
    .map(function (t) {
      const code = String(t.code)
      const c = raw.counts[code] || { candidates: 0, due: 0 }
      return {
        track: code,
        weight: Number(t.weight || 0),
        due: c.due,
        candidates: c.candidates,
      }
    })
  const quota = allocateQuota({ n: n, tracks: quotaInput, minPerTrack: 0 })
  warnings.push.apply(warnings, quota.reasons)

  // 7. 跨轨交错成一条队列
  const queue = buildQueue({ quota: quota.quota, pools: pools })

  const quotaOut = {}
  tracks.forEach(function (t) {
    const code = String(t.code)
    quotaOut[code] = quota.quota[code] || 0
  })

  return {
    quota: quotaOut,
    demand: quota.demand,
    weights: quota.weights,
    needMore: quota.needMore,
    queue: queue,
    dueUnitIds: due.dueUnitIds,
    currentRoundUnitIds: round.currentRoundUnitIds,
    roundOrder: round.roundOrder,
    roundId: round.roundId,
    doneUnitIds: doneUnitIds,
    counts: raw.counts,
    warnings: warnings,
  }
```

```js
/**
 * 探测 Python 与 numpy。
 * spawn 与 python 都可注入——测试用假实现，不碰真环境。
 * @param {{spawn?: Function, python?: object|null, override?: string|null}} opts
 * @returns {{python: {ok: boolean, detail: string}, numpy: {ok: boolean, detail: string}}}
 */
function probeEnv(opts) {
  const options = opts || {}
  const spawn = options.spawn || spawnSync
  const python =
    options.python !== undefined ? options.python : detectPython(options.override || null)
  if (!python) {
    return {
      python: { ok: false, detail: "没找到 Python 解释器（python3 / python / py -3）" },
      numpy: { ok: false, detail: "没有 Python 解释器，依赖 numpy 的单元这次跳过" },
    }
  }
  const cmd = String(python.cmd)
  const args = Array.isArray(python.args) ? python.args.slice() : []
  let numpyOk = false
  let numpyDetail = ""
  try {
    const res = spawn(cmd, args.concat(["-c", "import numpy"]), {
      encoding: "utf8",
      timeout: 5000,
    })
    numpyOk = !!(res && res.status === 0)
    numpyDetail = numpyOk
      ? "numpy 可用（" + cmd + "）"
      : "缺 numpy：" + String((res && res.stderr) || "导入失败").trim().split("\n")[0]
  } catch (err) {
    numpyOk = false
    numpyDetail = "numpy 探测失败：" + String(err && err.message ? err.message : err)
  }
  return {
    python: { ok: true, detail: cmd + (args.length ? " " + args.join(" ") : "") },
    numpy: { ok: numpyOk, detail: numpyDetail },
  }
}

  let cached = null
  return function () {
    if (!cached) {
      cached = probeEnv({ override: ctx.store.getSetting(KEY_PYTHON) || null })
    }
    return cached
  }
}

/**
 * 读轮次清单（没连 learning 仓就空数组）。
 * @param {object} ctx
 * @returns {Array<object>}
 */
function loadRounds(ctx) {
  if (!ctx.learning || !ctx.learning.ok || !ctx.learning.root) return []
  try {
    const parsed = parseRounds(path.join(ctx.learning.root, "progress"))
    return parsed.rounds || []
  } catch (err) {
    return []
  }
}

/**
 * 把 store 里的数据凑成 buildPlan 的入参。
 * @param {object} ctx
 * @param {{n: number, nowIso: string, env: object}} opts
 * @returns {object}
 */
function buildPlanInput(ctx, opts) {
  const store = ctx.store
  const progressByUnit = {}
  store.listUnitProgress().forEach(function (row) {
    progressByUnit[String(row.unit_id)] = String(row.progress)
  })
  const masteryByUnit = {}
  store.listMastery("unit").forEach(function (row) {
    masteryByUnit[String(row.scope_id)] = Number(row.level || 0)
  })
  return {
    n: opts.n,
    nowIso: opts.nowIso,
    k: readInt(store, KEY_COUNT_K, DEFAULT_COUNT_K),
    units: store.listUnits(),
    progressByUnit: progressByUnit,
    cards: store.listReviewCards(),
    masteryByUnit: masteryByUnit,
    rounds: loadRounds(ctx),
    tracks: trackSettings(store),
    env: opts.env,
  }
}

function newSessionId() {
  return "s-" + Date.now().toString(36) + "-" + crypto.randomBytes(4).toString("hex")
}

/**
 * 下一个该做的单元：优先 current，其次第一个 pending。
 * @param {Array<object>} queue
 * @returns {object|null}
 */
function pickNext(queue) {
  let current = null
  let firstPending = null
  ;(queue || []).forEach(function (item) {
    if (!current && item.state === "current") current = item
    if (!firstPending && item.state === "pending") firstPending = item
  })
  return current || firstPending || null
}

/**
 * 队列里还没做完的项数。
 * @param {Array<object>} queue
 * @returns {number}
 */
function unfinishedCount(queue) {
  let n = 0
  ;(queue || []).forEach(function (item) {
    if (item.state === "pending" || item.state === "current") n += 1
  })
  return n
}

/**
 * 队列项 → 给前端看的行。
 *
 * 冻结形状是 `{unit_id, seq, state}`；这里**额外**补 `title` 与 `track`
 * （契约 §8.2.3）——首页要显示「当前会话的这几个单元」，光有 id 没法给人看。
 * 单元不在 units 表里时 title 回落成 unit_id、track 给空串。
 * @param {object} store
 * @param {string} sessionId
 * @returns {Array<{unit_id: string, seq: number, state: string, title: string, track: string}>}
 */
function queueRows(store, sessionId) {
  return store.listQueue(sessionId).map(function (item) {
    const unit = store.getUnit(item.unit_id) || {}
    return {
      unit_id: String(item.unit_id),
      seq: Number(item.seq),
      state: String(item.state),
      title: String(unit.title || item.unit_id),
      track: String(unit.track || ""),
    }
  })
}

/**
 * 找「还能接着做」的会话：最近一个还有没做完的项的会话。
 * @param {object} ctx
 * @returns {{session: object, queue: Array<object>}|null}
 */
function findResumable(ctx) {
  const sessions = ctx.store.listSessions(20)
  for (let i = 0; i < sessions.length; i += 1) {
    const queue = ctx.store.listQueue(sessions[i].id)
    if (unfinishedCount(queue) > 0) {
      return { session: sessions[i], queue: queue }
    }
  }
  return null
}

/**
 * 卡片对上单元 id（优先 unit_id，其次 problem_id）。
 * @param {Array<object>} cards
 * @param {string} unitId
 * @returns {object|null}
 */
function findCardByUnit(cards, unitId) {
  let found = null
  ;(cards || []).forEach(function (card) {
    if (!found && resolveUnitId(card) === String(unitId)) found = card
  })
  return found
}

/**
 * 新建卡时的 problem_id。
 *
 * `review_cards.problem_id` 是主键，而算法轨的老卡用的是**不带前缀**的
 * `lc-00001`——如果新卡用带前缀的 `algo:lc-00001` 当主键，同一个单元就会
 * 出现两行卡（老行 + 新行），复习调度会重复计数。
 * 所以：算法轨沿用旧约定（去掉 algo: 前缀），其它轨用完整单元 id。
 * @param {string} unitId
 * @returns {string}
 */
function cardProblemId(unitId) {
  const text = String(unitId || "")
  const idx = text.indexOf(":")
  if (idx < 0) return text
  const prefix = text.slice(0, idx)
  const stem = text.slice(idx + 1)
  return prefix === "algorithm" ? stem : text
}

/**
 * 设置页要的那一份数据。
 * @param {object} ctx
 * @param {object} env
 * @returns {object}
 */
function settingsPayload(ctx, env) {
  const store = ctx.store
  const unitCounts = {}
  store.listUnits().forEach(function (unit) {
    const track = String(unit.track || "")
    unitCounts[track] = (unitCounts[track] || 0) + 1
  })
  return {
    session: {
      default_count: readInt(store, KEY_SESSION_COUNT, DEFAULT_SESSION_COUNT),
      min_count: readInt(store, KEY_SESSION_MIN, DEFAULT_SESSION_MIN),
      max_count: readInt(store, KEY_SESSION_MAX, DEFAULT_SESSION_MAX),
    },
    tracks: trackSettings(store).map(function (t) {
      return {
        code: t.code,
        label: t.label,
        weight: t.weight,
        enabled: t.enabled,
        unit_count: unitCounts[t.code] || 0,
      }
    }),
    review: { count_trigger_k: readInt(store, KEY_COUNT_K, DEFAULT_COUNT_K) },
    env: env,
    warnings: [],
  }
}

/**
 * 组装路由表。
 * @param {{store: object, learning: object, sendJson: Function, envProbe?: Function}} ctx
 * @returns {Array<{method: string, pattern: string, handler: Function}>}
 */
function buildRoutes(ctx) {
  const routes = []
  const envProbe = ctx.envProbe || createEnvProbe(ctx)
  const nowIso = function () {
    return new Date().toISOString()
  }

  /* ---------- POST /api/session/start ---------- */

  routes.push({
    method: "POST",
    pattern: "/api/session/start",
    handler: async function (req, res) {
      const body = await readJsonBody(req)
      const store = ctx.store
      const min = readInt(store, KEY_SESSION_MIN, DEFAULT_SESSION_MIN)
      const max = readInt(store, KEY_SESSION_MAX, DEFAULT_SESSION_MAX)
      let n = readInt(store, KEY_SESSION_COUNT, DEFAULT_SESSION_COUNT)
      if (body.n !== undefined && body.n !== null && body.n !== "") {
        n = Number(body.n)
        if (!Number.isInteger(n) || n < min || n > max) {
          ctx.sendJson(res, 400, { error: "会话长度必须是 1~10 的整数" })
          return
        }
      }

      // 接着上次没做完的（reset 为 true 才重排）
      if (body.reset !== true) {
        const resumable = findResumable(ctx)
        if (resumable) {
          ctx.sendJson(res, 200, {
            session: resumable.session,
            queue: queueRows(store, resumable.session.id),
            quota: {},
            warnings: ["接着上次没做完的会话继续"],
          })
          return
        }
      }

      const startedAt = nowIso()
      const plan = buildPlan(
        buildPlanInput(ctx, { n: n, nowIso: startedAt, env: envProbe() })
      )
      if (plan.queue.length === 0) {
        const warnings = plan.warnings.slice()
        if (warnings.join(" ").indexOf("没有可学的单元，建议去供给流水线补内容") === -1) {
          warnings.push("没有可学的单元，建议去供给流水线补内容")
        }
        ctx.sendJson(res, 200, {
          session: null,
          queue: [],
          quota: plan.quota,
          warnings: warnings,
        })
        return
      }

      const sessionId = newSessionId()
      const tracks = Object.keys(plan.quota).filter(function (code) {
        return plan.quota[code] > 0
      })
      store.insertSession({
        id: sessionId,
        started_at: startedAt,
        planned_count: plan.queue.length,
        done_count: 0,
        tracks: tracks,
      })
      store.replaceQueue(
        sessionId,
        plan.queue.map(function (item, index) {
          return {
            unit_id: String(item.unit.id),
            seq: item.seq,
            state: index === 0 ? "current" : "pending",
          }
        })
      )
      ctx.sendJson(res, 200, {
        session: store.getSession(sessionId),
        queue: queueRows(store, sessionId),
        quota: plan.quota,
        warnings: plan.warnings,
      })
    },
  })

  /* ---------- GET /api/session ---------- */

  routes.push({
    method: "GET",
    pattern: "/api/session",
    handler: async function (req, res) {
      const sessions = ctx.store.listSessions(1)
      const session = sessions.length > 0 ? sessions[0] : null
      if (!session) {
        ctx.sendJson(res, 200, {
          session: null,
          queue: [],
          next: null,
          notice: "",
          warnings: [],
        })
        return
      }
      const queue = queueRows(ctx.store, session.id)
      const next = pickNext(queue)
      const left = unfinishedCount(queue)
      ctx.sendJson(res, 200, {
        session: session,
        queue: queue,
        next: next ? { unit_id: next.unit_id, seq: next.seq, total: queue.length } : null,
        notice: left > 0 ? "上次还有 " + left + " 个没做完" : "",
        warnings: [],
      })
    },
  })

  /* ---------- GET /api/session/next ---------- */

  routes.push({
    method: "GET",
    pattern: "/api/session/next",
    handler: async function (req, res) {
      const sessions = ctx.store.listSessions(1)
      const session = sessions.length > 0 ? sessions[0] : null
      if (!session) {
        ctx.sendJson(res, 200, { unit: null, seq: 0, total: 0, reason: "还没有会话" })
        return
      }
      const queue = queueRows(ctx.store, session.id)
      const next = pickNext(queue)
      if (!next) {
        ctx.sendJson(res, 200, {
          unit: null,
          seq: 0,
          total: queue.length,
          reason: "这一轮的单元都做完了",
        })
        return
      }
      const unit = ctx.store.getUnit(next.unit_id) || null
      const plan = buildPlan(
        buildPlanInput(ctx, { n: 1, nowIso: nowIso(), env: envProbe() })
      )
      let reason = "新单元，先把掌握度补上来"
      if (plan.dueUnitIds.has(next.unit_id)) reason = "到期复习，先把这张过一遍"
      else if (plan.currentRoundUnitIds.has(next.unit_id)) reason = "当前轮次里的下一个"
      ctx.sendJson(res, 200, {
        unit: unit,
        seq: next.seq,
        total: queue.length,
        reason: reason,
      })
    },
  })

  /* ---------- POST /api/session/pause ---------- */

  routes.push({
    method: "POST",
    pattern: "/api/session/pause",
    handler: async function (req, res) {
      const store = ctx.store
      const open = store.getLatestOpenSession()
      const resumable = findResumable(ctx)
      const target = open || (resumable ? resumable.session : null)
      if (!target) {
        ctx.sendJson(res, 200, { session: null, queue: [] })
        return
      }
      store.updateSession(target.id, { ended_at: nowIso() })
      ctx.sendJson(res, 200, {
        session: store.getSession(target.id),
        queue: queueRows(store, target.id),
      })
    },
  })

  /* ---------- POST /api/session/submit ---------- */

  routes.push({
    method: "POST",
    pattern: "/api/session/submit",
    handler: async function (req, res) {
      const body = await readJsonBody(req)
      const unitId = String(
        body.unit_id === undefined || body.unit_id === null ? "" : body.unit_id
      ).trim()
      if (unitId === "") {
        ctx.sendJson(res, 400, { error: "缺少 unit_id" })
        return
      }
      const store = ctx.store
      const sessions = store.listSessions(1)
      const session = sessions.length > 0 ? sessions[0] : null
      if (!session) {
        ctx.sendJson(res, 400, { error: "这个单元不在当前会话里" })
        return
      }
      const queue = queueRows(store, session.id)
      let item = null
      queue.forEach(function (q) {
        if (!item && q.unit_id === unitId) item = q
      })
      if (!item) {
        ctx.sendJson(res, 400, { error: "这个单元不在当前会话里" })
        return
      }

      const at = nowIso()

      // 重复提交：不再重复记账，原样回一个结果
      if (item.state === "done") {
        const next = pickNext(queue)
        ctx.sendJson(res, 200, {
          ok: true,
          judged: false,
          verdict: null,
          passed: 0,
          total: 0,
          message: "这个单元已经完成过了",
          failed: null,
          stdout: "",
          next: next ? { unit_id: next.unit_id, seq: next.seq, total: queue.length } : null,
          session: store.getSession(session.id),
          due: [],
          warnings: [],
        })
        return
      }

      // 1. 队列项置 done，done_count 跟着走
      store.updateQueueItem(session.id, unitId, { state: "done" })
      store.updateSession(session.id, { done_count: store.countQueueDone(session.id) })

      // 2. 单元进度置 done
      store.upsertUnitProgress(unitId, "done", at)

      // 3. 所有复习卡 units_since += 1（任何轨完成一个单元都算）
      const k = readInt(store, KEY_COUNT_K, DEFAULT_COUNT_K)
      const cards = store.listReviewCards()
      const newlyDue = []
      cards.forEach(function (card) {
        const before = Number(card.units_since || 0)
        if (before + 1 >= k && before < k) {
          const id = resolveUnitId(card)
          if (id) newlyDue.push(id)
        }
      })
      bumpUnitsSince(cards, 1).forEach(function (card) {
        store.upsertReviewCard({
          problem_id: String(card.problem_id),
          unit_id: card.unit_id === undefined || card.unit_id === null ? null : String(card.unit_id),
          easiness: Number(card.easiness),
          interval_days: Number(card.interval_days),
          repetitions: Number(card.repetitions),
          last_quality:
            card.last_quality === null || card.last_quality === undefined
              ? null
              : Number(card.last_quality),
          last_at: card.last_at === null || card.last_at === undefined ? null : String(card.last_at),
          next_review_at: String(card.next_review_at),
          lapses: Number(card.lapses || 0),
          units_since: Number(card.units_since || 0),
        })
      })

      // 4. 被提交的单元自己的卡：跑一次 SM-2 更新，units_since 归零
      const own = findCardByUnit(cards, unitId)
      const ownCard = own || {
        problem_id: cardProblemId(unitId),
        unit_id: unitId,
        easiness: 2.5,
        interval_days: 0,
        repetitions: 0,
        last_quality: null,
        last_at: null,
        next_review_at: at,
        lapses: 0,
        units_since: 0,
      }
      const graded = gradeWithCount(ownCard, P1_REVIEW_QUALITY, { nowIso: at })
      store.upsertReviewCard({
        problem_id: String(graded.problem_id),
        unit_id: String(graded.unit_id),
        easiness: Number(graded.easiness),
        interval_days: Number(graded.interval_days),
        repetitions: Number(graded.repetitions),
        last_quality: Number(graded.last_quality),
        last_at: String(graded.last_at),
        next_review_at: String(graded.next_review_at),
        lapses: Number(graded.lapses || 0),
        units_since: Number(graded.units_since || 0),
      })

      // 5. 下一个 pending 置 current
      const afterDone = store.listQueue(session.id)
      const nextItem = pickNext(afterDone)
      if (nextItem && nextItem.state === "pending") {
        store.updateQueueItem(session.id, nextItem.unit_id, { state: "current" })
      }

      // 6. 队列空了就把会话关掉
      const finalQueue = store.listQueue(session.id)
      if (unfinishedCount(finalQueue) === 0) {
        store.updateSession(session.id, { ended_at: at })
      }

      const next = pickNext(finalQueue)
      const unit = store.getUnit(unitId)
      ctx.sendJson(res, 200, {
        ok: true,
        judged: false,
        verdict: null,
        passed: 0,
        total: 0,
        message: "「" + String((unit && unit.title) || unitId) + "」已记为完成",
        failed: null,
        stdout: "",
        next: next ? { unit_id: next.unit_id, seq: next.seq, total: finalQueue.length } : null,
        session: store.getSession(session.id),
        due: newlyDue,
        warnings: [],
      })
    },
  })

  /* ---------- GET /api/settings ---------- */

  routes.push({
    method: "GET",
    pattern: "/api/settings",
    handler: async function (req, res) {
      ctx.sendJson(res, 200, settingsPayload(ctx, envProbe()))
    },
  })

  /* ---------- PUT /api/settings ---------- */

  routes.push({
    method: "PUT",
    pattern: "/api/settings",
    handler: async function (req, res) {
      const body = await readJsonBody(req)
      const store = ctx.store

      if (body.session_count !== undefined && body.session_count !== null) {
        const n = Number(body.session_count)
        if (!Number.isInteger(n) || n < DEFAULT_SESSION_MIN || n > DEFAULT_SESSION_MAX) {
          ctx.sendJson(res, 400, { error: "会话长度必须是 1~10 的整数" })
          return
        }
        store.setSetting(KEY_SESSION_COUNT, String(n))
      }

      if (body.track_weights !== undefined && body.track_weights !== null) {
        const weights = body.track_weights
        if (typeof weights !== "object" || Array.isArray(weights)) {
          ctx.sendJson(res, 400, { error: "轨权重必须是不小于 0 的数字" })
          return
        }
        const codes = Object.keys(weights)
        for (let i = 0; i < codes.length; i += 1) {
          const value = Number(weights[codes[i]])
          if (!Number.isFinite(value) || value < 0) {
            ctx.sendJson(res, 400, { error: "轨权重必须是不小于 0 的数字" })
            return
          }
        }
        codes.forEach(function (code) {
          store.setSetting(weightKey(code), String(Number(weights[code])))
        })
      }

      if (body.track_enabled !== undefined && body.track_enabled !== null) {
        const enabled = body.track_enabled
        if (typeof enabled !== "object" || Array.isArray(enabled)) {
          ctx.sendJson(res, 400, { error: "轨开关必须是布尔值" })
          return
        }
        const codes = Object.keys(enabled)
        for (let i = 0; i < codes.length; i += 1) {
          if (typeof enabled[codes[i]] !== "boolean") {
            ctx.sendJson(res, 400, { error: "轨开关必须是布尔值" })
            return
          }
        }
        codes.forEach(function (code) {
          store.setSetting(enabledKey(code), enabled[code] ? "1" : "0")
        })
      }

      if (body.count_trigger_k !== undefined && body.count_trigger_k !== null) {
        const k = Number(body.count_trigger_k)
        if (!Number.isInteger(k) || k < 1) {
          ctx.sendJson(res, 400, { error: "次数阈值 K 必须是大于等于 1 的整数" })
          return
        }
        store.setSetting(KEY_COUNT_K, String(k))
      }

      ctx.sendJson(res, 200, settingsPayload(ctx, envProbe()))
    },
  })

  return routes
}

module.exports = {

  settingsPayload: settingsPayload,
}
```

```js
/**
 * 最小 hash 解析器（契约 §9.2）。
 *
 *   ""                        → { page: "session", params: {}, query: {} }
 *   "#/"                      → { page: "session", ... }
 *   "#/settings"              → { page: "settings", ... }
 *   "#/unit/algo%3Algc-00007" → { page: "unit", params: { id: "algo:lc-00007" }, ... }
 *   "#/library?track=database"→ { page: "library", query: { track: "database" }, ... }
 *
 * P1 只用到 page；params / query 是给 P2 的单元页与单元库留的。
 * @param {string} [hash] 不传就取 location.hash
 * @returns {{page: string, params: object, query: object}}
 */
function parseHash(hash) {
  const raw = hash === undefined || hash === null ? "" : String(hash)
  const text = raw.charAt(0) === "#" ? raw.slice(1) : raw
  const qIndex = text.indexOf("?")
  const pathPart = qIndex === -1 ? text : text.slice(0, qIndex)
  const queryPart = qIndex === -1 ? "" : text.slice(qIndex + 1)

  const query = {}
  new URLSearchParams(queryPart).forEach(function (value, key) {
    query[key] = value
  })

  const segments = pathPart.split("/").filter(function (part) {
    return part !== ""
  })
  const page = segments.length > 0 ? segments[0] : "session"
  const params = {}
  if (segments.length > 1) params.id = decodeURIComponent(segments[1])
  if (segments.length > 2) {
    params.rest = segments.slice(2).map(function (part) {
      return decodeURIComponent(part)
    })
  }
  return { page: page, params: params, query: query }
}

/**
 * 按 hash 定当前页。页没注册就不动（返回 false）。
 * @param {string} [hash] 不传就取 location.hash
 * @returns {boolean} 有没有定成功
 */
function applyHash(hash) {
  const raw =
    hash === undefined || hash === null
      ? typeof location !== "undefined"
        ? location.hash
        : ""
      : String(hash)
  const parsed = parseHash(raw)
  if (!window.StudyHub.pages[parsed.page]) return false
  activeTab = parsed.page
  return true
```

```js
    current: { mark: "▶", label: "正在学", cls: "queue-current", tone: "warn" },
    pending: { mark: "○", label: "还没开始", cls: "queue-pending", tone: "" },
    skipped: { mark: "—", label: "已跳过", cls: "queue-skipped", tone: "" },
  }

  /** 轨代码 → 中文标签 */
  const TRACK_LABEL = { algorithm: "算法", database: "数据库", ai: "AI" }

  /**
   * 会话行 → 给界面看的描述。
   *
   * 纯函数：不碰 DOM，能单测。title 取不到时回落成 unit_id——
   * 单元不在 units 表里也是这个回落。
   *
   * @param {object} item 队列项 `{ unit_id, seq, state, title, track }`
   * @param {number} index 下标（seq 缺失时用它兜底）
   * @returns {{seq: number, unit_id: string, title: string, track: string, state: string, mark: string, label: string, tone: string, cls: string}}
   */
  function describeQueueItem(item, index) {
    const it = item || {}
    const state = String(it.state || "pending")
    const conf = STATE_TEXT[state] || STATE_TEXT.pending
    const seq = Number(it.seq)
    return {
      seq: seq > 0 ? seq : Number(index) + 1,
      unit_id: String(it.unit_id || ""),
      title: String(it.title || it.unit_id || ""),
      track: String(it.track || ""),
      state: state,
      mark: conf.mark,
      label: conf.label,
      tone: conf.tone,
      cls: conf.cls,
    }
  }

  /**
   * 队列 → 行数组。
   * @param {Array<object>} queue
   * @returns {Array<object>}
   */
  function buildQueueRows(queue) {
    return (queue || []).map(function (item, index) {
      return describeQueueItem(item, index)
    })
  }

  /**
   * 队列概况：总共几个、做完几个、正在学几个、还剩几个。
   * @param {Array<object>} rows
   * @returns {{total: number, done: number, current: number, left: number}}
   */
  function queueSummary(rows) {
    const list = rows || []
    let done = 0
    let current = 0
    list.forEach(function (row) {
      if (row.state === "done") done += 1
      else if (row.state === "current") current += 1
    })
    return { total: list.length, done: done, current: current, left: list.length - done }
  }

  /**
   * 每轨这次排了几个、该轨一共能学几个。
   * 关掉的轨也摆出来（planned 照实数），标成「已关闭」。
   * @param {Array<object>} tracks 设置里的轨清单
   * @param {Array<object>} rows 队列行
   * @returns {Array<{code: string, label: string, planned: number, unit_count: number, enabled: boolean}>}
   */
  function trackSummary(tracks, rows) {
    const queue = rows || []
    return (tracks || []).map(function (track) {
      const t = track || {}
      const code = String(t.code || "")
      let planned = 0
      queue.forEach(function (row) {
        if (row.track === code) planned += 1
      })
      return {
        code: code,
        label: String(t.label || TRACK_LABEL[code] || code),
        planned: planned,
        unit_count: Number(t.unit_count || 0),
        enabled: t.enabled === false ? false : true,
      }
    })
  }

  /**
   * 顶部提示文案。服务端给了 notice 就用它，没给就自己算。
   * @param {object} payload GET /api/session 的响应
   * @param {{total: number, done: number, current: number, left: number}} summary
   * @returns {string}
   */
  function noticeText(payload, summary) {
    const given = String((payload && payload.notice) || "")
    if (given !== "") return given
    const left = summary ? Number(summary.left || 0) : 0
    return left > 0 ? "还有 " + left + " 个没做完" : ""
  }

  /**
   * 会话里的轨道列表——库里存的是 JSON 字符串，接口也可能给数组，两种都收。
   * @param {unknown} value
   * @returns {string[]}
   */
  function parseTracks(value) {
    if (Array.isArray(value)) {
      return value.map(function (v) {
        return String(v)
      })
    }
    if (typeof value === "string" && value !== "") {
      try {
        const parsed = JSON.parse(value)
        if (Array.isArray(parsed)) {
          return parsed.map(function (v) {
            return String(v)
          })
        }
      } catch (err) {
        return value
          .split(",")
          .map(function (v) {
            return v.trim()
          })
          .filter(function (v) {
            return v !== ""
          })
      }
    }
    return []
  }

  /** 一行队列 */
  function queueRowNode(row, view) {
    const children = [
      el("span", { class: "queue-mark", text: row.mark }),
      el("span", { class: "queue-title", text: row.title }),
      el("span", { class: "queue-meta", text: TRACK_LABEL[row.track] || row.track || "" }),
      UI.pill(row.label, row.tone),
    ]
    if (row.state === "current") {
      children.push(
        el("button", {
          class: "queue-action",
          text: "完成这个",
          onclick: function () {
            completeUnit(view, row.unit_id)
          },
        })
      )
    }
    return el("div", { class: "queue-item " + row.cls }, children)
  }

  /** 主卡：当前会话的队列 */
  function queueHero(payload, rows, summary, view) {
    const children = [
      UI.statGrid([
        { label: "本次共", value: summary.total + " 个", tone: "accent" },
        { label: "已完成", value: summary.done + " 个", tone: "ok" },
        { label: "正在学", value: summary.current + " 个", tone: summary.current > 0 ? "warn" : "" },
        { label: "还剩", value: summary.left + " 个" },
      ]),
      el("div", { class: "queue" }, rows.map(function (row) {
        return queueRowNode(row, view)
      })),
    ]
    const actions = [
      el("button", {
        text: "暂停会话",
        onclick: function () {
          pauseSession(view)
        },
      }),
    ]
    children.push(el("div", { class: "row" }, actions))
    return UI.hero({
      title: "本次会话的队列",
      sub: "按跨轨权重排好的一条队列——已完成打勾、正在学标黄、没开始置灰。",
      children: children,
    })
  }

  /** 普通卡：会话本身的信息 */
  function sessionPanel(payload) {
    const session = (payload && payload.session) || {}
    const tracks = parseTracks(session.tracks).map(function (code) {
      return TRACK_LABEL[code] || code
    })
    return UI.panel({
      title: "会话信息",
      children: [
        UI.kv([
          ["会话编号", String(session.id || "")],
          ["开始时间", String(session.started_at || "")],
          ["计划单元", String(session.planned_count || 0) + " 个"],
          ["已完成", String(session.done_count || 0) + " 个"],
          ["涉及轨道", tracks.length > 0 ? tracks.join("、") : "—"],
        ]),
      ],
    })
  }

  /** 静默卡：三轨概况——背景信息，不抢主卡的注意力 */
  function trackPanel(tracks) {
    const items = tracks.map(function (track) {
      return {
        label: track.label,
        value: track.planned + " 个",
        hint: track.enabled ? "可学 " + track.unit_count + " 个" : "已关闭",
        tone: track.enabled ? "" : "warn",
      }
    })
    return UI.panel({
      title: "三轨概况",
      className: "quiet",
      children: [
        UI.statGrid(items),
        el("p", {
          class: "faint",
          text: "这里摆的是「这次排了什么、各轨还能学多少」；掌握度要到诊断页看。",
        }),
      ],
    })
  }

  /** 还没有会话（或这次的队列全空了）时的空态：给一个开始按钮 */
  function emptyHero(settings, view, title, sub) {
    const sessionCfg = (settings && settings.session) || {}
    const defaultCount = Number(sessionCfg.default_count || 3)
    let totalUnits = 0
    ;((settings && settings.tracks) || []).forEach(function (track) {
      totalUnits += Number((track && track.unit_count) || 0)
    })
    return UI.hero({
      title: title,
      sub: sub,
      children: [
        UI.statGrid([
          { label: "默认每次", value: defaultCount + " 个单元", tone: "accent" },
          { label: "可学单元", value: totalUnits + " 个" },
          { label: "已排队列", value: "0 个" },
        ]),
        el("div", { class: "row" }, [
          el("button", {
            class: "primary",
            text: "开始一次学习",
            onclick: function () {
              startSession(view, defaultCount)
            },
          }),
        ]),
      ],
    })
  }

  /** 出错时的提示（不崩页面） */
  function errorPanel(title, err) {
    return el("section", { class: "panel" }, [
      el("h2", { text: title }),
      el("p", { class: "error", text: String((err && err.message) || err) }),
    ])
  }

  /** 开始一次会话 */
  async function startSession(view, count) {
    try {
      await A.postJson("/api/session/start", { n: count })
    } catch (err) {
      view.textContent = ""
      view.appendChild(errorPanel("开始失败", err))
      return
    }
    await render(view)
  }

  /** 把当前单元标记为完成（P1 只排不判） */
  async function completeUnit(view, unitId) {
    try {
      await A.postJson("/api/session/submit", { unit_id: unitId })
    } catch (err) {
      view.textContent = ""
      view.appendChild(errorPanel("提交失败", err))
      return
    }
    await render(view)
  }

  /** 暂停会话：队列留着，下次接着学 */
  async function pauseSession(view) {
    try {
      await A.postJson("/api/session/pause", {})
    } catch (err) {
      view.textContent = ""
      view.appendChild(errorPanel("暂停失败", err))
      return
    }
    await render(view)
  }

  /**
   * 渲染首页。
   * @param {HTMLElement} view
   * @returns {Promise<void>}
   */
  async function render(view) {
    view.textContent = ""
    view.appendChild(el("div", { class: "panel", text: "正在加载本次学习…" }))
    let payload = null
    let settings = null
    try {
      payload = await A.getJson("/api/session")
      settings = await A.getJson("/api/settings")
    } catch (err) {
      view.textContent = ""
      view.appendChild(errorPanel("加载失败", err))
      return
    }
    const data = payload || {}
    const cfg = settings || {}
    const rows = buildQueueRows(data.queue)
    const summary = queueSummary(rows)
    const tracks = trackSummary(cfg.tracks, rows)

    view.textContent = ""
    view.appendChild(
      UI.pageHead({
        eyebrow: "学习中枢",
        title: "本次学习",
        sub: "会话按单元数计，不按天——点开就开始学，中断了也不会丢。",
      })
    )

    const notice = noticeText(data, summary)
    if (notice !== "") {
      view.appendChild(
        el("div", { class: "notice" }, [
          el("p", { class: "notice-title", text: "接着上次" }),
          el("p", { class: "notice-text", text: notice }),
        ])
      )
    }

    if (!data.session) {
      view.appendChild(
        emptyHero(
          cfg,
          view,
          "还没有会话",
          "点「开始一次学习」就会按跨轨权重排一条队列——算法、数据库、AI 混着排，中断了也不会丢。"
        )
      )
    } else if (rows.length === 0) {
      view.appendChild(
        emptyHero(cfg, view, "这次学完了", "这次的单元都做完了。点「开始一次学习」排下一次。")
      )
    } else {
      view.appendChild(queueHero(data, rows, summary, view))
      view.appendChild(sessionPanel(data))
    }
    view.appendChild(trackPanel(tracks))
  }

  A.pages.session = {
    title: "本次学习",
    render: render,
  }

  // Node（单测）下导出纯函数与渲染函数——老测试直接用同一份实现
  if (typeof module !== "undefined" && module.exports) {
    module.exports = {
      describeQueueItem: describeQueueItem,
      buildQueueRows: buildQueueRows,
      queueSummary: queueSummary,
      trackSummary: trackSummary,
      noticeText: noticeText,
      parseTracks: parseTracks,
      render: render,
    }
  }
})()
```

```js
function findAllByClass(node, className) {
  const out = []
  function walk(n) {
    if (!n) return
    if (n.className === className) out.push(n)
    ;(n.children || []).forEach(walk)
  }
  walk(node)
  return out
}

function findByClass(node, className) {
  return findAllByClass(node, className)[0] || null
}

function findAllByToken(node, token) {
  const out = []
  function walk(n) {
    if (!n) return
    const parts = String(n.className || "").split(/\s+/)
    if (parts.indexOf(token) !== -1) out.push(n)
    ;(n.children || []).forEach(walk)
  }
  walk(node)
  return out
}

function findByAttr(node, attr, value) {
  let hit = null
  function walk(n) {
    if (hit || !n) return
    if (n.attributes && n.attributes[attr] === value) {
      hit = n
      return
    }
    ;(n.children || []).forEach(walk)
  }
  walk(node)
  return hit
}

function findButton(node, label) {
  let hit = null
  function walk(n) {
    if (hit || !n) return
    if (n.tagName === "button" && String(n.textContent || "").indexOf(label) !== -1) {
      hit = n
      return
    }
    ;(n.children || []).forEach(walk)
  }
  walk(node)
  return hit
}

}
```

```js
"use strict"
/**
 * settings.js —— 会话设置页（#/settings）
 *
 * 四块内容：
 *   1. 会话长度（主卡）——每次学几个单元，1~10
 *   2. 跨轨权重——每轨一个权重 + 一个开关，关掉的轨不参与排课
 *   3. 复习次数阈值 K——学 K 个单元就该回顾一次到期卡
 *   4. 环境自检（静默卡）——Python / NumPy 在不在
 *
 * 密钥纪律：这一页**只显示布尔事实**（有没有配 LLM 密钥），
 * 绝不显示密钥本身——密钥也不在 GET /api/settings 的响应里。
 */

;(function () {
  const A = window.StudyHub || window.AlgoPlan
  const el = A.el

  /**
   * 公共界面构件。浏览器里 ui.js 先加载挂 window.AlgoPlanUI；
   * Node 下没有全局挂载，就 require 同一份文件——实现只有一份。
   */
  const UI =
    (typeof window !== "undefined" && (window.AlgoPlanUI || (A && A.ui))) ||
    (typeof require === "function" ? require("../ui.js") : null)

  /** 轨代码 → 中文标签 */
  const TRACK_LABEL = { algorithm: "算法", database: "数据库", ai: "AI" }

  /**
   * 归一化设置里的轨清单——缺字段也不炸。
   * @param {Array<object>} tracks
   * @returns {Array<{code: string, label: string, weight: number, enabled: boolean, unit_count: number}>}
   */
  function normalizeTracks(tracks) {
    return (tracks || []).map(function (track) {
      const t = track || {}
      const code = String(t.code || "")
      return {
        code: code,
        label: String(t.label || TRACK_LABEL[code] || code),
        weight: Number(t.weight || 0),
        enabled: t.enabled === false ? false : true,
        unit_count: Number(t.unit_count || 0),
      }
    })
  }

  /**
   * 三轨权重加起来是多少（四舍五入到 4 位，避开浮点尾巴）。
   * @param {Array<object>} tracks
   * @returns {number}
   */
  function weightSum(tracks) {
    let sum = 0
    ;(tracks || []).forEach(function (track) {
      sum += Number((track && track.weight) || 0)
    })
    return Math.round(sum * 10000) / 10000
  }

  /**
   * 表单状态 → 请求体（契约 §8.2.2 的形状）。
   * @param {{session_count: number, count_trigger_k: number, weights: {[code: string]: number}, enabled: {[code: string]: boolean}}} fields
   * @returns {{session_count: number, count_trigger_k: number, track_weights: {[code: string]: number}, track_enabled: {[code: string]: boolean}}}
   */
  function buildPayload(fields) {
    const f = fields || {}
    const weights = {}
    const enabled = {}
    Object.keys(f.weights || {}).forEach(function (code) {
      weights[code] = Number(f.weights[code])
    })
    Object.keys(f.enabled || {}).forEach(function (code) {
      enabled[code] = f.enabled[code] === true
    })
    return {
      session_count: Number(f.session_count),
      count_trigger_k: Number(f.count_trigger_k),
      track_weights: weights,
      track_enabled: enabled,
    }
  }

  /**
   * 校验请求体。返回空数组表示没问题。
   * 报错文案与服务端一致——前端先拦一道，不让非法值打回去。
   * @param {object} payload
   * @returns {string[]}
   */
  function validatePayload(payload) {
    const errors = []
    const p = payload || {}
    const count = Number(p.session_count)
    if (!Number.isInteger(count) || count < 1 || count > 10) {
      errors.push("会话长度必须是 1~10 的整数")
    }
    const k = Number(p.count_trigger_k)
    if (!Number.isInteger(k) || k < 1) {
      errors.push("次数阈值 K 必须是大于等于 1 的整数")
    }
    const weights = p.track_weights || {}
    Object.keys(weights).forEach(function (code) {
      const w = Number(weights[code])
      if (!Number.isFinite(w) || w < 0) {
        errors.push("轨权重必须是不小于 0 的数字")
      }
    })
    const enabled = p.track_enabled || {}
    Object.keys(enabled).forEach(function (code) {
      if (typeof enabled[code] !== "boolean") {
        errors.push("轨开关必须是布尔值")
      }
    })
    return errors
  }

  /**
   * 环境自检 → 两行（Python / NumPy）。
   * @param {object} env
   * @returns {Array<{key: string, label: string, ok: boolean, detail: string}>}
   */
  function envRows(env) {
    const e = env || {}
    const defs = [
      { key: "python", label: "Python 解释器" },
      { key: "numpy", label: "NumPy" },
    ]
    return defs.map(function (def) {
      const item = e[def.key] || {}
      return {
        key: def.key,
        label: def.label,
        ok: item.ok === true,
        detail: String(item.detail || "没检测到"),
      }
    })
  }

  /** 出错时的提示（不崩页面） */
  function errorPanel(title, err) {
    return el("section", { class: "panel" }, [
      el("h2", { text: title }),
      el("p", { class: "error", text: String((err && err.message) || err) }),
    ])
  }

  /**
   * 保存设置。校验不过就不发请求，直接把中文错摆出来。
   * @param {HTMLElement} view
   * @param {HTMLElement} statusNode 提示行
   * @param {object} fields 表单状态
   * @returns {Promise<void>}
   */
  async function save(view, statusNode, fields) {
    const payload = buildPayload(fields)
    const errors = validatePayload(payload)
    if (errors.length > 0) {
      statusNode.className = "error"
      statusNode.textContent = errors.join("；")
      return
    }
    try {
      await A.putJson("/api/settings", payload)
    } catch (err) {
      statusNode.className = "error"
      statusNode.textContent = String((err && err.message) || err)
      return
    }
    statusNode.className = "ok-text"
    statusNode.textContent = "已保存，下一次会话按新设置排。"
  }

  /**
   * 渲染设置页。
   * @param {HTMLElement} view
   * @returns {Promise<void>}
   */
  async function render(view) {
    view.textContent = ""
    view.appendChild(el("div", { class: "panel", text: "正在加载设置…" }))
    let settings = null
    try {
      settings = await A.getJson("/api/settings")
    } catch (err) {
      view.textContent = ""
      view.appendChild(errorPanel("加载失败", err))
      return
    }
    const cfg = settings || {}
    const tracks = normalizeTracks(cfg.tracks)
    const sessionCfg = cfg.session || {}
    const reviewCfg = cfg.review || {}

    const fields = {
      session_count: Number(sessionCfg.default_count || 3),
      count_trigger_k: Number(reviewCfg.count_trigger_k || 5),
      weights: {},
      enabled: {},
    }
    tracks.forEach(function (track) {
      fields.weights[track.code] = track.weight
      fields.enabled[track.code] = track.enabled
    })

    const statusNode = el("p", { class: "muted", text: "" })

    view.textContent = ""
    view.appendChild(
      UI.pageHead({
        eyebrow: "学习中枢",
        title: "设置",
        sub: "会话长度、跨轨权重、复习次数阈值——改完保存，下一次会话按新设置排。",
      })
    )

    /* ---------- 会话长度：主卡 ---------- */

    const countInput = el("input", {
      type: "number",
      min: String(sessionCfg.min_count || 1),
      max: String(sessionCfg.max_count || 10),
      "data-field": "session_count",
      class: "setting-input",
    })
    countInput.value = String(fields.session_count)
    countInput.addEventListener("change", function () {
      fields.session_count = Number(countInput.value)
    })

    view.appendChild(
      UI.hero({
        title: "每次学几个",
        sub: "会话长度按单元数计，不按天数。",
        children: [
          UI.statGrid([
            { label: "当前", value: fields.session_count + " 个单元", tone: "accent" },
            {
              label: "可选范围",
              value: (sessionCfg.min_count || 1) + "~" + (sessionCfg.max_count || 10) + " 个",
            },
            { label: "生效时机", value: "下一次会话" },
          ]),
          el("div", { class: "setting-row" }, [
            el("span", { class: "setting-name", text: "每次学几个" }),
            countInput,
            el("span", { class: "setting-hint", text: "1~10 个单元，排一条队列。" }),
          ]),
          el("div", { class: "row" }, [
            el("button", {
              class: "primary",
              text: "保存设置",
              onclick: function () {
                save(view, statusNode, fields)
              },
            }),
          ]),
          statusNode,
        ],
      })
    )

    /* ---------- 跨轨权重：普通卡 ---------- */

    const trackChildren = tracks.map(function (track) {
      const weightInput = el("input", {
        type: "number",
        step: "0.05",
        min: "0",
        max: "1",
        "data-field": "weight:" + track.code,
        class: "setting-input",
      })
      weightInput.value = String(track.weight)
      weightInput.addEventListener("change", function () {
        fields.weights[track.code] = Number(weightInput.value)
      })

      const toggle = el("input", {
        type: "checkbox",
        "data-field": "enabled:" + track.code,
        class: "setting-input",
      })
      toggle.checked = track.enabled
      toggle.addEventListener("change", function () {
        fields.enabled[track.code] = toggle.checked === true
      })

      return el("div", { class: "setting-row" }, [
        el("span", { class: "setting-name", text: track.label }),
        weightInput,
        toggle,
        el("span", {
          class: "setting-hint",
          text: track.enabled
            ? "权重 " + track.weight + " · 可学 " + track.unit_count + " 个"
            : "已关闭，不参与排课",
        }),
      ])
    })
    trackChildren.push(
```
